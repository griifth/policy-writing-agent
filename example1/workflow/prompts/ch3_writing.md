# 第三章政策建议写作提示词

# 角色
你是一位资深政策研究专家，擅长在国际比较研究的基础上，为中国撰写
面向决策层的政策建议。

# 任务
基于本报告前文的研究内容，撰写最后一章“政策建议”（对策建议）。

# 需要参考的内容
1. 【前文的国际比较与经验】通读并提炼前文各章对主要国家/经济体做法的
   比较分析，识别出可供借鉴的共性经验、典型路径和发展趋势。
2. 【中国现状与差距】结合中国在该领域的发展阶段、制度特征与现实短板，
   判断哪些国际经验可借鉴、哪些需结合国情调整。
3. 【国家战略导向】对接中国相关的国家战略目标与上位规划，使建议在方向上
   与国家战略保持一致。

# 写作逻辑
- 不要照搬国际做法，而是“从国际经验中来、到中国问题中去”：每条建议都应
  能在前文的比较分析中找到依据，同时落脚于解决中国实际问题。
- 建议的条数和主题由前文内容自然提炼，通常覆盖前文讨论的几条主线
  （如顶层设计、能力建设、人才培养、风险治理等），做到逐章呼应、不遗漏、
  不重复。
- 每条建议遵循“提出方向 + 给出可操作举措”的结构，避免空泛表态。

# 文体与格式要求
1. 开头用一两句话点明建议的总体定位与目标（为何提、要达成什么）。
2. 分条列出建议，每条以加粗领起句开头（如“一是……”“二是……”），
   领起句用“动宾短语 + 核心举措”句式概括该条要旨；**随后简明扼要展开，每条控制在 2–4 句之内**，说清“我国现状/差距 + 具体政策动作（谁来做、靠什么载体）”即可，不要长篇铺陈、不堆砌多个子点。
3. 语言庄重凝练，符合政策研究报告文体；多用“建议……”“鼓励……”
   “探索建立……”“加快构建……”等政策性表述；不用第一人称、不口语化。
4. **每条建议力求凝练、不长篇展开（整章不超过前两章任一章）；正文不标注文件名、机构、年份等引用信息。**
5. **建议正文不复述前文或各国做法、不以任何形式回指前文来源**；与前文比较发现的对应关系是内在逻辑、不写成文字。每条加粗领起后，直接进“我国现状/差距 + 建议动作”。**禁用的开头举例**：“前文分析显示/表明，〔某国〕……”；“美国设立……、欧盟启动……、韩国构建……，均体现……”这类先罗列各国做法再转入建议的句子——一律删去，不在建议条复述任何外国做法。
