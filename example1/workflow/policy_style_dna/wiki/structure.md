# structure.md（顶层通则·全子型）

> 全子型通则。**章节递进范式与建议收尾随子型变化**，见 `subtype_a.md`（战略建议/预警）/ `subtype_b.md`（机制/趋势综述）。

## 1. 头号结构律（全子型）：先断后证·判断句领起每个单元
- 每个组织单元（章/维度/类型）以**一句归纳判断领起**（"综观〔A、B、C〕等国，主流实践趋向于……"），下挂多国实例填充。这是全语料最高频骨架，**比"编者按""加粗领起"都更普遍**。
- 判断∶证据 ≈ 1∶N；杜绝资料堆叠而无判断领起、或判断后不缀实证。

## 2. 开篇方式（**多态，无主次**；均无摘要/关键词/署名块）
语料里至少七式并存，按议题与意图任选其一，**不假设"编者按为主"**：
- **编者按**：交代①议题为何重要 ②梳理哪几国 ③"力图为我国……提供借鉴"。
- **数据导语**：首句抛权威机构统计确立议题重量。
- **价值升格句**：把议题抬到国家战略（多见子型A）。
- **趋势断言**：“随着〔某变化〕，〔某领域〕呈现新趋势和特点。”
- **警情切入**：“〔某国〕发布《某法案》，以中国为假想敌……”（子型A常用）。
- **政策语境切入**：以国内政策热词（如"双减"）入题。
- **纯报告自述/群体画像**：“本报告聚焦……进行梳理分析”，或先勾勒各国地理/收入分层画像。

## 3. 国际经验的组织法（全子型工程规则）
- **先类型化立框优于裸罗列**：先"国外主要存在三种模式：……"立骨架，再把国家当例证塞进类里——类是骨架，国是例证。
- **但"平铺＋收拢"也是合法形态**：一国一段平铺只要节首有判断句领起、节末有收拢句，即为合格人类成稿；**不要把"平铺"本身当缺陷**。真缺陷是下条。
- **追求"真比较"**：高质量比较 = 差异 + 原因 + 适用条件（"与〔A国〕不同，〔B国〕……究其原因，与其〔体制/人口/传统〕相关"）。**对比表 / √-矩阵是真比较的硬载体**，能上表则上表。
- **组织轴可选**：按维度切 / 按洲（区域）切 / 按功能大类横切（研究型/应用型…，而非按国切）。
- **量化分层对位**：用并置百分比（"前 5%／前 1%"、"占比 12.5%／33%／开放"）制造跨国可比性。

## 4. 加粗与标题（全子型）
- **加粗领起有两种语法**：(a) 论点/判断句加粗领起；(b) 国名/专名加粗作并列锚点（民生并列题材）。两者都合法。
- **标题以"判断式整句"或"维度名词"为主**；动宾化是可选项之一，**不作硬性要求**。

## 5. 落点（**随子型**）
- 子型A：回到中国——镜像建议章 / 段内嵌入式中国对照。
- 子型B：合法地**无中国建议章**，落点为"趋势收拢句 / 三大待解问题 / 价值升华句"，或一句轻收"这些经验或可为我国……提供借鉴"。
- 详见对应子型文件。
