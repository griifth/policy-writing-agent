# 澄清生成逻辑要点（路线判定 / 候选问题凝练 / 五问预填）

> 供 `report-clarify/SKILL.md` 各步引用的判定细则。本文件是 skill 内部资产，
> 不放 `report_modules/` 下（runner 会把该目录下的子目录当可选体例列进 help，放这里避免污染）。

## 一、路线判定判据（SKILL 第①步）

**判"问题已明确"须同时满足三条**（缺一即走预检索路线）：
1. 有明确研究对象：具体国家/国家组 + 具体政策领域（"美国 AI 人才战略"明确；"国外教育科技"不明确）。
2. 有可判的问题形态：能改写成一个判断句或"研判 X 对我影响/借鉴 X 经验/比较 X 政策"句式。
3. 落点无歧义：看得出要"应对/借鉴/研判/比较"中的哪一种意图。

**兜底规则**：三条中任何一条拿不准 → 按"模糊主题"处理，走预检索。误把明确当模糊只多花几分钟；误把模糊当明确会写偏整篇——代价不对称，宁可多问。

## 二、预检索的浅采集口径（SKILL 第②步）

- 目标是**够凝练出候选问题**，不是够写作：每个可能的子方向 1–2 条线索即停。
- 搜索式取"主题词 + 政策/战略/白皮书/OECD/UNESCO + 近 2 年"，优先命中：最新官方文件、国际组织报告、权威统计、标志性事件。
- 每条线索记：`一句话事实 + (机构, 文件/报告名, 年份, URL) + 证据状态[已实施/试点/评估数据/意图或建议/媒体转述]`。
- **不做**：全量六类检索、料包文件、DS 审校、跨类去重——那些是 topic-material-search 全量模式的事。
- 线索不足（<3 条 T1/T2）：如实写"公开线索不足，建议换角度或先用 topic-material-search 深挖"，列出已有的。

## 三、候选研究问题凝练（SKILL 第③步）

从线索凝练 3–5 个候选问题，每个按此模板：

> 候选 N：〈判断句式的研究问题〉
> 契合体例：〈strategic_response / experience_response / trend_review / intl_comparison〉——〈一句理由〉
> 依据线索：〈引②中哪条〉

**体例契合的判据**（与 runbook 第 1 节选型表同源）：
- 对象国有进攻性/竞争性动作、我方要"应对" → `strategic_response`
- 他国做法成熟、我方要"借鉴启示" → `experience_response`
- 多国零散新信号、要"归纳趋势并研判阶段" → `trend_review`
- 多国同一议题横向铺开、按维度分章比较 → `intl_comparison`（根引擎）

**质量线**：候选问题必须是判断句或明确的研判任务，不得是名词短语（"XX的现状与思考"不合格）；每个候选问题至少挂 1 条真实线索，无线索支撑的候选不出。

## 四、五问的预填默认项规则（SKILL 第④步）

自动判定**只做预填**，呈现时标注"推荐"，由用户改选或确认：

- **Q1 读者层级**：从问题的落点高度预填——涉国家战略格局/国际竞争位次 → `national_leader`；涉部级制度设计/政策工具 → `moe_leadership`；涉具体工程/试点/操作 → `bureau`。判不出 → 预填 `moe_leadership`（内参最常见档），并说明理由。
- **Q2 体例**：用第三节的体例契合判据预填；用户在 ③ 已点选候选问题时，直接带出该候选标注的体例。
- **Q3 核心观点**：预检索有强信号（如多条线索指向同一判断）→ 预填一句归纳；否则预填"暂无，由检索归纳"。
- **Q4 维度逻辑**：按体例预填——strategic_response → 举措→意图→压力→应对；experience_response → 做法→成因→有效性→迁移；trend_review → 信号→趋势→阶段→对策；intl_comparison → 顶层设计×实施机制（或用户自拟维度对）。
- **Q5 文风子型**：预填 `auto`（引擎会按体例路由 a/b）；仅当用户明确要求"预警腔"或"纯综述"时预填 a/b。

## 五、clarify_decision.md 的固定格式（SKILL 第⑤步）

```markdown
# 写作前澄清决策（<日期> · <主题短语>）

## 五问答案
- Q1 读者层级：<值>（<用户选择/默认确认>）
- Q2 体例：<值> → <引擎与 --report-type>
- Q3 核心观点：<一句话 或 "暂无，由检索归纳">
- Q4 维度逻辑：<表述>
- Q5 文风子型：<auto/a/b>

## 候选研究问题（含未选中项，备改题）
1. <候选1>（体例：<X>）【选中】
2. <候选2>（体例：<Y>）
...

## 预检索线索（3–5 条，带溯源）
1. <事实> (机构, 文件, 年份, URL) [证据状态]
...

## 启动命令（用户已确认）
<完整命令>
```
