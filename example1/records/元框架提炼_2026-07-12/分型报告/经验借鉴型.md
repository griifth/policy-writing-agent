# 分型报告：经验借鉴型

- **样本**：15 张骨架卡（全部读毕）
- **体裁判型自证**：15 张卡自标体裁均含"经验借鉴型"（副型分别挂综合比较型／风险预警型／趋势研判型／资料综述型）
- **一句话本型定义**：以"他国／他地区做法"为主体证据，替决策者回答"别人怎么做、做出了什么共性、我们该不该学、怎么学"这一串问题；举证是全篇骨肉，落地（对照中国＋给建议）是可切换的尾部开关。

---

## 1. 槽位序列（本型从头到尾的功能槽位顺序）

下列为本型的**典型主序列**。每槽标注必选/可选/条件，并给出"替读者回答什么问题"。

| 序 | 槽位 | 必选性 | 替读者回答什么问题 |
|---|---|---|---|
| S1 | **定调** | 必选 | 这个题此刻为什么值得决策者花时间看？站位／紧迫性从哪来？ |
| S2 | **引题** | 可选 | 从大背景里，究竟要拎出哪个具体抓手作全文靶心？ |
| S3 | **溯源** | 可选 | 这件事的来龙去脉／概念边界是什么？考察对象是谁、为什么选它？ |
| S4 | **铺态势** | 可选 | 放到全球看，眼下的总体动向／格局是什么样？ |
| S5 | **分型** | 可选 | 把纷繁做法归成哪几类／哪几条路径来看，才拎得清？ |
| S6 | **举证** | 必选 | 具体到某国／某维度，人家到底怎么做的？（全篇主体，反复出现） |
| S7 | **提炼** | 可选（高频） | 摊开这么多国别做法，共通的规律／共性是什么？ |
| S8 | **数据锚** | 可选 | 规模／差距／紧迫性有没有硬数字或比较表坐实？ |
| S9 | **研判** | 可选 | 这些做法背后的深层动因／成败逻辑／大势是什么（作者判断）？ |
| S10 | **对照中国** | 条件槽 | 落到我国，我们处在什么位置、差在哪、有什么基础？（触发条件：报告尾部拟落地本土时出现；纯综述篇不出现） |
| S11 | **给建议** | 条件槽 | 那我们具体该做什么？（触发条件：标题／编者按含"启示／应对／破解／建议／落地"取向时出现；纯综述篇不出现） |
| S12 | **预警** | 可选（低频） | 照这么走下去有什么风险不得不防？（多以子句嵌入建议/对照，罕见独立成段） |
| S13 | **收束** | 可选（低频） | 把全篇拔一句规律作结（罕见，仅"半截式"篇用它替代落地） |

**主序列可压缩为两条骨架**：
- **落地型骨架**（尾部开关"开"）：`定调 →〔溯源/铺态势〕→〔分型〕→ 举证(主体) →〔提炼〕→〔研判/数据锚〕→ 对照中国 → 给建议`
- **综述型骨架**（尾部开关"关"）：`定调/溯源 →〔分型〕→ 举证(主体) ↔ 提炼(交替) →〔研判/数据锚〕→（戛然而止或一句收束）`

两条骨架的分水岭就是 S10/S11 这对条件槽是否被激活——这是本型内部最大的形态断层（详见变体清单"落地开关"）。

## 2. 篇幅配比区间（取自各卡"篇幅占比%"列）

单段占比与聚合占比分列。聚合＝该功能所有段落占比之和。

| 槽位 | 单段占比区间 | 聚合占比区间（跨卡） | 说明 |
|---|---|---|---|
| 定调 | 2–10% | 2–10% | 通常一段；本土热点/紧迫感开篇偏长（课后服务10、人才争夺10） |
| 引题 | 1–5% | 1–5% | 极短，多与定调共段 |
| 溯源 | 1–8% | 1–8% | 概念界定型偏长（超常儿童8、综合高中8） |
| 铺态势 | 2–6% | 2–6% | 短 |
| 分型 | 1–5% | 1–9% | 显式分型句极短；生成式AI三处分型聚合约9% |
| **举证** | 1–20% | **约 20–96%**（主体，多数卡 40–85%） | 全型骨肉；纯综述篇逼近全篇（终身学习≈96、生成式AI≈81、数字教科书≈80） |
| 提炼 | 1–6% | 2–21% | 课后服务共性段聚合达21% |
| 数据锚 | 1–3% | 1–6% | 表格/附件锚 |
| 研判 | 1–9% | 3–22% | 校外教育"动因研判"聚合22%为异常高 |
| 对照中国 | 1–13% | 4–17% | 超常儿童单段13、全球AI六趋势聚合17 |
| 给建议 | 2–15% | 9–53% | 超常儿童聚合≈53、人才争夺≈44 为建议主导篇 |
| 预警 | 6% | 6% | 仅校外教育独立成段（6%） |
| 收束 | 5% | 5% | 仅生成式AI独立成段（5%） |

**结构性读数**：举证聚合占比的下限（超常儿童仅20%）与上限（终身学习≈96%）之比接近1:5，说明本型的"重心"可在"举证扫描"与"对策落地"两端大幅滑动；给建议聚合从0（7篇无建议段）跳到53%，是最不稳定的槽位。

## 3. 形态变体清单（每变体均引 ≥2 张卡原文为证）

### 变体组 A：定调（开篇立调）

**A1 政治站位/权威背书式**——引最高领导人讲话或党代会报告立政治调
- 《国外一流高校运用生成式人工智能加速原创性颠覆性科技创新的策略与举措》段1："编者按：习近平总书记2024年1月在中共中央政治局第十一次集体学习时强调，科技创新是发展新质生产力的核心要素……"
- 《主要国家将超常儿童培养上升为国家战略》开头第3句："党的二十大报告指出，教育、科技、人才是全面建设社会主义现代化国家的基础性、战略性支撑……"

**A2 外部威胁/竞争紧迫式**——以他国战略"盯上中国"制造紧迫感
- 《中美AI人才竞争及应对策略》段1："2021年3月，美国人工智能国家安全委员会发布最终报告，以中国为'假想敌'进行人工智能人才竞争（全文提及'中国'达500多次）……"
- 《全球经验-人工智能拔尖人才培养的六大前沿趋势》段1："2021年中国驻外使领馆教育处发回的三轮调研报告显示，欧美及日韩等发达国家的主流媒体时常渲染中国在人工智能领域的全球领跑地位……"
- 《美英澳等国新一轮国际人才争夺的长短线招数及其破解》段1："近期，美、英、澳等国均推出'短线'与'长线'相结合的国际人才争夺战略。"

**A3 编者按/共同难题式**——点明议题为各国普遍难题、日益受重视
- 《中小学数字教科书设计典型经验》段1："编者按：随着数字技术日益成熟和信息时代人才培养规格的新要求，数字教科书的建设与发展日益受到世界各国、地区政府……的重视。"
- 《主要国家学校体育发展综述》段1："编者按：为应对青少年体质下降危机，近年来，全球许多国家日益重视发展学校体育。"
- 《美英德澳培养与聘任体育教师的做法和特点》段1："编者按：体育教师的培养与聘任是世界各国普遍面临的难题……"

**A4 本土热点/政策落地式**——以我国当前政策或社会热点难点起笔
- 《从国际经验中优化课后服务推动双减政策落地》段1："'双减'工作启动以来，多部门快速联动，'组合拳'连环出击，在遏制资本无序扩张、治理校外培训乱象等方面已取得重大阶段性成效。"
- 《校外教育治理的国际趋势与经验》段1："校外教育治理是当前我国受到广泛社会关注的热点难点问题，从世界范围看，校外教育的扩张也成为普遍趋势。"

**A5 非定调起法（无立题段）**——以溯源/铺态势/直接举证代替定调开篇
- 《典型国家综合高中发展的基本经验》段1（溯源开篇）："20世纪以来，世界各国纷纷开始创办综合高中，旨在打破普通教育和职业教育二元对立的高中教育体系……"
- 《拔尖创新人才早期培养国际经验及启示》段1（无头直接举证）："天才儿童个人成长与国家战略结合。"
- 《主要国际组织和国家推动终身学习主要路径》段1（铺态势开篇）："创建学习型社会是国际教育领域的重要理念，多个国际组织积极倡导该理念并推动其落地。"

### 变体组 B：举证的组织方式（全篇骨架）

**B1 维度切块×国别填充**——以主题/设计维度为一级框架，维度内并列多国
- 《中小学数字教科书设计典型经验》段3/4："技术举措方面。美国国家教育统计中心组织开发了'全国教育数据模型'……" / "政策与规范方面。韩国教育部发布了《中小学数字基础设施发展规划》……"
- 《葡语九国教育数字化策略》段10（维度提炼领起）："推动数字基础设施建设……为发展教育数字化的关键举措……"其下堆叠莫桑比克、葡萄牙、安哥拉等国别举证
- 《主要国家学校体育发展综述》以五大主题栏目（立法—课时—赛事/特色校—评价—师资）切块，栏内罗列英/意/法/德/美/加等国做法

**B2 国别切块×维度填充**——以国家为一级定点，逐国一段走完做法
- 《从国际经验中优化课后服务推动双减政策落地》段2/3/4："法国《社会行为和家庭法》……" / "2007年，日本文部科学省与厚生劳动省联合发布'放学后儿童计划'……" / "美国国会多项保育和教育法案……"
- 《美英澳等国新一轮国际人才争夺的长短线招数及其破解》段3/4/5："拜登政府今年2月向国会提交的《美国公民法案2021》……" / "英国2020年7月发布《英国研究与发展路线》……" / "2019年11月，澳大利亚首次推出'全球人才签证计划'……"
- 《美英德澳培养与聘任体育教师的做法和特点》以"美国PETE模式／英国多元灵活模式／德国二二制／澳大利亚CPD模式"逐国分块

### 变体组 C：分型（组织框架）

**C1 二元/少数几类关系分型**——归为两种模式对举
- 《典型国家综合高中发展的基本经验》段5："美国、英国和日本的综合高中与职业高中形成了并列和包含两种关系。"
- 《中小学数字教科书设计典型经验》段14："学习资源组织上，基本遵循两种思路。"
- 《拔尖创新人才早期培养国际经验及启示》段13："多种培养模式相结合，打造个性化培养路径。"（加速制/充实制两分）

**C2 并列多趋势/多路径分型**——归为三条以上并列型，以小标题或总起句承载
- 《国外一流高校运用生成式人工智能加速原创性颠覆性科技创新的策略与举措》段2："……大学制定生成式人工智能指南，主要从以下三个方面为科研工作者提供服务。"（鼓励使用—提供支持—规避风险三型）
- 《全球经验-人工智能拔尖人才培养的六大前沿趋势》小标题"二、六大角度借力全球经验"（六大前沿趋势并列）
- 《主要国际组织和国家推动终身学习主要路径》以二级小标题（六条路径）承担并列分型

### 变体组 D：提炼（共性归纳）

**D1 "主要国家/发达国家普遍……"段首共性判断句**
- 《从国际经验中优化课后服务推动双减政策落地》段8："主要国家学生课后服务具有托管看护和教育服务的双重功能，是儿童保育在学校教育阶段的延伸……"
- 《主要国家学校体育发展综述》段7："发达国家普遍构建了法律保障、课程体系和资源协同三位一体的支撑框架……"
- 《美英德澳培养与聘任体育教师的做法和特点》段21："国外体育教师培养注重跨学科性和综合性，强调体育科学、教育学、心理学等多学科领域的结合。"
- 《中小学数字教科书设计典型经验》段2："相关国家和地区数字教科书建设都非常重视安全与隐私问题……"

### 变体组 E：研判（作者判断）

**E1 归因/病根式研判**——揭示深层动因或制约根源
- 《校外教育治理的国际趋势与经验》段7："第一，收入差距的持续扩大和教育社会筛选功能的日益强化不断加剧教育竞争，是全球校外教育扩张的深层次原因。"
- 《拔尖创新人才早期培养国际经验及启示》段25："梳理发现，不利于天才儿童教育政策发展的因素主要是绝对平等主义。"

**E2 规律/大势式研判**——点明"核心逻辑/大势所趋/成败已证"
- 《主要国家学校体育发展综述》段3："世界体育教育强国将体育教育上升到国家战略层面……的核心逻辑，是以立法和政策强化顶层约束……"
- 《全球经验-人工智能拔尖人才培养的六大前沿趋势》段13："纵观全球，将人工智能上升为边界清晰的专业学科，以及整合为独立院系，是大势所趋。"
- 《典型国家综合高中发展的基本经验》段8："美国和英国综合高中的发展已经证明，包含关系模式并不成功。"

### 变体组 F：数据锚

**F1 表格/附件锚**——以比较表或数据附件作举证支点
- 《主要国家学校体育发展综述》段16/20/24："表1：英国学校运动会四级竞赛体系功能与成效" / "表2：西方特色体育学校核心运行机制对比" / "表3：全球主要国家中小学生体育素养测评体系比较"
- 《葡语九国教育数字化策略》段68："附件：葡语九国基本情况"（数据表）

**F2 权威统计开篇锚**——以国际权威机构数据坐实规模/紧迫
- 《全球经验-人工智能拔尖人才培养的六大前沿趋势》段3："国际权威数据显示，迄今在全球顶级学术会议上发表人工智能论文的约2.2万名AI拔尖人才中，美国占比高达46%……"
- 《主要国家学校体育发展综述》开头第2句："世界卫生组织（WHO）2019年报告显示，全球81%的青少年（11—17岁）未达到每日60分钟中高强度运动的标准……"
- 《美英德澳培养与聘任体育教师的做法和特点》开头第2句："根据美国国家教育统计中心（NCES）2022年统计数据，全美超半数的州存在体育教师短缺的问题……"

### 变体组 G：对照中国

**G1 差距/失机式对照**——直指我国短板、丧失机会
- 《主要国家将超常儿童培养上升为国家战略》段4："……如果不从国家层面研究论证和推进，不能做好超常儿童早期识别和科学培养工作，会存在丧失机会、遗漏潜在人才的可能。"
- 《全球经验-人工智能拔尖人才培养的六大前沿趋势》段4："我国国内目前还没有自己的较为权威的AI拔尖人才统计数据，只能从上述他国统计中，来反观中国这一群体的大致规模。"

**G2 基础/传统＋差距式对照**——先述我国已有基础再转差距（先扬后抑）
- 《拔尖创新人才早期培养国际经验及启示》段38："我国素有重视天才儿童教育的传统。"
- 《主要国家将超常儿童培养上升为国家战略》段4："基于人口总量和完善的国民教育体系，我国培养拔尖创新人才具有优势，但也要看到……"

### 变体组 H：给建议

**H1 "一是…N是…"序号分条（国家部门主语、过程动词）**
- 《主要国家将超常儿童培养上升为国家战略》段5起："一是成立专门机构。……二是加强专业科研。……六是稳慎有序推进。"
- 《拔尖创新人才早期培养国际经验及启示》段41起："一是研制专项战略。……二是加强专题科研。……七是稳慎有序推进。"

**H2 "第一…第N…"抓手分条（对位前文特点/共性）**
- 《从国际经验中优化课后服务推动双减政策落地》段12起（对位共同特征）："第一，明确服务对象，坚持适度规模。……第二，加强法治标准建设。"
- 《美英德澳培养与聘任体育教师的做法和特点》段26起（对位五大特点）："我国在体育教师职前培养方面，应充分借鉴国外先进经验，构建更加系统、全面的培养体系。"
- 《美英澳等国新一轮国际人才争夺的长短线招数及其破解》三级标题"（一）建立尖端人才国家数据库……（五）引导高中国际项目健康发展"

**H3 柔性启示/内嵌式建议（"值得关注/理应/可以探索"，非硬性对策）**

## 4. 异常篇目（不服从本型主序列的卡，逐一记录）

主序列指 `定调 →〔背景〕→ 举证主体 →〔提炼〕→ 对照中国 → 给建议`。以下逐卡记录偏离点：

1. **《主要国际组织和国家推动终身学习主要路径》**——**深度综述偏态**。以铺态势代定调开篇（无立题段），全篇 11 段除首段外几乎全为举证，无提炼共性收拢、无研判、无对照中国、无给建议、无收束；分型逻辑不落段落而全靠二级小标题（六路径）承载。落地槽位（S10–S13）整体缺位，是本型"纯举证扫描"的极端。

2. **《典型国家综合高中发展的基本经验》**——**无尾偏态**。溯源开篇（无定调），主体走"发展历程—普职关系—课程比例—管理—招考"多维举证＋两处分型/研判，但止于事实呈现：无提炼共性段、无对照中国、无给建议，"全文在日本毕业去向数据处戛然而止"。标题挂"基本经验"却不外推中国。

3. **《拔尖创新人才早期培养国际经验及启示》**——**无头＋碎片举证偏态**。开篇违序：无定调/引题/溯源，第1段即"天才儿童个人成长与国家战略结合"直接举证；主体由 37 段密集小举证（多为 1–2% 的极短段）拼成，概念界定散嵌各分点内。所幸尾部完整走"对照中国→提炼→七条建议"，落地部分回归主序列，属"头违序、尾合规"的半异常。

4. **《葡语九国教育数字化策略》**——**定调后置＋超密举证＋无落地偏态**。第1段为溯源（概念界定葡语九国），定调后置到第2段；主体以 8 主题维度堆叠约 60 处国别机构举证（占比几乎全篇），无研判、无对照中国、无给建议、无收束，末段以几内亚比绍案例直接收尾，数据表作附件锚。介于经验借鉴型与资料综述型之间，举证密度为全样本之最。

5. **《国外一流高校……策略与举措》**——**半截式＋收束替尾偏态**。定调→三型(分型+举证)并列，但分型句直接领起、无独立提炼共性段；结尾无对照中国、无给建议，改以段14"收束"作规律升华。是 15 卡中唯一以显式"收束"结篇者，属"只借鉴、不落地"的半截式。

6. **《中小学数字教科书设计典型经验》**——**维度平行＋无落地偏态**。定调→(提炼+举证)×五维度反复，规整但落地全缺：无研判、无对照中国、无给建议、无收束，借鉴取向仅由编者按一句"值得关注和借鉴"隐含。另有案例外延溢出标题（正文出现法国、日本，不在标题所列四方之内）。

7. **《校外教育治理的国际趋势与经验》**——**序列重排偏态**。走"定调→铺态势→举证(态势)→研判(动因，聚合达22%)→预警(独立成段)→提炼→举证(经验)"，把研判/预警**前置**于经验举证之前，与主序列"举证在前、研判在后"相反；且是本型唯一让预警独立成段的卡。无独立给建议段，中国方位仅开篇一句带过。

> 说明：以上 7 卡之外的 8 卡（中美AI、超常儿童、课后服务、全球AI六趋势、国外学制、体育教师、人才争夺，及作为标准三段式主干的若干篇）基本服从主序列或其"落地型"骨架，未单列为异常。全样本最大的规律是——**举证是唯一 15/15 全覆盖的必选槽，其余槽位（尤其对照中国、给建议、研判、收束）均可按"综述/落地"两种取向自由开合**，本型的形态方差主要由这对"落地开关"制造。
