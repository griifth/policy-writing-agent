## 一、方法（提示词 3·V2 多智能体 map-reduce）

38 篇 ≈60 万字超单 agent 上下文，故改为 map-reduce：每篇一子代理产骨架卡 → 引文抽查闸防编造 → 按主判型合并 → 总指挥本体总装。

| 阶段 | 做法 | 执行者 |
|---|---|---|
| **0 建制** | 建目录 `骨架卡/`、`分型报告/`；枚举 38 篇构造派单清单 | 总指挥 |
| **1 骨架卡** | 每篇一个全新子代理，只读被指派的 1 个源文件，按**固定模板**填卡（标题形态/体裁判型/小标题树/段落功能流[标签｜占比｜领起句原文]/开头解剖/建议段解剖/族谱归属/异常备注），功能标签取**封闭词表 15 个＋"其他"栏**，不得自造 | 38 个子代理（并行） |
| **1.5 抽查闸** | 逐卡抽 2 条引文，grep 回源核对；查不到即作废重派一次 | 38 个抽查子代理（低配） |
| **2 分型** | 按主判型分组，每型一个子代理**只读本组卡**出分型报告（槽位序列/配比区间/变体清单≥2卡证据/异常篇目）；不足 3 篇的型并入近似型 | 3 个分型子代理（并行） |
| **3 总装** | 读三份分型报告，总装 `元框架.md`＋`变体与反例.md`＋本 README | 总指挥本体 |

**封闭功能标签词表（15＋其他，本次冻结版，全程未改）**：
开篇 `①定调 ②引题 ③溯源`｜铺陈 `④铺态势 ⑤举证 ⑥数据锚`｜归纳 `⑦分型 ⑧提炼 ⑨研判`｜落地 `⑩展望 ⑪对照中国 ⑫预警 ⑬给建议`｜收尾 `⑭兜底 ⑮收束`｜`其他`（溢出栏）。
