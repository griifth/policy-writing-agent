## 一、背景（2 分钟读完）

`direction_workflow/` 是一套装配式政策报告工作流：从一个主题出发，机器跑「侦察→定方向→检索→立观点→人勾选→组稿→质量闸→交付」14 步，产出一篇决策咨询报告。**每跑一单，全部过程产物落在一个 `runs/<日期-主题>/` 目录里**（方向书、料包、观点清单、闸门报告、成稿……约 15–25 个 md 文件）。

**要解决的问题**：撰写者拿到成稿后想回看"这句话背后是哪条观点、那条观点背后是哪份材料、机器扔掉了什么"，现在只能在目录里翻十几个 md。**你要做的**：一个 skill（给 AI agent 读的作业指导书）＋一个 HTML 页面模板——让任意 agent 按 skill 指导读取一个 run 目录，生成一张**自包含单文件 HTML 回顾页**，把整条链路可视化。

**本机路径实况**（路径含空格，一切命令加引号）：
- 包根：`/Users/hujingkai/Documents/New project/example1/direction_workflow/`
- 试点 run（件最全）：`<包根>/runs/2026-07-13-科技教研员/`
- 容错测试 run（件不全）：`<包根>/runs/2026-07-15-新科技革命教育研判/`（只有方向书）

## 三、页面规格（六区一链）

**技术底线**：单文件 HTML，UTF-8，**零外链**（无 CDN/无外部字体/无网络请求），vanilla JS＋内联 CSS，数据以一个内联 JSON 嵌入。双击本地打开即用，可离线转发。中文正文字号 ≥14px，浅色底，打印友好。

```
① 单头卡：run 标题｜判型（若有）｜日期｜方向书四栏摘要（议题/倾向箭头/读者层级/禁区）｜台账关键数（勾选率、执行引擎）
② 主线链视图（页面主体·核心交互）：
   成稿各节小标题（左列）⇄ 对应已勾观点（中列）⇄ 观点的证据锚/料条目（右列）
   点击任一列条目，另两列高亮其关联项（三级联动）；关联数据来自观点的"证据摘要 F 锚"与"拟落槽位"
③ 观点清单区：全量观点，勾（✅）正常显示、叉置灰、改过的并排显示原句/改句；每条带勾选备注与置信度
④ 料包区：按类目分组的材料卡（编号/要点/来源/T级）；边角料箱独立子区——每条弃用料带"为什么没用/可在哪用"原文
⑤ 闸门区：各闸违例清单原文照录（清单为空显示"本闸无违例"）；预检单读数表原样呈现
⑥ 预读提词区：两组顾问考题＋三翻模拟；需作者定夺清单逐条列出
```

- 六区均可折叠；②默认展开，⑤⑥默认折叠。
- 顶部放一条"数据抽取备注"横幅入口：agent 生成时自报哪些字段是推断的、哪些文件缺失（见红线 6）。
- 页脚固定一行：**"本页内容全部抽取自 run 内文件原文；历史单中的称谓为当时实况。"**

## 五、红线（逐条自检，违反即返工）

1. **零分数零档位**：页面任何位置不得出现评分、星级、百分比健康度、"优/良/合格"。勾选率可显示（它是过程指标，须带上原文的"代理预演·非质量背书"字样，如有）。
2. **零编造**：页面所有实质文字必须抽自 run 文件原文；生成器不得新写任何结论、概括、评价性语句。区块空缺显示"本单无此件"。
3. **可见可捞回**：叉掉的观点、边角料、反证、`[待核]` 标记必须呈现（可默认折叠，不可省略）。
4. **只读**：对 run 目录只读；回顾页是唯一新增文件。
5. **模板不含人名**：page_template.html 与 SKILL.md 中不得出现任何真实人名；历史 run 内容含旧称谓（如 yongjun/cao 等）原样展示，靠页脚声明兜底。
6. **抽取诚实**：解析不确定、字段靠推断、文件缺失——一律记入 `extractionNotes` 并在页面"数据抽取备注"中可见。**宁可标"推断"，不可默默填**。

## 六、SKILL.md 要点（写给未来执行 agent 的作业指导）

- frontmatter：`name: run-review`；description 写明触发语（「回顾这单」「回顾 <run-id>」「看看这篇成稿背后的资料」「生成回顾页」；给成稿路径也应反查所属 run）。
- 生成流程四步：①清点 run 目录在场文件（对照第四节候选名单）→ ②按抽取规约解析为 JSON → ③把 JSON 替入 page_template.html 的 `/*__RUN_DATA__*/` 占位符 → ④落盘 `<run>/outputs/回顾页.html` 并自检（红线六条逐条过＋浏览器无 console 报错）。
- 写明红线六条（照抄第五节）。
- 路径约定一行：「本文件内相对路径一律以 direction_workflow/ 为根」（与包内其他 skill 一致）。

## 七、施工顺序与验收

1. 通读试点 run 全部文件 → 2. 写抽取规约 → 3. 写 page_template.html（可先用手造假数据调联动）→ 4. 写 SKILL.md → 5. 按 SKILL 流程对试点 run 真实生成 `回顾页.html` → 6. 对容错 run（只有方向书）再生成一张，验证缺件不崩 → 7. 逐条过验收清单。
