## 3. 预注册指标与成败口径

### M1 偏差复现（条件 N）
- 指标：人稿与 AI 稿的组中位排名（每评委 1–12 排名的组内中位数，再取 3 评委中位）。
- 预期：AI 稿组中位排名优于人稿（复现偏差）。若 N 条件下人稿已不吃亏，则"朴素评委偏差"结论需收窄，后续改善解释也要相应降级。

### M2 分离度改善（N → V31 → V4）
- V31 排名用其 JSON 的重点参考价值排名；V4 排名 = A 档优先、同档比 A 分总分（A 通道为主，因专家场景即快读）。
- 成功口径（抄自实验设计，不改）：**留出集上人稿中位排名显著优于条件 N**；方向 N→V31→V4 单调改善为强成功，V4 优于 N 为最低成功。

### M3 同题成对胜率（PW）
- 每对 ×3 评委 ×2 问题 = 30 个二选一。分别统计 Q1（重点参考）与 Q2（可报送）的人稿胜率。
- 成功口径：Q1 人稿胜率 ≥ 2/3。Q2 无预设（人稿时效旧，可报送输是合法结果——这正是双通道要分开的理由）。
- 同时算 V4 判档与 PW 的一致性：对每对，V4 组合档（A 优先）预测的胜者与 PW Q1 多数票胜者一致的比例。

### M4 设计集回测（J16–J19，档位锚）
- 稳定锚（P4 修正后口径）：**D05(E) A 档最高**；D03(C)、D04(D) 不低于 D02(B)；D01(A) 只记录不设预期。
- A 通道预期：D03/D04/D05 → A1，D02 → A2 或给出"为什么不如 E"的实质理由（理由中须点出空心/表演处才算过）。
- **E vs B 试金石**：若评委给 D02 ≥ D05 且理由是"要素齐全/结构完整"类，判 V4 失败于机制1（Goodhart）。

### M5 评委间信度
- 同条件 3 评委：档位完全一致率（目标 ≥2/3）；排名 Spearman ρ（目标均值 ≥0.6，报告即可不设硬门）。

### M6 检测与偏好分离（附加题数据，探索性但预先声明）
- 每评委的来源猜测准确率 vs 其排名偏向：
  - 猜不准 + 偏 AI → 偏差在判据（rubric 形状）；
  - 猜得准 + 仍偏 AI → 偏差在效用函数（评委口味）；
  - 猜得准 + 不偏 → 该条件已矫正。

### M7 反 Goodhart（第二波，W2 之后）
- 应试稿混入小盲测集重评：应试稿的 V4 判档不应压过同集人稿中位（口径：A 档不高于人稿组最高 A 档，或 B 通道被预检单/表演判定标记）。
- 若被攻破：记录攻破手法 → 提机械防御建议（只记录，不改代码）。

## 4. 归因分析（定性，跟随定量之后）

- 对每个"人稿被压低"的案例：抽评委扣分理由原文，对照 P1–P3 已证伪判据清单，标注该理由属于四机制中哪一层。
- 对每个"AI 稿被抬高"的案例：对照预检单表演指标，检查评委是否把显性完整当实质。
- 输出：机制 × 条件的命中矩阵（哪些机制被 V4 修掉了、哪些还在）。
