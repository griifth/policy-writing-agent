# 标尺 N（基线）

对每篇稿件按以下六个维度打分（各 0–10 分），给出总分（60 满分），最后对全部稿件按总分从高到低排名（同分强制排序，说明理由）。

| 维度 | 判准 |
|---|---|
| 结构完整 | 章节层次清楚，开头—主体—建议完整 |
| 论证清晰 | 观点与材料的关系明确，推理连贯 |
| 材料丰富 | 事实、数据、案例的覆盖面与充分度 |
| 语言正式 | 符合公文/研究报告的正式书面语 |
| 建议可操作 | 建议具体、可执行 |
| 整体可提交 | 综合印象：这篇作为政策研究报告可否提交 |

每篇输出：六维分数 + 总分 + 两句话总评（须各引原文一处，引文 ≤30 字）。
