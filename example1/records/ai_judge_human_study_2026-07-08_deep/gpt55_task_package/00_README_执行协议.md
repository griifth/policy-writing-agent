## 一句话说明

本包共 **19 个第一波任务**（tasks/J01–J19）+ **1 个第二波任务**（tasks/W2_01）。每个任务文件都是自包含的：把**单个任务文件的全文**作为唯一指令交给一个**全新的 GPT-5.5 会话**执行即可。任务之间禁止共享上下文。

## 操作步骤（给派单人）

1. 第一波：J01–J19 可以任意顺序、可并行派发。每个任务 = 一个全新 GPT-5.5 会话（不能复用会话，评委之间不能互相看见）。
2. 每个任务完成的标志：在 `results/` 下出现该任务指定的结果文件，且文件末尾有合法 JSON 块。缺 JSON 或缺引文的结果视为无效，重派一个新会话重做（不要让原会话修补）。
3. 第一波 19 个结果全部落盘后，再派 W2_01（应试写手）。W2 产物交回给 Fable 5，由 Fable 5 构造第二轮盲测集后再出第二波评审任务。
4. 全部完成后叫醒 Fable 5 做揭盲与分析（分析程序见 `02_分析计划_预注册.md`）。

## 防泄漏铁律（每个任务文件里也有，这里是总纲)

- 执行者**只准读取任务文件中明确列出的文件路径**，禁止浏览仓库其他任何文件/目录。
- 特别是：任何路径含 `_label_map`、`_normalize`、`agent_notes`、`工作日志`、`实验设计`、`最终结论`、`评审割裂`、`人类稿优势` 字样的文件，读了即整场作废。
- 禁止联网检索稿件文本、禁止运行任何脚本、禁止读 git 历史。
- 评委不知道稿件的人写/AI 构成比例；对来源的任何猜测**不得影响评分**（每个任务最后有独立的"来源猜测"附加题，在评分锁定后才填，且不得回改评分）。
