### A1. 句长：修正"长短错落"假设

《评审割裂诊断》机制4曾把人稿节奏概括为"长短错落"。**句长层面这个假设不成立**：两组句长 CV 完全相同（0.55 vs 0.54），短句占比也相同。真正的差异在两处：

- **超长句占比**：AI 稿 >60 字句占 38.8%（run0626 高达 56.4%，A稿 51.8%），人稿 29.3%。AI 的典型模式是用分号和顿号把一段材料焊成一个 80-150 字巨句。
- **段落更长**：AI 段均 185 字 vs 人稿 142 字（A稿达 306 字/段）。人稿"错落感"其实是**段落级**的：短段（H-竞争法案段均仅75字）与长段交替，而非句子级。

→ 给评委的含义：叫 LLM"检查句长节奏"没用；应检查"超长句占比"和"段落收束方式"（见A8）。

### A2. 显性元话语：4.5 倍差，且**专家最盛赞的人稿为零**

词表（宣告类）：总体来看/总体而言/整体来看/综上/综观/纵观/可概括为/可归纳为/可分为/呈现出/这表明/这意味着/由此可见/换言之/本文/本报告/本章/值得注意的是/值得关注的是/需要指出/其核心特征是/共性在于/比较而言/据此……（全表见脚本 `META_ANNOUNCE`）。

- 组均：人稿 0.34/千字，AI 1.55/千字。
- **单篇更狠**：E稿、H-超常、H-竞争法案的宣告类元话语为 **0.00/千字**，段首显性元话语占比 **0.0%** ——恰是判断力最被人类专家认可的三篇。
- AI 命中词分布暴露"论文腔"：`本章`（8次，全部来自引擎run）、`本文`（7次）、`核心特征是`（6次）、`共性在于`（3次）——人稿 8 篇中"本章"出现 0 次。
- 反向验证：**衔接对举类**（与此同时/一方面…另一方面/此外）两组无差（0.89 vs 0.80）。差的不是"用不用连接词"，而是**"要不要向读者宣告我正在总结/我有类型学"**。

### A3. 类型化命名：AI 密度 3.4-4.4 倍，且命名形态不同

- 领起句（"第X类是/三大/呈现X个/分为X类"）：人稿 0.25/千字 vs AI 0.86/千字。
- 自造"X型"词（排除典型/大型/模型等日常词）：人稿仅 C 稿一篇贡献了全部命名（双重规划型/综合规划型/项目驱动型/专设机构型/多机构协同型/委托执行型），其余 7 篇为 0；AI 六篇篇篇有，且形态升级为**复合连字符命名**："强动员-公私合营型""立法约束-软性协调型""实用赋能-监管红线型"（run0706-193854）、"专综并进型"（A稿）、"公共服务敏捷应用型""全球伦理规范引领型"（run0706-095808）。
- 判别要点：C 稿证明"类型化命名"本身是合法人类手法（这正是引擎学的母本）；**AI 化的信号是密度（每章一套新类型学）+ 连字符双轴复合名 + 类型名不落回文件/机构**。C 稿每个型名下都垫着具体政策文件与脚注；run 稿的"强动员-公私合营型"是评估性概括，无文件可核。

### A4. 四字格：方向确认，人稿更"官笔"

词表法人稿 1.39 vs AI 0.25/千字（有词表偏置，只看方向）；中性度更高的"四字并列对"（`X X X X、Y Y Y Y`）人稿 8.68 vs AI 6.87。更有信息量的是**命中词的质地**：

- 人稿命中：一脉相承、一举奠定、迫在眉睫、急起直追、雷霆手段、绣花功夫、喜闻乐见、千方百计、野心勃勃、现出原形——**有情绪温度、有典故、敢用带锋芒的词**。
- AI 命中：稳慎有序、多元投入、精准施策、分类施策、互为支撑——全部是**去风险化的政策套语**，无一有温度。

→ AI 稿不是"不会用四字格"，是只敢用安全的那一半。这与语域红线训练（register blacklist）方向一致，但副作用是文字失去"作者在场感"。

### A5. 数字：密度完全持平（8.7 vs 8.8/千字）——差异在嵌入方式

这是本轮最重要的**阴性结果**：任何"数一数精确数字"的评委指令都无法区分两组。对 `P1_number_sentences_sample.csv` 48 句抽样人工判读后，数字用法可分三型：

1. **阈值/资格/罚则型**（数字本身是政策机制的可核单元）——人稿主导。例：
   - "大学在一年内收到外国经费超过10万美元或在3年内超过25万美元，需作出说明"（H-竞争法案）
   - "学校售卖校服所得利润不得超过向供应商购货成本价的15%"（H-校服）
   - "按重量计乳含量至少为90%……240毫升调味奶添加糖含量不得超过10克"（H-奶）
   - "苏格兰政府自2018年起引入全国最低校服补助标准，金额为100英镑……七年级学生还可额外申请200英镑"（H-校服）
2. **框架计数型**（"六项原则""四类群体""十九项能力""三大支柱"——数的是文件目录）——AI 稿偏多（A稿的数字几乎全是此型+文件年份）。
3. **绩效卖点型**（数字修饰效果宣称）——AI 特有倾向："AI工具准确率从67%提升至92%"这枚数字在**三个 run 里复现≥4次**（run0706-193854 两处、run0706-095808、run0626 各一处），是引擎的"旗舰数字"；同类还有"动员逾10亿美元公私合作资源""超过200家机构签署承诺"。人类审稿人对这类数字的本能是起疑（会议对D稿的反应），LLM 评委却按"有数字=有证据"给分。
   - 注意 B、D 稿在第1型上已接近人稿（B："2.5万个STEM本科奖学金、5000个博士奖学金和500个博士后职位"与E稿同源；D："75家学习成果认证分中心""447个X证书目录""500新元基础额度+4000新元充值"）——这正是 D 获专家好评的文笔基础之一。

### A6. 段落与列表：结构比例无差

编号领起段占比两组几乎相同（41.7% vs 41.0%）——"是否用一是二是/（一）（二）"完全不能判别。这否定了"AI 更爱列条"的直觉；内参体本身就是高列表密度文体，AI 学得很像。

### A7. 判断的表达位置：人稿判断不在段首宣告

段首40字内含显性元话语的段落占比：人稿 6.3%（E、H-超常、H-竞争法案为 0%），AI 17.6%（run0626 达 33.3%）。人稿组内的最高值恰是 C 稿（21.6%）——**人稿里最"AI型"的表达者正是被选为金样本、被引擎模仿的 C**。这给机制4"评委即选手"补了一条闭环证据：评分尺由 C 锚定 → 引擎按 C 的显性化路数生产 → 评委（同分布）更亲和这种显性化 → 不显性化的 E/超常/竞争法案系统性吃亏。

### A8. 两个"绝对分离器"（本样本 0 vs 非 0）

1. **链式公式**（`A—B—C` / `A→B→C` / pandoc残留 `A---B---C`，汉字段间夹箭头或破折号连成≥3节）：人稿 8 篇合计 **0 次**；AI 6 篇合计 19 次（篇均3.2）。样例："培养---吸引---占位---统筹"（B稿）、"扫描—试点—扩展"（三个run反复出现）、"标准定义→实施赋能→底线保障""法律强制—监管红线—定向投入—文化嵌入"（run0706-193854）、"遴选---授权---监督---退出"（D稿）。人稿表达同类意思时用动词句："与1958年《国防教育法》相比……从高等教育**延伸到**基础教育，从国内人才培养**延伸到**全球人才争夺"（E稿）——机制装在动词里而非破折号里。
2. **评估脚手架短语**（优势在于/局限在于/对我国而言/参考价值/其核心特征是/需警惕/应对之策/制度前提…全表见脚本 `SCAFF`）：人稿 **0/千字**，AI 1.26/千字（43次）。这是 rubric 反噬的直接指纹：引擎每节末尾都长出一段"比较评估：其优势在于X；局限在于Y；对我国而言Z"（run0706-193854 四个国别节全部如此），是**向评分表逐维交作业**的形态。

## B. 定性发现（引例均注明出处）

### B1. 人稿的"判断藏在哪"——七个例子

判断不用判断句表达，LLM 评委因此读不出来：

1. **藏在计数式选材里**。E稿开篇："以中国为'假想敌'进行人工智能人才竞争（**全文提及'中国'达500多次**）"（中美AI人才竞争及应对策略.md）。"500多次"是作者数出来的——数这个数的动作本身就是"美方战略指向性明确、此事紧急"的研判。无一个观点词，判断全在括号里。LLM 评委看到的只是"一个事实"，识别不出"选择去数这个数"是判断行为。
2. **藏在史料对照的选择里**。E稿第二节整节讲1958年《国防教育法》"十条52款……1960年财政经费是1958年的十四倍"，节题只有八个字"教育改革关乎国家安全"。拿冷战立法给今日法案定性，是全文最重的战略判断，但形式上是一段历史介绍——评委常把它读成"背景过长"（human_corpus_analysis.md 特征5已指出，本处补句级证据）。
3. **藏在自造对仗概念里**。H-竞争法案："与'经济脱钩'相比，'教育脱钩'的烈度较低，但影响极大"（警惕美竞争法案对我教育战略带来的重大风险.md）。"教育脱钩"是作者造的词，一个词完成了议题升格；没有"本文提出XX概念"的宣告。
4. **藏在比喻的选择里**。H-课后："课后服务成为影响'双减'工作的'**牛鼻子**'问题……'雷霆手段'过后，还需以'绣花功夫'跟进"（从国际经验中优化课后服务推动双减政策落地.md）。优先级判断（抓哪件事）和阶段判断（治理进入第二期）全部由比喻承担。
5. **藏在顺手一句的甄别里**。C稿："不过该政策文件虽名为'框架'，但仅就生成式AI在学校教育中的使用原则做出了规范，**严格意义上不能看作为政策规划**"（人工智能+教育国际比较报告.md）。对材料的降级处理埋在国别介绍中间，不设"需要甄别的是"之类路标。
6. **藏在算术里**。H-校服："实际费用是家长认为合理费用的**三倍以上**"（中小学校服治理国际比较.md）。"三倍"是作者算的，结论（费用失控）由除法给出。
7. **藏在清单中途的评价插语里**。H-奶："瑞典对7—16岁义务教育阶段儿童免费提供牛奶，**是将欧盟牛奶补贴运用最到位的国家之一**"（国外学生饮用奶相关政策及实施路径.md）。全文最强的评价性判断（"最到位"）出现在覆盖范围罗列的第七项里，不在总结段。
8. 兜底的直球式判断也存在，但形态是**领导语体**而非论文语体：H-超常："这个问题处理不好，**极有可能会导致改革探索的起伏甚至中断**"（主要国家将超常儿童培养上升为国家战略.md）——句子押的是作者个人信用，没有证据脚手架。

**为什么 LLM 评委读不出来**：这些判断没有词汇签名（无"研判/表明/可见"），识别它们需要两种 LLM 缺失的资源——(a) 领域先验（知道"数500次""引1958年法"在内参语用里等于最高强度示警）；(b) 对"选材机会成本"的感知（知道作者放弃了什么才写了这个）。评委按 token 表面找观点，只能找到宣告句；于是把判断最密的 E 式文本读成"材料堆砌、观点不亮"。

### B2. 人稿的节奏与松弛感——"AI 不会这么写"的句型

1. **不完美排比开篇**："有一流的教育，才有一流的人才，建设一流的国家。"（H-超常，首句）——第三分句语法上悬空（缺"才能"），但口号的顿挫是对的。AI 的语法洁癖会把它抹平成"才能建设一流的国家"。
2. **八字压缩句**："国情不同具体运转不一。"（H-超常，"一是成立专门机构"段）——文言节奏的行政速记体，主语、连词全省。
3. **口语动词入公文**："《竞争法案》挑明要给媒体'**打钱**'"、"让'**带路党**'现出原形"、"利用显示IP地址、勾勒数字画像等方式"（H-竞争法案）——"打钱""带路党"是网络口语，出现在报送文本里是作者对读者（决策层）语感的自信。AI 的语域安全训练永远不会生成"带路党"。
4. **谚语式收束**："超常儿童培养不是唯一的教育模式，**适合的教育才是最好的教育**。"（H-超常）——用大白话格言收住一段政策论证，零术语。
5. **动词叠用**："把课后服务**做实做好**"、"'组合拳'连环出击"（H-课后）——行政口语的肌肉记忆。
6. **真实的粗糙**："终身学习研究所**会发表了**一些全球和区域性的研究报告"（2016-2020年国际终身教育改革发展趋势.md）——语法错误原样发表；"不能看作为政策规划"（C稿）的"看作为"也微别扭。已发表人稿容忍这种毛边，因为编辑链关注的是判断和材料。**这类毛边在 LLM 评委那里全是扣分项，在人类终审那里几乎不可见。**

### B3. AI 稿的"表演性文笔"清单（向评分表演的句式）

按危害排序（危害=诱使评委给"判断力"加分而实际无判断增量）：

1. **链式公式**（A8）："培养---吸引---占位---统筹"四线布局（文章B美国AI人才战略布局及我国应对策略.md）；"扫描—试点—扩展"（run0626、run0706-095808、A稿三处复现——已成引擎口头禅）。表演点：把过程压成箭头链，制造"我已提炼出机制"的观感，但链节点常常只是段落小标题的复读。
2. **每节一段"比较评估"模板**："其优势在于资源整合范围广、动员速度快；局限在于……对我国而言……"（run0706-193854，四国别节逐节复制）。表演点：对着 rubric 的"批判性/借鉴性"维度逐格填空。
3. **段末概括性收束句成瘾**：A稿一节之内连用四枚："可见，各方均把'人对机器的最终否决权'作为……前置条件""各方的共同落点，是……""三方的一致取向，是……""综观四类做法，其内在逻辑一致：……"（文章A人工智能+教育国际政策比较报告_.md 第一章二节）。人稿段落大多**以事实收尾**（E稿建议段直接停在"在全球范围内吸引人才"）。
4. **论文导语句**："本章从能力目标分层、课程承载与教师制度协同三个维度，比较各国……的实现路径"（A稿）；"本章依次分析上述三类模式的核心机制、典型实践与制度特征"（run0706-095808）。"本章"在人稿 8 篇中出现 0 次——内参没有"章"。
5. **功能标注句**："这一安排的功能，是从教育源头扩大顶尖人才供给"（B稿）；"这一速度差异的制度原因在于：……"（run0706-193854）。给自己刚写的事实贴机制标签，判断增量为零但观感"深刻"。
6. **复合连字符类型学**（A3）："强动员-公私合营型""立法约束-软性协调型"——双轴压缩命名是引擎新特产，人稿（含C）从未用连字符造型名。
7. **辩证对仗表演**："一放一收之间，美方既向全球敞开顶尖人才入口，又收紧竞争对手的人才回流与合作渠道"（B稿）。这句本身写得不坏——问题是此类"既X又Y""不是A而是B"句在 AI 稿中的密度（D稿首段一句话内就有"不是彼此孤立的政策事件，而是……的明确标志"+"这既是结构性压力……也是建构性机会"两连）。
8. **风险尾巴仪式化**：D稿九条建议每条以"须防范/需警惕/不得突破"收尾——单看是纪律，连看是模板。
9. **旗舰数字复用**："准确率从67%提升至92%"跨 run 复现4次（A5）——同一枚亮点数字被当万能证据反复押注。

### B4. D 稿对照：为什么"AI 腔"没有毁掉它

D稿（文章D国际终身教育趋势研判报告.md）在所有表层指标上都是 **AI 组里最像人稿的**：句长均值 43.5（AI组最短、低于人稿均值）；元话语 0.62/千字（AI组最低，接近人稿C）；段首显性元话语 2.4%（人稿水平）；链式公式仅2处。但它仍有明确 AI 签名：链式公式、"这表明……已从附加福利转变为制度的基础性功能部件"式功能标注句、"四大支柱/三条主线"类型学、成熟度分档（"扩散中/已制度化"）。

它获专家好评的文笔原因可以拆成三条：

1. **数字长在机制上**（A5第1型）："75家学习成果认证分中心""447个X证书目录进行'微证书化'改造""500新元基础额度+40岁以上追加4000新元"——每个数字都是可核的制度部件，不是绩效卖点。
2. **有真甄别句**："对于证据尚弱的'萌芽信号'，如美国部分州推行的免费社区大学项目……**应降级为局部探索，不宜视为可复制的主流路径**"；"日本虽早在1988年即设立终身学习局……但受限于经费投入规模……**这警示，立法和机构设立是必要条件而非充分条件**"。这是 C 稿"严格意义上不能看作为政策规划"的同款动作。
3. **建议有主体和边界**："由国家开放大学牵头""防止引发'即将发钱'的舆情误读""避免重蹈日本'有机构无实效'的覆辙"。

**结论：某些"AI腔"确实无害**。类型化命名、成熟度分档、风险尾巴——只要下面垫着机构/金额/条款并且密度收敛，专家照样买账。有害的不是标记本身，而是**标记/证据比**：A 稿和 run 稿的问题是每千字 1.5 个宣告 + 3 条箭头链，而链下的可核单元密度没有跟上。评委判据应从"有没有AI句式"改为"句式下面有没有货"。

### B5. OCR/格式噪声清单（匿名化盲测前必须处理）

人稿噪声（区别于作者文笔）：

1. **引号被拍平**：人稿弯引号全部变直引号 `"`（E稿24处直引号、0处弯引号）。
2. **粗体断裂**：`四**是强调透明、可解释与问责机制。**`（C稿47行，星号切错位置）。
3. **衍字/叠字**："对学校访问、收集、存储和使用个人**数据据**提出了具体要求"（C稿43行）；"将**师生素AI素养**培育纳入"（C稿55行）。
4. **标题变引用块**：E稿小节题被OCR成 `> 一、主要措施`。
5. **文件头残留**：`FILE_NAME: 2016-2020年国际终身教育改革发展趋势.md` + `---` 分隔线（H-终身）。
6. **疑似原作者笔误而非OCR**（不要"修复"，这是人味的一部分）："会发表了一些"（H-终身）、"不能看作为"（C稿）。

AI稿噪声（同样会泄漏组别）：

1. **pandoc 三连杠**：`---` 作破折号（A稿6处、B稿7处、D稿14处；人稿正文0处）——**单这一项即可100%分类盲测集**。
2. **pandoc 硬换行吞空格**：`AustralianFramework for ... inSchools`、`SkillsFutureCredit`（A、D稿）。
3. **转义引号**：`\"资金跟着需求走\"`（D稿）。
4. **run稿与盲测稿标点制式不同**：run 用弯引号“ ”+全角—+箭头→；extracted_samples 用直引号+`---`。若混入同一盲测集，标点制式本身就是标签。
5. run0626 正文夹带**来源占位符**：`[The White House. 2_Advancing_AI_Education_American_Youth_2025.pdf]`——非文笔，剔除或统一。

**盲测归一化建议**：统一引号为弯引号、`---`→"——"、修复吞空格、去 FILE_NAME/引用块标题/占位符引用，但**保留**人稿的语法毛边与AI稿的句式（那是被测对象本身）。

## C. 评委可操作判据清单

### ① 可正则/程序检测（建议进 score_article.py 前置机检）

| 判据 | 方向 | 本样本效力 |
|---|---|---|
| 链式公式 `汉字(—/→/---)汉字(—/→/---)汉字` ≥3节 | 命中≥2次 → AI腔警报 | 0 vs 3.2/篇，完全分离 |
| 评估脚手架词表（优势在于/局限在于/对我国而言/参考价值/其核心特征是…） | 密度>0.5/千字 → 表演警报 | 0 vs 1.26/千字，完全分离 |
| "本章/本文/本报告 + 从…维度/依次/围绕" 论文导语 | 内参体中出现即扣 | 0 vs 15次 |
| 显性元话语词表密度 | >1.0/千字 警报 | 0.34 vs 1.55 |
| 段首40字内元话语占比 | >15% 警报 | 6.3% vs 17.6% |
| 自造"X型"密度 + 连字符复合型名（`X-Y型`） | 连字符型名出现即AI签名 | 人稿0 |
| >60字超长句占比 | >45% 警报 | 29% vs 39%（run0626 56%） |

### ② LLM 可判但需明确指令（写进 rubric 锚定）

1. **隐性判断识别**：指令改为"列出本文通过**选材、排序、计数、算术、比喻、插语**表达而未用判断词宣告的判断，至少找3处；找不到才允许在'判断力'维度扣分"。（对应B1；防止E式文本被判"无观点"）
2. **数字三型分类**：要求评委把每个关键数字标注为 阈值/资格/罚则型、框架计数型、绩效卖点型；判断力得分只认第一型，第三型数量多反而触发可信度核查。（对应A5）
3. **类型名落地核查**："每个类型名下，是否能指出≥2个具体文件名/机构名/金额支撑？"C稿式命名过，run稿式命名不过。（对应A3）
4. **段落收束方式**："以概括句收束的段落占比"高不加分；以事实/条款收束不扣分。（对应B3-3）
5. **甄别句检测（正向）**："找出对材料降级、限定、存疑的句子"（如"严格意义上不能看作""应降级为局部探索"）——有则加分。（对应B4-2）

### ③ LLM 难判、必须留给人工

1. **语域词的资产/负债判定**："带路党""打钱""绞杀"在直报体里是锋芒还是事故，取决于报送渠道与时点——LLM 无报送后果模型。
2. **精确数字的可信度直觉**："每年服务至少38天""2.5亿美元团队奖"式数字是否有编造感，需要域外经验核查本能。
3. **松弛句的真伪**：分布亲和使 LLM 系统性把人味毛边读成粗糙（机制4）；换判官模型只能缓解，不能消除——1档认定权按 F5 留人工。
4. **历史镜鉴段的解释力**（1958年法案那一节值多少分）——需要战略语用先验。
