# 元模块契约（装配式工作流·图纸之二）

> 2026-07-12。上游图纸：`records/元框架提炼_2026-07-12/元框架.md`（槽位族谱，已验收：5/5 引文独立回源、封闭词表零溢出）。
> 契约的用法：调度智能体每接一篇，按契约＋本篇结构单＋方向书**现场生成**各模块的实体提示词。契约只定边界，不含成品提示词——实体化是装配工的活。
> 通用禁令（四模块共守）：不得出现任何评分维度/档位/分数；不得注入文风规则（风格不限制系会议决议）；实体提示词必须引用其激活槽位的"替读者回答什么问题"原文，引不出即违宪。

## 契约① 检索元模块

**职责**：按本篇结构单的**主线段缺口与**槽位缺口找料——不是"检索这个主题"，是"为**铁三角三段（表现／归因／建议）**里的这些槽位找到能回答其问题的料"。**归因段的料型随判型走（见下"检索计划"）。**〔2026-07-15 主线架构修订〕

**两种实体**：
- **侦察实体**（服务触点一）：输入＝裸主题；产出＝态势速览一页（四栏＋逐栏逃生口）；分钟级。**其候选研究问题所附"候选判型证据"由态势速览模板承载，供触点一判型点选对称呈现，检索职责不因此扩张（不替用户判型）。**
- **全量实体**（服务立论与组材）：输入＝方向书＋本篇结构单**（含判型＋主线段-节问题链）**；产出＝二段式料包（沿用现有 retrieval_outputs 契约），**检索计划先按主线段加权、段内再按激活槽位细化**：
  - **表现段**（定调／引题／溯源槽）：要**我国这个问题目前的现状料与问题料**——是什么状况、卡在哪、有多严重；`溯源`槽要概念史与文件谱系（校准"是什么"）；
  - **归因段·按判型定料型**（铺态势／分型／举证／提炼／数据锚／研判／预警[威胁映射用法]槽）：**③④型**要国际机制料／立法料（③提炼底层机制、④国外立法核心原则；`举证`槽仍要机制/条款级细节，`数据锚`槽要硬数字与比较表）；**①型**要落地博弈料（执行机构考核压力／目标群体消极应对／制度掣肘的利益相关者博弈证据）；**⑤型**要趋势料／情景料（技术成熟度、拐点、乐观/悲观情景推演所需材料）；**②型**要满意度鸿沟／认知错位料；**⑥型**要利益阻力料；其余按元框架 v2 第三章各型"归因段核心任务"取料。**归因须是政策问题归因——"国际现象成因"属现象归因、不作归因段料。**
  - **建议段**（对照中国／给建议／预警[建议性用法]槽）：要**我方制度现状料**（`对照中国`槽开启时的本土制度谱系与落点，供建议前置锚）。

**质量底线**：溯源纪律不打折（每条料带可查来源，T1/T2 分级沿用）；侦察实体分歧轴两端中立对称；方向书禁区剪枝**但反证不剪**——打倾向箭头的料必须保留入包并标记。

**注入点**：topic-material-search-v2（两种模式）；元框架槽位定义。

**禁止**：为凑槽位编造料；把禁区剪枝扩大成反证过滤。

## 契约② 构思元模块（立论）

**职责**：在方向锥体内立观点、提结构——判断密度的主要生产工序。

**输入**：方向书＋料包＋本篇结构单**（含结构单主线：判型＋主线段-节问题链）**。〔2026-07-15 主线架构修订〕
**产出**（两件，都停在触点二等人勾选）：
1. **观点清单**：约 10 行，每行＝可错的明确判断句＋一句证据摘要＋拟落槽位＋**主线地址（回答第几节的问题）**＋置信度。**观点带地址出生，并按主线段（表现／归因／建议）分组呈现，某段空置或富余一眼可见。**
2. **段内详略与可选模块触发建议**（原"结构提案"收缩）：全文骨架（主线序、各节问题）**已由触点一判型前置决定、落结构单，立论不再提案结构主体**；本项只提两件——(a) **段内详略权重**（每一主线段内已勾候选观点谁详谁略，载体③排序即判断收窄到段内）；(b) **可选模块触发建议**（可行性研判／窗口期研判／资源成本测算／协同路线图四模块，逐一给"触发/不触发＋一句理由"，触发条件见元框架 v2 第五章）。**落地开关开合的显式决定与理由移至结构单实例化环节（目标产物为决策咨询报告，默认开）；立论若判断本篇宜关某开关，附理由回写结构单 diff（沿宪法§二"结构单可中途修订，落盘 diff＋理由"），不再按 v1-A/v1-B 旧默认规则在此提案。**

**质量底线**：每个观点落在方向锥体内（回溯方向书栏目）；每个观点挂料包证据；**归因段观点按型定路数（按型出题规则）——①走博弈归因、②走认知错位、③走机制抽象/量化比强度、④走立法逻辑、⑤走压力推演、⑥走利益阻力（元框架 v2 第三章归因段核心任务；混合类③④两色并出不硬选）；归因段只收"政策问题归因"，"国际现象成因"不作归因段观点（现象归因出局）**；若用`分型`槽，每个类型必须对应读者的一个拍板选项（元框架载体①的判断形态，非综述分类）；`提炼`槽观点用"主要国家普遍……"式主题句形态（载体⑥）。

**注入点**：yongjun-thinking skill（生成式提问：这条给谁拍板？他的层级够不够动这件事？分几类才成决策菜单？）；元框架载体①③⑥；方向书半成形直觉栏（有则优先转译为候选观点）。**并注入"司局级可读"硬约束（实体化时整段随实体提示词下发）：**

```text
【语言硬约束·司局级可读（立论）】
1. 每条观点须以司局级领导能一遍读懂为准：用常规政策语言，不用生造复合词、不用学术黑话。
2. 生造词零容忍：凡"未见于公开政策文本的自造复合词"（如"加速的收益边界""下行风险""两张全向地图""落条款级""标准悬空"）一律不得出现；确有含义、无可替代的专门表述至多保留一个，并须在该处一句话点破其含义。
3. 内部术语不外漏：本工作流内部概念（研判主轴、主线、槽位、判型、铁三角、锥体、元框架、骨架卡、落地开关、触点、勾选率、装配工、边角料箱、来源锚、预读提词单、结构单、论证结构单、可选模块、问答链）与学术模型名（史密斯模型、CIPP、期望-绩效差距、利益相关者分析、Policy Transfer、地平线扫描、德尔菲法、情景规划、政策生命周期理论 等）严禁写入观点判断句——它们只用于内部谋篇，不入观点文本。国际测评项目/数据源名（PISA、TALIS、TIMSS 等）可作数据锚引用：首次出现给全称＋一句白话，不得作分析框架术语裸用（2026-07-16 DEV-06 裁定）。
4. 判断句用规范措辞承载力度（应当/宜/不宜/须/不应），不用标签口号，不堆术语。
5. 归因类观点禁用"万能归因"：不得以"领导重视不够""投入不足""体制机制不完善"等放之四海皆准的表述充当归因，须指向可指认的结构性根源（体制/机制/利益）（0716b 增补）。
```

**执行引擎**：生产环境 DeepSeek（经 engine/run_entity.py）；试跑/测试可 agent 直写，须在台账标注执行引擎。

**禁止**：观点清单未经人勾选直接进写作；给观点打分排序（只标置信度）；锥体外夹带。

## 契约②.5 观点逻辑确认元模块（2026-07-15 主线架构迭代增）

**职责**：在触点二已勾观点与结构单之间加一步**观点逻辑关系确认**——把已勾散装观点按主线归并、定序、承接、映射，产出《论证结构单》。**只理逻辑关系，不立论、不改方向、不新增观点、不打分。**

**输入**：触点二已勾观点清单＋本篇结构单（判型＋主线段-节问题链＋铁三角覆盖轴）。

**产出**：《论证结构单》（落 `runs/<id>/outputs/论证结构单.md`），六件：
1. **归并表（一节一问题）**：同一问题下的观点合并为一节，一节只回答一个问题（把"现状+问题"这类相近点并类，取代同一问题散成多节）；
2. **定位定序**：每条观点认领其主线地址、全篇标题序＝主线序（表现→归因→建议）；
3. **段间承接语**：逐节写"继承什么（段首接上节交出的结论/悬念）／交出什么（段尾抛下节要回答的问题）"；
4. **建议↔归因映射（一因一策）**：每条建议标注回应哪一条归因，缺映射的建议或悬空的归因显式列出；
5. **缺口清单**：哪一主线段空置、哪一节缺料/缺归因/缺建议，逐条列；
6. **离线出清表**：好但不在主线链上的观点，登记移入边角料箱备查（主线向外即边界）。

**自动 pass 规则**：本工序**默认可自动通过**——代理（子代理）预演即自动 pass，产物照落盘，**不构成新增强制触点**（触点仍只有触点一方向书签字、触点二观点勾选两处）。仅当缺口清单命中"缺段"时才转回炉（见下），否则直通契约③。

**回炉规则**：缺口清单出现"某主线段空置/某节缺归因或缺建议"时——**插补立论一次**（沿宪法§二自由度"立论或写作中发现料不够，可插补一次检索；任何模块可重跑[新实体]"机制，扩展为可插补一次立论/检索重跑），落盘 diff＋理由；插补后仍缺段→带缺口清单**停下叫人**，不硬写、不自造观点补段。

**执行引擎**：**调度 agent／子代理（代理预演），非 DeepSeek**（结构逻辑层工序，同契约⑤/⑦的 agent 层定位）；实体提示词头部标执行引擎字段，与台账对应。

**禁止**：以确认之名新增/反转观点；把现象归因当政策问题归因归并入归因段；给观点或节打分排序；静默出清主线内观点（出清须入离线出清表）。

## 契约③ 写作元模块（组材撰写）

**职责**：表达，不是立论——把已勾观点按结构单写成可采用的稿。

**输入**：已勾观点清单＋**《论证结构单》**＋结构单＋料包。〔2026-07-15 主线架构修订〕
**产出**：成稿＋边角料箱（正文未用的好料附文末）。

**输出形制（按撰写者采用场景定死）**：
- **标题顺序＝主线序**：全篇小标题按《论证结构单》定位定序排列（表现→归因→建议），不跳跃、不交叉穿插；
- 小标题＝已勾观点句（可润不可换意）；**一节只解决一个问题（一节一问题）**；
- 段首＝可直接引用的主张句；段身＝条款级证据带来源；
- **节间承接硬约束**：**每节段首接住上一节交出的结论/悬念（继承什么）、段尾抛出下一节要回答的问题（交出什么）**，形成"我国现状与问题→国际趋势/做法→我们面临的挑战→建议"不跳跃的叙事线；
- 每章反证栏：打本章观点的料摆出，附"修观点或接住它"一句话；
- **段落以事实收尾，不加概括尾巴**（人稿实态，P1 实证：AI 段末概括成瘾）；
- `给建议`槽开启时：**每条建议逐条标注回应哪一条归因（一因一策，可追溯映射，取代"陈述完观点再来一个笼统总建议"）**；每条主语层级 ≥ 方向书读者层级、主句用决定动词（载体⑤）、实操句取"动词＋宾语"结构（0716b），逐条回扣前文槽位（元框架依赖1：建议条数与结构由前文维度数决定）。

**质量底线**：全部小标题可逐条回溯已勾清单；每个事实带来源；元话语宣告克制（"本文/综上/呈现X大"类不作骨架）。

**注入点**：元框架各槽位的形态变体清单（装配工按篇选型）；cao-thinking（结构层：这条判断往上挂什么战略、往下落到哪级怎么改——生成式，不是三格检查）。**并注入"司局级可读"硬约束（实体化时整段随实体提示词下发）：**

```text
【语言硬约束·司局级可读（组稿）】
1. 成稿正文（含小标题、判断句、过渡句）以司局级领导能读懂为准，通篇不出现生造词与内部术语外漏。
2. 内部术语与学术模型名：成稿正文零命中（清单见契约②立论条款第3点）。归因所用的学术模型只用于内部组织思路，成稿只写其结论与机理的白话表述，不写模型名。
3. 交付件名分层：边角料箱、来源锚、预读提词单、论证结构单、需作者定夺清单等——作附件标题可用，正文散文严禁作为行文用词（如不得写"如边角料箱所示""按研判主轴…"）。
4. 已确诊外漏词"研判主轴"最高优先拦截：成稿任何位置不得出现。
5. 生造复合词按常规政策表述改写；确有含义无可替代者至多保留一个并当场点破含义。
6. 归因段禁用"万能归因"（同契约②立论条款第5点）；建议句须有操作主体＋"动词＋宾语"实操结构（如"成立……专项工作组""制定……管理办法"），避免"加强……工作""完善……机制"类无主体无宾语的空洞表述（0716b 增补）。
```

**执行引擎**：生产环境 DeepSeek（经 engine/run_entity.py）；试跑/测试可 agent 直写，须在台账标注执行引擎。

**禁止**：夹带未勾观点；替换观点句语义；注入任何文风模板。

## 契约④ 审查元模块

**职责**：下限守门＋预读提词。**本模块内容已由前期决议定死，不留装配自由度**（防评分器复辟）。

**输入**：成稿＋方向书＋已勾清单＋**《论证结构单》＋结构单**＋料包＋机械预检单。〔2026-07-15 主线架构修订〕
**产出**：闸门报告（逐闸过/不过＋违例清单）＋预读提词单。

**四道闸（全部机械可查，无裁量；称谓与道数不变，原样必跑）**：
1. 溯源闸：零编造，逐事实可回源；
2. 承重闸：段首判断句删掉其下证据必须塌，塌不了＝装饰句下架；
3. 方向保真闸：全部小标题回溯方向书＋已勾清单，锥体外＝夹带打回；
4. 语域预检：H3 机械执行（军事化命中≥3 封顶），**未过线不得在语域上重罚**（T02 教训）；**增补"生造词模式＋内部词表扫描"作为并列扫描项——走新建 `gates/lexicon_blacklist.md`（本工作流自有：生造词样例＋内部术语外漏＋学术模型名）独立扫描函数命中即出违例；军事化第5项照旧读军事化词表、逻辑原样、不放松、不合并。**

**主线保真检查（机械预检族新增项·非第五闸·全机械无裁量）**：与四道既有闸**并列**、同属机械预检族，只出违例清单、不打分、无裁量；**四道既有闸原样必跑，本项不改"四闸"称谓、不占闸序**。检查项（逐项出"齐/违例"，违例只列具体缺项）：
1. **每节挂段？**——每一节都归属某一主线段（表现／归因／建议），有无游离节；
2. **标题序＝结构单序？**——成稿标题顺序是否等于《论证结构单》定位定序（主线序）；
3. **建议↔归因映射齐全？**——每条建议是否标注了所回应的归因，有无悬空建议或无策归因；
4. **有无空段？**——铁三角三段有无整段空置（对照结构单铁三角覆盖轴缺项）；
5. **内部词表零命中？**——成稿正文对内部词/生造词/学术模型名零命中（词源即 `gates/lexicon_blacklist.md`，与闸4扫描同源）。
