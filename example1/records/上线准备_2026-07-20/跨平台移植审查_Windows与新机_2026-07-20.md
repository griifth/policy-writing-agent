# direction_workflow 跨平台移植审查（Windows / 另一台电脑）

> 审查日期：2026-07-20。对象：GitHub main 发布包（提交 0a7bb03）。方法：逐文件静态审查四个 Python 脚本的 I/O 与依赖、全部文档中的命令写法、文件名合法性、路径锚点逻辑。
> 仓库根旧文件 `WINDOWS_MIGRATION_CHECKLIST.md` 是针对旧引擎（workflow/、NotebookLM）的，**不适用于本包**，仅借鉴其规范（UTF-8 纪律、幂等、长路径）。

## 一、总结论

**移植到另一台 Mac/Linux：零代码改动**，按移植说明四步走即可（clone → pip install → 包上一级放 .env → 装 skill 换绝对路径）。

**移植到 Windows：代码同样零改动**——四个脚本的文件读写已全部显式 `encoding="utf-8"`（逐行核过 `open()`/`read_text`/`write_text` 共 10 处），路径全用 pathlib 相对定位，无 subprocess/os.system、无 POSIX 专属调用，文件名无 Windows 非法字符。需要改动的只有**文档命令写法与环境配置**，共 7 项（见第三节），已落成移植说明新增的「五、Windows 附注」。

**审查抓出 1 个真问题（与平台无关，所有新机都会踩）**：requirements.txt 漏了 `openai`——`engine/deepseek_client.py` 依赖 OpenAI-compatible SDK（`from openai import OpenAI`，try-import，客户端构造时缺库即报错），生产单必需。此前依赖文档误称"engine 纯标准库"。**已修正**：requirements.txt 补 `openai>=1.0`，依赖说明同步改（并把 Python 要求明确为 3.10+，engine 用了 `X | None` 语法）。

## 三、需要做的改动清单（全部已落实到包内文档）

1. **requirements.txt 补 `openai>=1.0`**（所有平台，生产单必需）——已改。
2. **依赖说明.md**：Python 明确 3.10+；依赖表补 openai——已改。
3. **移植说明.md 新增「五、Windows 附注」**，含 7 条：①`python3`→`python`；②控制台 `PYTHONUTF8=1`；③skill 安装 PowerShell 版（复制＋绝对路径替换）；④git 三项配置；⑤.env 位置不变（`C:\proj\.env` 例）；⑥GB2312 字体说明；⑦文件名合法性结论——已加。
4. **无任何代码改动**。

## 四、Windows 新机部署顺序（浓缩版）

```
1. git config 三项（longpaths/autocrlf/quotepath）→ git clone 到浅目录（如 C:\proj\）
2. 安装 Python 3.10–3.12 → pip install -r requirements.txt
3. （生产单）C:\proj\.env 写 DEEPSEEK_API_KEY
4. 按移植说明附注第3条装三个 skill 并替换绝对路径
5. 自检：python gates\precheck.py <任一md> ／ python -c "import docx, openai" ／ python engine\run_entity.py --help
```
