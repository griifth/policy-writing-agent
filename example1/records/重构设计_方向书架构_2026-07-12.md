# 重构设计记录：方向书架构（撰写者中心）

> 2026-07-12，用户与 Fable 5（马斯克视角 skill 辅助）的重构讨论收敛稿。地位：设计记录，未动代码。
> 前置证据链：盲测 v2 三轮结论（评委路线判死）、2026-07-03 会议（所长评稿原话）、职能梯度发现。

## 一、推导链（第一性原理，五步到位）

1. **政策报告的目的**：让有权者在三分钟注意力窗口里改变一个决定。报告价值 = P(被读) × P(改变决策) × 决策分量。核心功能三件：注意力压缩、**责任转移**（AI 永远给不了）、触发批示。
2. **本系统的真实客户**：不是部长、不是所长——是**报告撰写者**。产品是零件供应商，撰写者是主机厂：扫小标题和段首句，拆走能用的观点/材料/建议，装进自己签名的报告。责任链在撰写者处闭合。
3. **撰写者满意函数**：满意 = (自己干的时间 − 验证你的时间) × 信任 × 任务匹配度。满意机制 = **先共振再增量**（D 稿实证："跟我的经验的判断对上的，还有他的分析"）。杀手 = 一次编造（"一输出没用，他就不会再继续用了"——永军）。
4. **极性修正**：机器不替撰写者立观点全集，也不只做他的传声筒。分工 = **人给方向，机器立论，人勾观点，机器表达**。（用户拍板：撰写者手里有的是大体方向，不是成形观点；观点由系统写，但必须落在方向锥体内。）
5. **人的介入压缩到两触点九十秒**：定方向（1 分钟）＋认观点（30 秒）。其余全部机器。

## 二、新流水线

```
触点一 方向书（人，1分钟，点选为主）
  议题 ＋ 倾向箭头（警惕/借鉴/观望…）＋ 读者层级 ＋ 用途类型（借鉴/研判/追赶——永军三类型学）＋ 禁区 ＋（可选）半成形直觉
    ↓
检索 ＋ 机器立论（锥体内立观点；观点模具＝所长蒸馏产物：可错的明确判断／决定动词＋牵头主体／分类=拍板选项）
    ↓
触点二 观点清单（人，30秒）：十来行候选观点＋一句证据摘要，勾/叉/改
  —— 全流水线人力杠杆最高点：观点层拦错省一整篇废稿；勾选完成作者感与责任转移
  —— 机制复用：现成 --reviewer handoff 暂停-恢复，把暂停点从审查步挪到立论步
    ↓
组材撰写（机器）：小标题＝已勾观点句；段首＝可引用主张；段身＝条款级证据＋来源；反证栏（打观点的材料必须摆出，注明"修观点或接住它"）；文末边角料箱
    ↓
质检（机器，全部机械可查）：
  ① 事实闸：零编造、全溯源（每个事实带可点来源）
  ② 承重闸：段首判断句删掉底下证据必须塌，塌不了＝装饰句，下架
  ③ 方向保真闸：全部小标题逐条回溯方向书，锥体外＝夹带私货打回（复用重写实验的轴保真闸）
  ④ 预读提词（非评分）：所长模型预测的考题清单（"永军会问这条谁牵头""曹会问跟纲要哪节挂接"）
    ↓
收货（人）
```

## 三、clarify（report-clarify 五问）改造清单

| 现五问 | 处置 | 理由 |
|---|---|---|
| Q1 读者层级 | **留** | 方向书分量 |
| Q2 体例 | **留＋升格** | 即永军三类型学，方向锥体主轴 |
| Q3 核心观点 | **改为倾向箭头** | 撰写者给得出方向给不出命题；逼问观点=逼他现场编 |
| Q4 维度逻辑 | **降级** | 由前置必答改为机器在观点清单中提案、人勾选 |
| Q5 风格子型 | **撤** | 会议决议风格不限制，收集无人要的信息 |
| （新增）禁区 | **加** | 锥体边界，缺它机器必夹私货 |
| （新增可选）半成形直觉 | **加（选填）** | 有就收，不逼 |

形态改变：从"一次性问卷→拼启动命令"变为"两触点合同"；方向书全程有效，保真闸对其逐条核查。

## 三·五、触点一的实现：侦察检索辅助定向（2026-07-12 补充，用户提案）

原理：人给不出真空里的方向，但对着东西挑方向只要几秒——反应比生成便宜。故触点一形态＝**先侦察，后点选**，复用 topic-material-search 作侦察兵。

1. **检索分两速**：澄清阶段跑"侦察连"（同 skill 降配：十几条权威线索、几分钟）；方向书签字后主力检索全量上。方向书反哺主检索：箭头定加权方向、禁区剪枝、侦察结果作种子防重复。
2. **态势速览一页纸**（侦察产出，为点选而生，四栏）：①最近谁动了什么（3–5 条硬事实）②**分歧轴**——各方在哪几个点上吵；每根轴的两端即候选箭头（"你站哪边"远比"你的倾向是什么"好答）③反直觉信号与数据缺口（勾问题意识）④候选研究问题 3–5 个。
3. **反锚定焊死**：分歧轴两端都摆、中立措辞；每栏留逃生口"以上都不是，我关心的是____"；逃生口被填＝侦察打偏，记录并改侦察策略。
4. 与现状关系：即 report-clarify"预检索"模式升级——产出从"候选研究问题"扩为"态势＋分歧轴＋候选箭头＋候选问题"，服务对象从定题扩到定向。改动量小，杠杆大。

## 四、被这个架构杀掉/降级的旧部件

- 评分门"鉴赏家"角色 → 只留机械闸（三闸＋H3；评委对预检未过线者的语域裁量封死）
- 教科院修订步 → 删（数据判死：越像人稿 LLM 分越低，且无顶层认可先例）
- 推理刀机器立论 → 降级为"锥体内候选观点生成器"
- 文风 DNA → 基本退役（风格不限制决议）
- 四把审查尺子 → 归一
- 三代评分标尺（7维/v3.1/V4）→ 档案馆
- 双引擎 → 长期合一

## 五、验收指标（全部真实可数，不造评委）

1. **方向命中率**：观点清单勾选率（<50% ＝ 方向书没拿准，修触点一）
2. **观点保真率**：成稿小标题可回溯方向书＋已勾清单的比例（机械查）
3. **采用率**：撰写者最终真报告里来自本系统的句数（逐段可数）
4. **复购率**：下一篇他还来不来——唯一不会骗人的满意度
5. 里程碑不变：第一篇所长级点头的稿（真人盲评，"打分让我们迷惑了"）

## 六、MVP 路径（先做最小可卖）

1. 只做触点一＋触点二的交互原型（方向书模板＋观点清单模板，handoff 机制复用）——不改写作步
2. 挑所里本周真题、真撰写者，跑一单，数：勾选率、采用句数
3. 蒸馏产物（所长模型）第一上岗位置＝观点模具＋预读提词，不做评分
4. 与《下一阶段行动方案》的关系：蒸馏计划（Phase A–D）不变，其 Phase D 接入点由本设计确定为"观点模具＋预读提词"两处

## 七、风险与边界

- 命题作文风险：观点先行→证据裁剪。对策＝反证栏强制（诚实供货是助手与谄媚机的分界）
- 方向书过粗：倾向箭头给错→整锥体白跑。对策＝触点二 30 秒拦截，代价封顶一次立论
- 所长信任/采纳是组织问题非工程问题，本设计不承诺解决；预读提词只帮撰写者备考，不替所长判断
