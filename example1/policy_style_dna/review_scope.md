# 文风与表述审查范围（scope = style_and_expression）

只审【文风】和【表述】，**不核查事实对错、不读检索原始材料**（事实由别的环节负责）。**本标准适用全部体例（战略应对 / 经验借鉴 / 趋势研判），是 A（handoff 子 agent）与 B（inline 自审）两种审查模式共用的单一文风与表达尺子。**

重点盯以下问题（都只看正文即可判断）：

- **一国平铺无收拢**：连续“〔A国〕…〔B国〕…〔C国〕…”裸排，节首无共性总判、节末无类型化/趋势收拢——本体例头号问题。
- **悬空建议**：建议只剩“应加强/应重视/大力推进”空壳，缺实施机制（谁做/靠什么/怎么衔接）；或与前文经验/风险不对位。
- **空泛大词裸奔**：强判断、关键数字未就地带出处（报告名/机构/文件/年份）；价值词单独成句作呼告。
- **AI 腔 / 八股**：套话、空泛排比、“首先其次最后”式机械结构、为对仗而对仗。
- **情绪化 / 文学化**：四字格堆砌、煽情、标语腔、军事化或比喻化动词、“触目惊心”类渲染词。
- **原始材料 / 过程信息外露（硬禁）**：正文出现“根据材料”“材料显示”“据材料”“材料[编号]”“如材料所述”“检索材料表明”“根据检索”“模块”“标签”“本文将分析”等暴露原始材料或生成过程的字样——逐处指出并要求删除或改为真实出处。
- **判断强度失当**：指向中国用“必须/务必/立即”**仅在【子型 A 且所接威胁 ≥E3（运行数据级）】时合法**，其余场合判失当（改为“应/宜/可借鉴/值得关注/可探索”）；子型 B 任何证据级都封顶建设句/陈述句。判据真源：`../strategic_response_workflow/shared_schema/strength_gate.md`（双钥门）。
- **本土化缺失**：照搬国外机构名/法案名要求中国“也应设立”，未做体制对接与敏感词软化；敏感议题缺“稳慎有序推进”兜底。
- **形式纪律**：分类基数不一致（说“三种”却给两条）、加粗编号断裂、OCR 残留（断裂英文/乱码/表格错位）入文。
- **句式与篇幅**：超长段落（8 行以上）、超长复合句、冗余重复、夹生英文术语未中文化。

## 可读性与表达校对（与上并列，必查）

- **通俗易懂**：绕口 / 学术腔 / 术语堆砌；专业概念与英文缩写首次出现是否一句话解释。
- **通顺流畅**：超长复合句、该断不断、逻辑连接生硬；单句原则上不超过 50 字。
- **观点清晰**：每部分 / 每段核心观点是否一眼可见，必要时用判断性领起句点明。
- **解释到位**：是否只抛结论不讲“为什么”；关键判断后是否有解释与依据。
- **小标题正式、简明扼要**：避免口语化与解说式长标题（如“为什么会这样，又是否管用”→“制度根源与有效性裁决”）。
- **删除元说明句**：建议正文残留“这一条属于近期/中期/长期……”“要等某条出台后推进”“可与第几条协同部署”等优先序对应解释句——必须删，优先序靠正文与排序自然体现。

判据：查“有没有上述问题的**具体实例**”，逐条**引原文** + 给改写示范，不要泛泛而谈。最后给一行 `总体结论：达到 | 基本达到 | 未达到`。
