# 提示词流水线一致性整改方案

人工智能与教育政策研究工作流课题组（以教科院研究员范式拟定）
2026年7月6日

写作流水线的提示词体系，本质上是一份"多人协作的编辑部规程"。此次审查发现的各类矛盾，病根不在个别措辞，而在三件事未立规矩：引用体例未统一、判断权属未划清、审查尺子与写作尺子未对表。本方案以内参体例与循证纪律为总裁决标准，对审查发现的八处高危、一批中危问题逐条给出改法，并按"稳慎有序推进"原则分四批实施、每批验证后再进下一批。

## 一、总裁决标准（五条，一切具体改法由此导出）

**一是引用体例从课题组研究报告体。** 正文不加角标、不设脚注、文末不列引用；政策文件在正文内以《中文译名》（英文原名）加发布机构、年份就地标注；URL 与引用编号只存在于料包和构思产物层，供核对，不入正文。（本条为用户拍板：脚注不保留。）

**二是判断权属一步一主。** 分类轴、入稿集合、排序分档、阶段定位，每项判定只能有一个环节说了算；上游只供事实与问题，下游只执行不再裁；凡两个环节都自称"最终"的，必须明文划界。

**三是写作、审查、修订同一把尺子。** 审查维度必须是写作要求的镜像，修订依据必须是审查报告本身；不得出现"写按甲、审按乙、改按丙"的三套标准轮转。

**四是分类轴一经确立、全程不得变更。** 各小节的类型划分由其写作模块按锁定的轴完成后，组装、全文审查、全文重写各步只能润色表达，不得重新命名类型、不得更换分类轴——这是本次"轴劫持"事故的直接教训，须以硬约束写入末端步骤。

**五是示例必配边界、缺失必配兜底。** 凡给具体示例，须注明"结构示范、不得照搬"并给出可替代形态；凡要求"必须使用上游产物"，须写明产物缺失或不合格时的降级处理，禁止静默回退。

## 二、第一批：引用口径统一（H1、H7，改后 dry-run 验证拼装）

**（一）第一章案例公式去脚注（H1）。**
- 《模块 1B：顶层设计 · 归类加写作》案例公式末项"→ 脚注[机构. 文件名. URL]"改为"→ 文件与机构信息在句内以中英文全称＋年份呈现，不另加脚注或来源标签"；文体硬规范第2条"引用一律脚注"改为"政策文件首次出现写'中文译名（英文原名）'＋年份，就地入句，不加任何引用标记"。
- 《2B：实施机制 · 归类》同款两处，同改。
- 3C 提示词中"暂不写脚注，但每条末尾用【素材来源：文件名】标出依据"一句删除，改为"依据落在句内（机构＋文件＋年份），不加任何来源标签"——该句与 prompt_builder 的删除规则正面冲突，是必然被后处理吞掉的无效指令。
- `workflow/report_pipeline.py` 的 `_clean_ch1_governance_text` 增加一条兜底正则，清除残留的"脚注[…]"字样。

**（二）三体例 writing.md 内部矛盾句修正（H7）。**
- strategic_response、experience_response、trend_review 三个 `prompts/writing.md` 的"关键数据优先写明报告名、机构名、年份或材料中的引用编号"统一改为："关键数据须能对应材料出处（后台核对用）；正文呈现只写机构、文件、年份，不出现引用编号。"——与同文件"材料[编号]不得入文"句归于一致。

## 三、第二批：判断权属划清（H2、H3、H4、H8，逐体例改后抽样验证）

**（三）建议筛选权归池、排序权归序（H2，experience_response，strategic 同款同改）。**
- `policy_priority.md` 开头增写："本步只对候选建议池判定'建议入稿'的条目做排序与分档，不新增、不复活、不剔除条目；如认为某条必须剔除，标注理由退回建议池环节，不得直接删除。"
- `writing.md` 建议段增写："建议部分的条目集合以候选建议池的入稿判定为准，次序与分档以政策优先序产物为准；两者冲突时以入稿判定为准并在文外标注冲突。"

**（四）趋势研判分层不分权（H3，trend_review）。**
- `planning.md` 归并要求处增写："压力-判断映射产出的3—6条研判是素材层，本步归并的2—3条主线是结构层；须输出'主线—研判'对应表，说明每条主线吸纳了哪几条研判，不得留无归属研判；确实无法归并的，如实保留3条以上并说明原因。"
- `writing.md` 相应增写："正文按构思产物的主线组织，各条研判作为主线内的证据与判断展开。"

**（五）"趋势成熟度"与"中国方位"分名定主（H4，trend_review）。**
- 全体例统一术语：国际侧成熟度（萌芽信号/扩散中/已制度化）称"趋势成熟度"；中国相对位置（落后空白/已上马缺配套/已过度/领跑并跑）称"中国方位"。
- `pressure_judgment_mapping.md` 输出结构增设"中国方位"字段（按 stage 刀四档扫描），明确该扫描的完成环节即本步；`material_roles.md`、`writing.md`、`review.md` 涉"阶段"表述统一替换为两个术语之一；`reasoning_dna/conventions.md` 补一行术语映射说明。

**（六）末端重写步立"轴不可变更"硬约束（H8，新增，根引擎）。**
- `workflow/prompts/fulltext_rewrite.md` 增写硬约束："各小节已确立的分类轴与类型命名（如'专综并进型/总体嵌入型/专项引领型'、'专设机构型/多机构协同型/委托执行型'）不得更改、不得重新命名、不得合并拆分；重写只处理表达、衔接与结构顺序，分类体系原样保留。"
- `workflow/prompts/fulltext_review.md` 审查维度同步补一条："检查重写稿是否保持了各小节原有分类轴与类型命名。"
- 本条为本次 v4 验证的直接发现：1B 草稿分型正确，末端重写步却重新命名了类型——轴纪律必须贯穿到最后一步。

## 四、第三批：审查尺子对表（H5、H6，改后用现成稿件复审对比）

**（七）审查判据前置为写作自查（H5，strategic_response，另两体例同款同改）。**
- 从 `review.md` 提取属于"写作时就应自查"的判据（建议的政策对象/工具/场景匹配、战略回应精度、压力-建议闭环），改写为"写作自查清单"嵌入 `writing.md` 建议段；`revision.md` 头部增写："修改的唯一依据是审查报告所引判据，不另立标准。"

**（八）审查尺随读者档位路由（H6，横切层）。**
- `reviewers/jiaokeyuan_review_scope.md` 增设路由门：依 run 目录的 audience_profile_snapshot——national_leader 档按"判断密度与篇幅"从严、moe_leadership 档侧重"与部级权限的对应"、bureau 档侧重"操作颗粒度与试点设计"；未注入档位时按体例默认站位评。
- `audience_alignment_scope.md` 与 `jiaokeyuan_review_scope.md` 就"无档位快照时的处理"在共同规范源中写明分工，避免重复或漏评。

## 五、第四批：中危清理（示例边界、证据分级、刀界、兜底）

**（九）示例配边界。** `policy_priority.md` 三层结构示例前加"按压力数量与松紧度可取两层或三层，须说明理由"；`article_template.md` 建议示例前加"以下为结构示范，条数与措辞不得照搬"；trend 体例两处注入抽象模板处注明"示例分类轴仅供参考，题目自然轴优先"。

**（十）证据分级一表通用。** 以 `efficacy.md` 四级为母表，在三体例 `writing.md` 补对应关系——E1（意图）称"计划/正在推进"、E2（试点）称"试点实践/初步经验"、E3（运行数据）称"成熟经验"、E4（效果评估）称"验证有效的经验"；`review.md`、`revision.md` 按同表执行。

**（十一）刀与构思步划界。** 各体例 `pressure_judgment_mapping.md` 输入节声明："成因与有效性分级以 cause/efficacy 刀产物为准，本步只做整合与映射，不重做分级；发现前置分级需修正的，回溯标注。"

**（十二）缺失兜底成文。** 三体例 `suggestion_pool.md` 补"判断对少于3条时，建议数不超过判断数的1.5倍，宁缺毋滥"；`writing.md` 补"写作依据缺失时开篇如实标注，不得强行编造"；`revision.md` 补"材料无记载的精确数据一律删除并转定性表述"；trend 体例 `revision.md` 另补"中国现状数据不足时，对策可只回扣趋势研判，并标注'短板数据待补'"。

## 六、实施与验证安排（稳慎有序）

一是分批推进：第一批（引用口径）一次改齐，dry-run 验证拼装；第二批（判断权）逐体例改后抽跑小样核对产物；第三批（审查尺）用现成稿复审一遍对比评分口径；第四批择机清理。二是每批完成即提交一次版本记录，保留回滚能力。三是每批验证以"产物是否符合裁决标准"为唯一判据，不以"跑通"为完成标准——此为本次 1B 空产出被标 done 的教训。四是全部完成后，将第一节五条总裁决标准沉淀为流水线的"编辑部规程"，纳入 runbook，作为日后新增体例与提示词的先验约束。

（说明：低危项——语域闸重复表述、DESIGN.md 归档、趋势命题格式、task_redefinition 中性化回溯——不入批次，随手清理即可。）
