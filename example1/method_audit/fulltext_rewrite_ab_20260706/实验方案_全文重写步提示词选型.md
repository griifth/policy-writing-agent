# 全文重写步（full.rewrite）提示词选型实验方案

目的：现行 full.rewrite 是全流水线权力最大、监督最少的一步（v4 实证：重命名了正确的分类轴）。本实验用多个写作 agent 平行模仿这一步，测试不同提示词与组装方法，用同一把审稿尺盲评，选出最优方案回写引擎。

## 一、素材基座（全部取自 v4 run-20260706-193854-4dab90d1，各变体输入一致）

- A＝`final_report.md`（final.assemble 机械拼接稿，19.4KB——第一章为 1B 正确的结构三型产物）
- B＝`review_reports/final_review.md`（task 20 最终审查报告，用户点名的依据）
- C＝`review_reports/fulltext_content_structure_review.md`（task 21 全文结构审查报告，现行 rewrite 用的依据）
- 机构落点文本（统一保留，控制变量）
- **全部变体一律不注入战略态势卡**（用户要求 1）

## 二、变体矩阵（5 个写作 agent 并行，公共硬边界一致）

公共硬边界（每个变体都含）：不新增材料外事实；不加脚注/角标/引用编号；清除"【素材来源】/材料显示/[编号]"等外露字样；分类轴与类型命名不得变更（H8）；只输出正文。

| 变体 | 角色/提示词 | 修改策略 | 审查依据 | 测什么 |
|---|---|---|---|---|
| **V1 去卡基线** | 现行 fulltext_rewrite.md 原文（含 H8） | 全文重写 | C（同现行） | 单测"撤态势卡"的净效果（与现行产物对照） |
| **V2 定向施工** | V1 + "先内部把审查报告逐条转成施工单，只对点名句段动刀；**未被点名的句段（含小标题与类型命名）一律原样保留**" | 定向修改 | C | 降权：漂移面从全文缩到点名处 |
| **V3 教科院终审整合** | 教科院研究员终审人范式：三遍读法（全局判断→逐章缝合→防伪清理）、内参体例（论点句加粗、例证内嵌、判断收束）、课题组视角整合三章 | 终审整合 | B＋C | 范式注入能否同时提升缝合质量与体例（用户要求 2） |
| **V4 分章施工** | 组装方法变体：逐章处理——每章只按审查报告中该章条目修改，章与章之间只允许动过渡句与总起句 | 章内定向＋章间仅过渡 | C | 组装粒度（分章 vs 全文）对漂移/保真的影响 |
| **V5 双审查·最小干预** | "只解决 B、C 两份报告中的高优先与交集问题，低优先润色一律不做" | 最小干预 | B＋C | 审查依据构成＋最小干预的信息保全上限 |

对照组：**S0＝现行流水线产物 `final_report_reviewed.md`**（有态势卡、全文重写、无 H8 时代产物）一并进入评审——回答"多 agent 方案是否优于现行单步"。

## 三、统一审稿标准（用户要求 4）

### 机械检查（脚本，先跑，客观硬指标）
1. **轴保真**：与 A 比对类型命名集合（专综并进型/总体嵌入型/专项引领型/专设机构型/多机构协同型/委托执行型）是否完整保留、有无新造类型名；
2. **锚点事实保留率**：10 个锚点抽查（EO 14277、《美国人工智能行动计划》、400万英镑、67%、92%、1.78亿、五部门、2027年12月、Ofqual、原住民）；
3. **结构稳定**：章节标题数与层级对比；字数比（超 ±25% 标警）；
4. **外露清理**：残留"材料[编号]/素材来源/[数字]角标"计数。

### 盲评（3 个独立评审 agent，多数决）
6 个样本（S0＋V1–V5）随机编号、不告知来源方案；每个评审 agent 拿到 A、B、C、rubric，独立对全部样本按 6 维打分（每维 0–10）并排名：
1. 轴保真与越权（有无擅改分类/框架）
2. 审查落实率（B/C 点名问题逐条核对）
3. 事实纪律（无中生有 / 关键信息丢失）
4. 跨章缝合（重复消除、过渡、第三章回扣前文）
5. 体例文风（政策研究报告文体、格式干净）
6. 总体可交付度（能否直接作为终稿）

### 评判
机械硬指标一票否决（轴保真失败/锚点丢失>2 个直接出局）→ 盲评总分排序 → 三评审排名一致性核查（分歧大的样本人工复核）。

## 四、产出与回写

- `outputs/S*.md` 六个样本、`scores/` 机械检查表＋三份盲评表、`结论.md` 对比汇总；
- 胜出方案回写 `workflow/prompts/fulltext_rewrite.md`（及 `_rewrite_full_report` 是否撤态势卡注入的代码决定）；
- 若 V3/V4 类"组装方法"胜出且单提示词无法承载，则给出流水线改造建议（如 rewrite 拆两步）。

## 五、成本与时长

5 写作 agent＋3 评审 agent ≈ 8 个子任务，并行两波，约 30–40 分钟；不动引擎、不动 run 产物、全程只读仓库＋写实验目录。
