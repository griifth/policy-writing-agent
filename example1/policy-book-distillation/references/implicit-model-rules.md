# Implicit Model Rules

Use this file when moving from explicit extraction to hidden-model inference.

## Core Rule

Infer an implicit thinking model only when the same pattern appears multiple times across the text or across clearly connected sections.

Do not infer from:

- one striking sentence
- publisher copy
- chapter titles alone
- your prior knowledge of the author

## What To Infer

Look for repeated answers to these questions:

- What does the author treat as the real unit of analysis?
- Where does explanation usually start?
- What kind of evidence settles the argument?
- Where is agency located?
- How are policy recommendations generated from diagnosis?
- Which tensions keep returning?
- What is routinely left under-specified?

## Signal Types

### 1. Sequencing Signal

Infer from the order in which the author repeatedly proceeds, for example:

- problem definition -> actor mapping -> institutional constraint -> implementation
- historical baseline -> mechanism -> case comparison -> recommendation

### 2. Evidence Signal

Infer from what evidence the book trusts most:

- cases over metrics
- institutional design over actor preference
- implementation scenes over top-level goals
- discourse and framing over measurable outputs

### 3. Compression Signal

Infer from what the author consistently skips or compresses:

- implementation details
- local discretion
- political conflict
- distributional effects
- cross-level feedback

Repeated omission is evidence, but only when the omitted dimension would normally matter for the topic.

### 4. Recommendation Signal

Infer from how recommendations are formed:

- redesign institutions
- realign incentives
- improve coordination
- change frontline capability
- adjust policy tools
- reframe the public problem

## Safe Phrasing

Use phrasing like:

- `从多处论证顺序看，作者默认从制度约束进入问题`
- `该书并未明说这一点，但从案例选择和证据偏好看，更重视实施场景而非形式目标`
- `基于重复出现的分析动作，可推断其隐含模型偏向机制链条而非价值宣示`

Avoid phrasing like:

- `作者真正相信`
- `作者本质上就是`
- `作者潜意识里`

## Minimum Evidence Threshold

Use this rough threshold before making a hidden-model claim:

- `A` coverage: at least 3 independent repeated signals
- `B` coverage: at least 2 repeated signals plus no major contradiction
- `C` coverage: treat hidden-model claims as tentative only
- `D` coverage: do not make them

## Output Discipline

For each substantial hidden-model claim, try to pair:

- one short evidence note
- one inference statement
- one uncertainty note when applicable

Example:

- `证据：多章都先讨论制度安排，再进入行动者策略`
- `推断：默认解释起点偏向制度约束`
- `不确定性：尚未看到完整方法章节，需防止过度推断`
