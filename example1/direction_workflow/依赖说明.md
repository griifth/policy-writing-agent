# direction_workflow 运行依赖一页纸

> 2026-07-20 编写。回答一个问题：整包拎到任何新位置，还差什么才能跑。
> 结论：**包外一个 `.env`（生产单才需要）＋一次 `pip install`＋可联网的 agent 会话**，其余全部随包自带。

## 一、必备依赖

| # | 依赖 | 谁用 | 怎么配 |
|---|---|---|---|
| 1 | **Python 3.10+** | `gates/precheck.py`（纯标准库）、`engine/`（代码用 3.10+ 语法） | 系统自带或官网安装 |
| 2 | **python-docx＋openai** | python-docx：`tools/neican_docx.py`（第⑬步排版导出 docx）；openai SDK：`engine/deepseek_client.py`（生产单走 DeepSeek 时必需，试跑单不需要） | `pip install -r requirements.txt` |
| 3 | **联网** | 第①步侦察、第④步全量检索（真网搜） | **平台无关**：skill 里的 WebSearch/WebFetch 泛指执行平台自带的联网搜索/网页抓取工具，任何具备等价工具的 agent 平台（Claude Code、OpenClaw 等）均可执行；平台若无联网工具，侦察/检索降级并按 `[SIMULATED]` 如实标注，不静默编造 |
| 4 | **Claude Code / agent 会话** | 全流程调度（装配工 skill、清稿/瘦身聚拢/排版工序均为 agent 执行） | skill 可装 `~/.claude/skills/` 按名触发，或按包内路径读取执行（见 移植说明.md 第二节） |

## 二、DeepSeek 密钥（.env）——生产单才需要

- **设计原则：密钥不入包。** `engine/` 不存放任何密钥。
- **位置（2026-07-22 简化）**：**包根 `direction_workflow/.env`**——把随包的 `.env.example` 复制为 `.env`、填入密钥即可；该文件已被包级 `.gitignore` 排除，不会误提交。旧位置（包上一级 `.env`）仍兼容，引擎先找包内、再找上一级。
- **覆盖方式**：进程环境变量最优先；或用 `--env <路径>` / `DEEPSEEK_ENV_PATH` 指定其他位置。
- **所需变量**：`DEEPSEEK_API_KEY`（必填）；可选 `DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`、`DEEPSEEK_REASONING_EFFORT`。
- **没有密钥时**：立论（⑤）与组稿（⑧）由 agent 直写替代，流程照跑；台账须标注执行引擎。

## 三、可选依赖（缺了只降级，不致断）

| 依赖 | 缺失影响 |
|---|---|
| 旧引擎 `strategic_response_workflow/`（内部仓库，不随包） | 仅 topic-material-search-v2 **全量模式的 DeepSeek 复审**与 runner hand-off 不可用；侦察、检索、组稿、四闸全部照常 |
| 蒸馏溯源材料（会议证据/蒸馏报告，内部仓库，不随包） | 仅影响"追溯顾问 skill 结论依据"的核对，日常跑单不依赖 |
| `~/.claude/skills/` 安装件 | 只影响"按名触发"；按包内路径读取执行则完全不需要 |

## 四、自检三条（新位置部署后跑一遍）

```bash
cd <你放置的位置>/direction_workflow
python3 gates/precheck.py <任一md文稿>        # 应输出六项语域读数（只依赖包内两份词表）
python3 -c "import docx; print('python-docx OK')"
python3 engine/run_entity.py --help            # 无密钥时也应正常打印用法
```
