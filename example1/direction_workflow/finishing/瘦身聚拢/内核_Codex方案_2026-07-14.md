## 一、整体流程（先诊断、再定岗、后删改、最后校验）

关键不是简单缩短文字，而是让文章中每个观点只承担一次完整论证，避免同一个意思在"问题分析、形势判断、建议、风险、结论"里反复出现。

### 第一步：理解全文，不急着修改

先回答三个问题：文章的核心结论是什么？每个章节分别承担什么任务？哪些段落是在提供事实，哪些是在判断、建议或提示风险？

提示词：

```
请通读下面这篇文章，暂时不要修改文字。
请完成以下任务：
1. 用一句话概括文章的核心结论。
2. 梳理全文的论证结构。
3. 标注每个自然段的主要功能，功能类型包括：
   - 背景
   - 事实或数据
   - 案例
   - 问题诊断
   - 原因解释
   - 核心判断
   - 对策建议
   - 风险提示
   - 结论
4. 说明各章节在全文中承担的独特任务。
5. 如果两个章节承担了相同任务，请特别指出。
此阶段只分析，不改写、不删减。
文章如下：
【粘贴全文】
```

### 第二步：查找"观点重复"，而不只是字面重复

这一步重点识别：同一结论换一种说法再次出现；同一组数据被反复引用；问题分析和对策建议重复解释背景；风险部分重新讲了一遍前文判断；结论只是把全文再复述一次。

提示词：

```
请检查下面文章内部是否存在"论证功能重复"。
这里的重复不只指句子相同，还包括：
1. 同一个核心观点被不同表述反复说明；
2. 同一组数据、案例或政策依据出现多次；
3. 不同章节虽然标题不同，但实际上在回答同一个问题；
4. 对策部分重复问题分析，而没有转化为具体行动；
5. 风险部分重复前文判断，而没有提出新的边界条件；
6. 结论部分逐条复述正文，缺少新的综合判断；
7. 上位概念与下位概念被并列反复论述。
请输出一份"重复关系表"，包括：
- 重复主题
- 首次出现位置
- 再次出现位置
- 两处分别承担的功能
- 属于字面重复、语义重复还是功能重复
- 建议保留哪一处
- 另一处应删除、合并、压缩还是改换功能
注意：
- 不要因为出现相同关键词就直接判定重复；
- 必须判断两段是否提供了新的证据、新的分析层次或新的行动信息；
- 此阶段仍然不要直接改写全文。
文章如下：
【粘贴全文】
```

### 第三步：给每个观点确定"唯一落点"

原则：数据和案例集中放在"事实证据"部分；原因和机制放在"问题分析"部分；作者立场放在"核心判断"部分；建议只写行动、主体和机制；风险只写适用边界和防范措施；结论只保留最终判断，不再逐段复述。

提示词：

```
根据前面的重复诊断，为文章建立"观点唯一落点表"。
请对每一个反复出现的重要观点确定：
1. 该观点最适合放在哪个章节；
2. 哪个位置保留完整版本；
3. 其他位置如何处理：
   - 删除
   - 合并
   - 压缩成过渡句
   - 改为证据
   - 改为行动建议
   - 改为风险边界
4. 处理后各章节应当分别回答什么问题。
请遵守以下分工：
- 背景部分回答：为什么现在要讨论这个问题？
- 事实部分回答：现实情况到底是什么？
- 分析部分回答：为什么会出现这些问题？
- 判断部分回答：作者据此得出什么结论？
- 建议部分回答：谁应该做什么，如何实施？
- 风险部分回答：什么情况下可能失效，如何防范？
- 结论部分回答：最终最值得决策者记住的是什么？
不要让同一个观点在两个章节都得到完整展开。
```

### 第四步：执行去重修改

这一阶段才真正修改文章。核心原则是"保留信息，减少重复表达"。

提示词：

```
请根据"重复关系表"和"观点唯一落点表"修改全文。
修改目标：
消除文章内部的语义重复和论证功能重复，同时保留文章的核心观点、关键数据、案例、政策依据和必要的反方证据。
具体要求：
1. 同一观点原则上只保留一次完整论证；
2. 优先保留证据最充分、位置最合理、表达最准确的版本；
3. 其他重复位置可以删除、合并或压缩为过渡句；
4. 不得为了缩短篇幅而删除关键数据、来源、案例和反向证据；
5. 对策部分不要重复解释问题，要改写为可执行内容：
   - 行动主体
   - 具体动作
   - 实施机制
   - 评估方式
6. 风险部分不要重述前文，要说明：
   - 适用条件
   - 失效情形
   - 可能副作用
   - 防范措施
7. 结论不再逐段总结，只保留一至两个综合判断；
8. 保持原文正式、克制、政策研究型的语言风格；
9. 保持原有标题层级和基本结构，除非合并章节确有必要；
10. 不新增没有依据的数据、案例和政策表述。
请输出：
一、修订后的全文；
二、主要删改说明；
三、仍需作者确认的内容。
```

### 第五步：专门改写对策部分

建议部分最容易重复"为什么要做"，因此把建议改成行动表达。

提示词：

```
请单独检查文章的对策建议部分。
判断每条建议是否仍在重复前文的背景、问题或必要性论述。如果存在，请删除重复解释，将建议改写为行动导向表达。
每条建议尽量包含：
1. 谁来做；
2. 做什么；
3. 通过什么制度、平台或机制实施；
4. 形成什么成果；
5. 如何评估实施效果。
建议采用以下结构：
"行动主体＋关键动作＋实施机制＋预期产出/评价方式"。
要求：
- 不新增未经原文支持的政策措施；
- 不再大段解释问题的重要性；
- 保持政策研究文章的表达风格；
- 各条建议之间不能只是换词重复。
```

### 第六步：专门处理风险和结论

提示词：

```
请检查文章的风险提示和结论部分。
风险部分：
- 删除与正文问题分析重复的内容；
- 只保留新的适用边界、实施风险、副作用和防范措施；
- 每项风险都要说明"风险从何而来"和"如何应对"。
结论部分：
- 不逐条复述各章节；
- 不重复摘要和开头的判断；
- 只保留全文经过论证后形成的最终决策判断；
- 最好控制为一个自然段，必要时可以保留两个自然段。
请先指出重复之处，再给出修改后的风险部分和结论部分。
```

### 第七步：进行"信息保全"校验

去重最容易出现的问题，是把必要证据也删掉。因此需要反向检查。

提示词：

```
请对修订稿进行信息保全检查。
将修订稿与原稿逐项比较，检查以下内容是否被误删或改变：
1. 核心结论；
2. 关键数据及其时间范围；
3. 政策文件、研究报告和引用来源；
4. 典型案例；
5. 因果关系和逻辑条件；
6. 反方证据、限制条件和风险提示；
7. 对策建议中的责任主体；
8. 原文具有辨识度的重要表达。
请输出：
- 完整保留的内容；
- 被合理合并的内容；
- 可能被误删的内容；
- 表述发生实质变化的内容；
- 建议恢复或进一步核实的内容。
如果没有发现问题，也要明确说明。
```

### 第八步：做最终的重复复检

提示词：

```
请把下面的修订稿视为一篇独立文章，重新进行一次内部重复检查。
重点检查：
1. 是否仍有同一判断在相邻段落中反复出现；
2. 是否存在不同章节承担同一论证任务；
3. 是否有多次使用"这表明、这意味着、由此可见"等句式得出相同结论；
4. 对策是否重复问题分析；
5. 风险是否重复核心判断；
6. 结论是否重复摘要或引言；
7. 删除某一段后，全文信息是否几乎没有损失。
请把问题分为：
- 必须处理的重复；
- 可以进一步压缩的内容；
- 虽然相似但应当保留的内容。
只对确有必要的地方提出修改，不要为了追求短篇幅而过度删减。
```

## 二、总提示词（快速路径，不分轮时使用；分轮质量更稳）

```
你是一名教育政策研究文章编辑。请对下面文章进行"内部去重修订"。
这里的"重复"不只是字面相同，而是同一观点、数据、判断或论证功能在不同章节中反复出现。
请按照以下步骤处理：
第一步：概括文章核心结论，并标注各章节的功能。
第二步：找出以下重复：
1. 同一观点换一种说法再次出现；
2. 同一数据、案例或政策依据重复使用；
3. 不同章节实际回答同一个问题；
4. 对策部分重复问题分析；
5. 风险部分重复前文判断；
6. 结论部分重复摘要或正文。
第三步：为每个核心观点确定唯一落点：
- 数据和案例放在事实证据部分；
- 原因和机制放在分析部分；
- 作者立场放在判断部分；
- 建议只写主体、动作、机制和评价；
- 风险只写适用边界和防范措施；
- 结论只保留最终综合判断。
第四步：修改全文：
1. 同一观点原则上只完整论证一次；
2. 保留证据最充分、位置最合理的版本；
3. 其他位置删除、合并或压缩为过渡句；
4. 不删除关键数据、来源、案例和反方证据；
5. 不新增原文没有依据的事实或政策；
6. 保持原有标题层级、基本立场和正式文风；
7. 避免把文章修改成缺少论证的提纲；
8. 避免仅通过替换近义词制造"表面不重复"。
第五步：进行自检：
- 核心观点是否完整；
- 数据和引用是否准确；
- 章节分工是否清楚；
- 对策是否具有行动性；
- 风险是否提供了新的边界信息；
- 结论是否简洁而不重复。
请依次输出：
一、重复诊断表；
二、修订后的全文；
三、主要删改说明；
四、信息保全检查；
五、仍需作者确认的问题。
文章如下：
【粘贴全文】
```

## 三、元提示词（提示词编译器）

本质：**通用去重原则 + 当前文章的结构诊断 + 重复关系图 + 信息保留清单 → 文章专用执行提示词**。元提示词不直接修改文章，而是先阅读文章，判断这篇文章"具体重复在哪里、为什么重复、应该保留哪一处"，然后生成一份只适用于当前文章的修改指令。

元提示词由六个模块组成：识别文章画像 / 建立重复簇 / 判断重复类型 / 确定唯一落点 / 建立保留清单 / 生成文章专用提示词。生成出来的提示词不会只说"请减少重复"，而会说：哪一节与哪一节重复；重复的是哪个判断；哪一处保留完整版本；哪一处删除、合并或者转换功能；哪些数据和观点不能删除；修改完成后检查什么。

完整元提示词：

```
你是一名"政策研究文章编辑任务设计师"。
你的任务不是直接修改文章，而是先诊断文章内部的重复问题，再生成一份只适用于当前文章的"专用去重修改提示词"，供另一个编辑模型执行。
请注意：
"重复"不只包括字面相同，还包括：
1. 同一观点换一种说法再次出现；
2. 同一数据、案例或政策依据被多次使用；
3. 不同章节虽然标题不同，但承担相同的论证功能；
4. 问题分析、核心判断和结论反复表达同一个意思；
5. 对策部分重复解释问题，没有转化为行动；
6. 风险部分重复前文判断，没有提供新的边界条件；
7. 上位概念与下位概念被并列展开，造成意义上的重复。
请按照以下步骤工作。
第一步：建立文章画像
识别并输出：
- 文章题目；
- 文章类型；
- 主要读者；
- 核心研究问题；
- 一句话核心结论；
- 全文论证主线；
- 原文语言风格；
- 必须保持的立场和写作特点。
第二步：标注章节功能
判断每个章节和重要段落主要承担什么功能：
- 背景说明
- 事实或数据
- 案例
- 问题诊断
- 原因分析
- 机制解释
- 核心判断
- 对策建议
- 风险提示
- 结论
如果两个章节承担了相同功能，请明确指出。
第三步：建立重复簇
将表达不同但实质相同的内容归为一个"重复簇"。
每个重复簇需要说明：
1. 重复主题；
2. 涉及的章节或段落；
3. 各处的具体含义；
4. 重复类型：
   - 字面重复
   - 语义重复
   - 证据重复
   - 结构重复
   - 论证功能重复
5. 是否提供了新的证据、分析层次或行动信息；
6. 哪个位置最适合保留完整版本；
7. 其他位置应采取什么处理：
   - 删除
   - 合并
   - 压缩
   - 改为过渡句
   - 改为证据
   - 改为行动建议
   - 改为风险边界
判断重复时，不要仅凭关键词相同。只有当两处没有产生新的证据、新的分析层次或者新的行动信息时，才判定为需要处理的重复。
第四步：建立"观点唯一落点表"
请为每个核心观点确定唯一的主要位置：
- 数据和案例主要放在事实证据部分；
- 原因和机制主要放在分析部分；
- 作者立场主要放在判断部分；
- 对策部分只写行动主体、具体动作、实施机制和评价方式；
- 风险部分只写适用条件、失效情形、副作用和防范措施；
- 结论部分只保留最终综合判断。
同一个观点原则上只能有一个完整展开的位置。
第五步：建立信息保留清单
列出修改时不得误删或改变的内容：
- 核心观点；
- 关键数据；
- 数据的时间范围；
- 重要案例；
- 政策文件；
- 研究报告；
- 引用来源；
- 反方证据；
- 限定条件；
- 风险边界；
- 责任主体；
- 原文具有辨识度的重要表达。
如果某项内容是否需要保留无法确定，请标注"需作者确认"，不要擅自删除。
第六步：生成文章专用修改提示词
根据上述分析，生成一份可以直接交给编辑模型使用的提示词。
专用提示词必须包含：
一、当前文章的编辑目标；
二、文章核心结论和论证主线；
三、需要重点处理的具体重复簇；
四、每个重复簇的保留位置和处理方式；
五、各章节修改后的功能；
六、必须保留的内容；
七、禁止发生的修改；
八、输出格式；
九、修改完成后的自检项目。
生成的指令必须具体，不要只使用：
- "适当精简"
- "减少重复"
- "优化结构"
- "提升逻辑"
- "使表达更加简洁"
这类笼统表述。
应当明确说明：
- 哪个观点重复；
- 重复出现在哪些位置；
- 哪一处保留；
- 其他位置怎样处理；
- 为什么这样处理；
- 哪些信息绝对不能删除。
重要要求：
1. 此阶段不要修改原文；
2. 不要虚构文章中不存在的问题；
3. 不要因为句式相似就机械删减；
4. 不得改变文章核心立场；
5. 不得新增没有依据的数据、案例或政策；
6. 生成的专用提示词必须脱离本次分析也能独立使用。
请按照以下格式输出：
A.文章画像  
B.章节功能表  
C.重复簇诊断表  
D.观点唯一落点表  
E.信息保留清单  
F.文章专用去重修改提示词
待分析文章如下：
【粘贴文章全文】
```

## 四、关键中间产物：重复簇

整个过程中，真正决定质量的并不是最终提示词的措辞，而是中间形成的"重复簇"。

```
重复簇 = 同一核心含义
       + 它出现的多个位置
       + 每次出现承担的功能
       + 最适合的完整落点
       + 其他位置的处理方式
```

示例：

| 重复簇 | 完整保留位置 | 其他位置的功能转换 |
|---|---|---|
| 标准先于资源配置 | 核心判断 | 问题部分写后果，建议部分写行动 |
| 数字化不能替代教师 | 风险边界 | 正文只写技术能够提供什么 |
| 区域能力存在差异 | 事实分析 | 建议部分写分类实施 |
| 人工智能是否构成学习革命 | 核心判断 | 引言提出问题，结论给出最终判断 |

模型执行的不是笼统的"去重"，而是**重新安排文章内部的论证分工**。

## 五、公式

```
文章专用提示词
= 通用编辑规范
+ 文章核心结论
+ 章节功能地图
+ 重复簇清单
+ 观点唯一落点
+ 信息保留清单
+ 禁止修改边界
+ 验收标准
```

最重要的三个变量：这篇文章究竟在重复什么；这个观点最应该在哪里说完整；它在其他位置应该转化为什么功能。同样是处理"重复"，不同文章生成的专用提示词会不同——通用原则不变，但每篇文章的重复簇、唯一落点和保留清单都不同。这个过程可以称为**"先诊断文章，再编译编辑任务"**。
