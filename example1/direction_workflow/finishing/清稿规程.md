## 甲、工作流适配层（包装，不入内核）

### 1. 执行引擎（用户明确要求，写死）

**执行引擎：调度 agent／子代理。非 DeepSeek。** 本模块不经 engine/run_entity.py，不调用任何外部生成引擎；台账"执行引擎"字段照实标注。

### 2. 输入与触发时机

- 输入：过闸底稿（`runs/<id>/outputs/成稿.md`，四闸已过）＋方向书＋触点二已勾清单（勾选记录）。
- 时机：四闸＋预读提词之后、排版交付之前（装配工标准流程第 7.5 步）。

### 3. 【文稿背景】三栏自动填充规则

内核开头的【文稿背景】由 agent 从本 run 档案自动填充，不再问人：

| 栏 | 填充来源 |
|---|---|
| 文体 | ← 方向书判型派生的读者用途标签＋内参呈报（如：借鉴型内参·呈报领导） |
| 读者 | ← 方向书"读者层级"（national_leader／moe_leadership／bureau） |
| 立场要求 | ← 默认"必须给出明确判断和建议"；方向书对立场另有特别说明时，从其说明 |

### 4. 本工作流已知痕迹定向清单（阶段一的靶子）

内核阶段一的通用五类之外，本工作流的产出**已知**会带出以下痕迹，逐项点名排查：

1. 文首报送对象／归属头注（`> 报送对象：…｜归属：…` 类引导块）；
2. 【反证栏】标签；
3. "边角料箱"节；
4. "来源锚一览"节；
5. `[ASSEMBLER]`／`[AGENT-WRITER]` 类角色留痕；
6. "回扣第X节"式组稿标记（含"（回扣第…节…）"括注与"逐条回扣前文"类说明语）；
7. 生造词（本工作流已知样例，靶向排查后按内核阶段一第4类改常规表述）：加速的收益边界／下行风险／两张全向地图／落条款级／标准悬空（开放清单，以本 run 触点二"自定义禁用词"与实测新命中为准；样例库真源见 `records/主线架构迭代_2026-07-15/语言治理图纸.md ②2.2` 与 `direction_workflow/gates/lexicon_blacklist.md`）；
8. 内部术语外漏（内部方法论概念漏入正文，靶向清除；"研判主轴"为已确诊外漏词，最高优先）：研判主轴／主线／槽位／判型／铁三角／锥体／元框架／骨架卡／落地开关／触点／勾选率／装配工／边角料箱／来源锚／预读提词单／结构单／论证结构单／可选模块／问答链，以及学术模型名（史密斯模型／CIPP／期望-绩效差距／利益相关者分析／Policy Transfer／地平线扫描／德尔菲法／情景规划／政策生命周期理论 等；PISA／TALIS 等国际测评项目/数据源名不在此列——作数据锚可引用，首次出现给全称＋一句白话，不得作分析框架术语裸用，2026-07-16 设计方裁定 DEV-06）——成稿正文零命中；完整词表见 `records/主线架构迭代_2026-07-15/语言治理图纸.md ①1.2/①1.3`。分层豁免：交付件名（边角料箱／来源锚／预读提词单／论证结构单）按第5条附件分流规则，附件标题可用、正文散文禁用；学术模型名只许在图纸/注释层。

> 衔接（甲层，不入内核）：第7、8项是把内核阶段一（第4类生造复合词）、阶段三（术语白话化）的通用能力，靶向对准本工作流已知的生造词与内部词——不改内核判据、只给靶子；与第5条"附件分流规则"衔接，边角料箱／来源锚等作附件保留（标题合法），本清单只清正文散文里的这些词，不误删附件。守恒约束（第6条）不变。

### 5. 附件分流规则（关键：防止把有用件当痕迹扔掉）

| 对象 | 处置 |
|---|---|
| 边角料箱 | **不删除**——移出正文，另存 `outputs/附件_边角料箱.md`（原文照录＋出处头注） |
| 来源锚一览 | **不删除**——移出正文，另存 `outputs/附件_来源锚.md`（原文照录＋出处头注；供撰写者与后续核验回溯） |
| 预读提词单 | 本就独立文件（gates/），不动 |
| 反证栏 | 按内核原则处理：**标签删、内容不丢**——改写融入正文，按内核阶段二做"预答辩"式闭环 |

### 6. 守恒约束（清稿不许越界）

- **不新增观点**；**不反转**触点二已勾／改的观点（改后句语义为准，润色可、换意不可）；
- 清稿后**小标题判断句语义须与已勾清单一致**——轻跑一次方向保真核对（逐标题对照已勾清单，记入改动说明），语义漂移即回改；
- 清稿后**复跑 `gates/precheck.py`**，六项读数**不得高于清稿前**；若某项升高，如实报告并停在那里交人裁量，**不许为压读数硬调文字**。

### 7. 产出（四件＋伴生附件）

1. `outputs/初稿_可阅读.md`——清稿后的完整成稿；
2. `outputs/改动说明.md`——分阶段列出改了什么、为什么；末尾附 precheck 前后读数对照与方向保真核对记录；
3. `outputs/需作者定夺清单.md`——内核阶段四第 3 项的独立成文，**并入触点三交付物**，交撰写者裁量；
4. 伴生附件（如正文含对应节）：`outputs/附件_边角料箱.md`、`outputs/附件_来源锚.md`。

## 阶段一：识别并清除AI痕迹

逐项排查以下五类痕迹，先列出清单（标注位置），再执行清除：

1. 元结构外露：写作方法论的脚手架残留在正文里。包括但不限于：
   "反证栏""接住它"之类的流程标签；"改后句""已覆盖""留此备用"之类的
   修订痕迹；"边角料箱""素材留底"之类的组稿区；报送抬头、定位说明等
   模板残留；写给生成流程自己看的任何说明文字。
   原则：脚手架删除，但其中有价值的内容改写后融入正文，不得连内容
   一起扔。

2. 伪精确引证：字母数字编码式引注（C1/E5/S2等）、"检索核实"式自我
   背书、来源与断言不匹配（科普聚合站撑学术结论、一条引注坐实多国
   事实、精确计数配模糊出处）、同一数据被反复调用支撑不同论点。
   处理：编码全部还原为自然引述（作者＋年份＋刊物/机构）；来源可疑
   处降调为"有研究指出"，不得伪装成硬引证。

3. 句式复读：同一修辞结构全文出现三次以上即为复读。重点排查：
   "不是A，而是B"、三段式排比＋降格收束（"任何一环薄弱都会使X从Y
   退化为Z"）、每章末尾同构的总结句、全部章节标题同一句法。
   处理：每种结构全文至多保留一处（用在最核心的判断上），其余改写。

4. 高频过渡词与生造术语："换言之""综观""综合来看""这一X表明/提示"
   等过渡词减半；生造的复合词（"落条款级""标准悬空"类）改为常规
   表述，确有含义、无可替代的至多保留一个。

5. 数据堆砌：统计数值（效应量、百分比、样本量）逐一判断是否为结论
   所必需。呈报类文体只保留文字结论，数值删除或移入附注；承载核心
   事实的具体数字（如某项标准的分数线）保留，装饰性数字删除。

## 阶段二：观点判断清晰化

前提：本文体要求给出明确判断（见文稿背景；若文体允许开放讨论，
本阶段仅执行"表述规范"部分，三条规则不启用）。

反证和争议信息不删除，但必须改变其功能——从"两说并陈"改为
"已虑及、已排除"。三条规则：

规则一：判断前置，反证做垫脚不做对手。每处反证压缩成一句，置于
结论之前或之中，作为结论的支撑条件。禁止任何段落以让步收尾
（"但也有研究认为……"结尾即违规）。

规则二：读者可能追问的争议，用一句"预答辩"闭环处理：一句话完成
"我知道有此争议→该争议恰恰支持本文方案"，不单独成段展开。

规则三：构成执行约束的保留条件（前提、适用范围、顺序要求），从
论证章节移出，直接写进建议/方案的执行条款里，变成硬性要求。

判断句的表述规范：
- 禁止使用"判断明确：""结论明确：""我们的选择应当明确："等任何
  标签引出结论，判断力度由规范措辞本身承载（应当/宜/不宜/须/
  不应予以采纳）；
- 结论句不得压缩成脱离论证的口号，须回到其论证来源展开为自含的
  完整表述；文中的简称指代（如"三项条件""上述边界"）在结论处须
  写出实指内容，各章应可独立成读，不依赖跨章交叉引用；
- 人称统一为正式口径（我国/国家层面/无主语公文句式），不用
  "我们""我方"等非正式人称。

完成后自查：每一章是否都以明确的判断句收尾？全文核心主张能否用
一句话复述？

## 阶段三：术语白话化

对照读者身份，排查所有专业术语（测量学、统计学、学科行话，如
常模、信效度、元分析、效应量、预测效度等）：
- 正文一律改为白话表述（如"常模"→"分数分布参照基准"），改写时
  不得损失原义；
- 若成稿需下发专业执行部门，可在建议/条款部分以括号形式保留术语
  一次，作为口径对接；其余位置不得出现；
- 术语改写与数字取舍遵循同一标准：读者读得懂、判断不失真。

## 阶段四：输出

1. 输出完整成稿；
2. 附改动说明：分阶段列出改了什么、为什么；
3. 单独列出"需要作者定夺"的位置：凡是替作者往前推了一步的地方
   （如替作者把方案定死、加重了措辞力度、删掉了作者可能想保留的
   内容、保留了可删可不删的技术条款），必须明确指出，交由作者
   裁量，不得静默处理。
