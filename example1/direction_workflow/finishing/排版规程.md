# 排版规程（交付工序二：初稿·可阅读 → 初稿·可交付 docx）

> 2026-07-13 入包。脚本：`tools/neican_docx.py`（真源 `<内部仓库>/scripts/neican_docx.py` 的只读快照，头注注明出处）。
> 图纸依据：元模块契约·契约⑥（排版交付元模块）；调度宪法 §三运行形制。

---

## 1. 执行引擎与依赖

- **执行引擎：agent 跑脚本**（本模块无生成任务，agent 只做格式中转与命令执行，不改动文字内容）。
- 依赖：`python3` ＋ `python-docx`（安装：`pip install python-docx`；2026-07-13 本机实测 1.2.0 可用）。

## 2. 输入 / 输出

| | 文件 | 说明 |
|---|---|---|
| 输入 | `runs/<id>/outputs/初稿_可阅读.md` | 清稿规程的产出 |
| 输出 | `runs/<id>/outputs/初稿_可交付.docx` | 教科院课题组研究报告体／内参版式（A4；标题小二黑体居中；一级"一、"三号黑体、二级"（一）"三号楷体；正文三号仿宋、首行缩进 2 字、固定行距 28 磅；行内加粗保留；政策文件《…》就地标注不加角标） |

## 3. 操作步骤

1. **格式中转**：脚本约定输入为"课题组干净体"md（第 1 行＝标题、第 2 行＝署名、`一、`/`（一）`行首标题、行内 `**…**` 记加粗）。agent 现场把 `初稿_可阅读.md` 转为中转稿（存临时目录，**不入 runs/**）：
   - 首行标题去掉 `# `；第 2 行补署名行（含"课题组"；无真实署名时用占位并**记入需作者定夺清单**）；
   - `## 一、…` → `一、…`；`###（一）…` → `（一）…`；
   - 列表项去掉行首 `- `／`* `，转为独立段落；
   - 删去 `---` 分隔线、`> ` 引导块等纯 markdown 结构行；
   - 除 `**…**`（脚本负责转加粗）外，中转稿不得残留任何 markdown 记号（`#`、`>`、`|`、行首 `-`）。
2. **执行**：`python3 tools/neican_docx.py <中转稿.md> runs/<id>/outputs/初稿_可交付.docx`
3. **自检**（见下节），通过后交付。

## 4. 产出后自检（三项，必做）

1. **文件可打开**：用 python-docx 重新打开产出 docx，能读出段落且段数与中转稿量级相符；
2. **标题层级正确**：文题居中；`一、…九、` 各级独占一行且不缩进；正文段首行缩进；
3. **无 markdown 残留符号**：全文文本检索 `#`、`*`、`|`、行首 `-`、`>`，零命中。

任一项不过：修中转稿重跑，**不得手改 docx**；三项读数记入交付说明或改动说明。

## 5. 边界

- 排版模块**不改动文字内容**——发现文字问题退回清稿工序，不在本工序处理；
- 真源 `scripts/neican_docx.py` 改动后须重新快照 `tools/neican_docx.py`（含头注日期），勿只改快照。
