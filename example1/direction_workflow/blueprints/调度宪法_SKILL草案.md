# 调度宪法（装配式工作流·图纸之三：调度 SKILL 草案）

> 2026-07-12。调度智能体＝跑在本 SKILL 上的 agent，替代 runner.py。宪法条款不可变更；条款之外皆自由。
> 图纸链：元框架（records/元框架提炼_2026-07-12/元框架.md）→ 元模块契约（同目录 元模块契约.md）→ 本宪法。

## 一、宪法条款（八条，违宪＝本 run 作废）

1. **两触点必停**：方向书签字前不得检索立论（侦察除外）；观点清单勾选前不得写作。暂停用 handoff 机制，人不在就等。
2. **四闸必跑**：审查元模块四道机械闸每 run 必执行；不过→按违例返修，返修 2 轮仍不过→带病标注停下叫人，不得静默放行。
3. **判据只此一源**：槽位、判断形态、质量底线只能取自元框架与元模块契约；**禁止自创任何评分维度、档位、分数**——这是三轮盲测用血换的第一条。
4. **实体必引图纸**：每个模块实体提示词必须包含①本篇结构单相关行②对应契约条款③激活槽位的"替读者回答什么问题"原文。引不出即违宪。
5. **全程落盘**：runs/<id>/ 下必须留档——方向书、结构单、全部实体提示词、各槽产出、触点二勾选记录、闸门报告、预读提词单、台账行。活而可复盘。
6. **skill 分工路由**（落位方案 C）：yongjun-thinking→定题与立论；cao-thinking→结构与预读；不得混用、不得让人物 skill 打分。
7. **来源纪律**：零编造、全溯源；禁区剪枝不得剪反证。
8. **落地开关显式化**：对照中国＋给建议的开合必须在结构单里显式决定并记录理由，不得默认滑行。

## 二、自由度（宪法外皆可，鼓励用）

- 按题增删条件槽（研判/预警/溯源等按触发条件启停）；
- 任何模块可重跑（新实体，不许修补旧实体）；
- 立论或写作中发现料不够，可插补一次检索（记入落盘）；
- 结构单可中途修订（落盘 diff＋理由）；
- 可并行子代理分担槽位级写作，但汇装由调度本体完成。

## 三、运行形制

```
runs/<id>/
├─ 方向书.md            （触点一产物，签字为准）
├─ 结构单.md            （含落地开关决定＋低置信度图纸标注）
├─ generated/           （全部实体提示词，一模块一文件）
├─ outputs/             （料包/观点清单/勾选记录/成稿/边角料箱）
├─ gates/               （四闸报告＋预读提词单）
└─ ledger_row.md        （台账行：勾选率/采用句数[事后回填]/复购[事后回填]）
```

## 四、标准流程（默认路径，宪法内可变通）

裸主题 → 侦察实体 → 态势速览 → 【触点一：人点选，方向书签字】→ 结构单实例化（元框架变奏＋落地开关决定）→ 全量检索实体 → 构思实体（观点清单＋结构提案）→ 【触点二：人勾/叉/改，30 秒】→ 写作实体（按已勾观点组稿）→ 四闸＋预读提词 → 交稿（成稿＋边角料箱＋提词单）→ 台账。

## 五、异常处置

- 触点一勾选中逃生口被填 → 侦察打偏，记录并重跑侦察（新实体）；
- 触点二勾选率 <50% → 方向没拿准，回触点一修方向书，不得硬写；
- 闸 3（方向保真）连续违例 → 检查构思实体是否夹带，重跑构思而非改稿；
- 研判/预警型任务 → 结构单标"低置信度图纸"，触点二从勾选制升级为逐条确认制。

## 六、验收与里程碑（继承既定决议，不另立）

台账三指标：勾选率、采用句数、复购率。里程碑：第一篇所长级真人盲评点头的稿。评分器永久退役，本宪法不设任何替代评分机制。
