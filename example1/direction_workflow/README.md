# direction_workflow — 装配式政策报告工作流

> 总装完成：2026-07-13。分支 `fix/dna-governance`。领班制施工，七工包全部落地。
> 一句话：把"写一篇政策报告"拆成**装配工现场造流水线**——不是一个大模型硬写，而是按三张图纸（元框架/元模块契约/调度宪法），从裸主题现场装配「侦察→定向→检索→立论→勾选→组稿→四闸→预读」的本篇专属流水线，人只在**两个触点**出场（点方向、勾观点），机器守**四道闸**兜下限，全程留档可复盘。

## 三、怎么接单（给下一个使用者）

1. **触发装配工**：对装配工 skill 说「接单：<你的主题>」或「装配一篇报告」。它会读三张图纸、建 `runs/<日期-主题缩写>/`。
2. **触点一（你出场）**：它跑侦察给你一页态势速览，你对着分歧轴点选、填方向书六栏（议题/倾向箭头/读者层级/用途类型/禁区/半成形直觉），≤1 分钟，点选为主。**逃生口被你填 = 侦察打偏，它会重跑侦察。**
3. 机器据方向书实例化结构单、真联网全量检索、立论出观点清单（约 10 行可错判断句）。
4. **触点二（你出场）**：逐行勾/叉/改观点清单，约 30 秒。**勾选率 < 50% → 回触点一修方向书，不硬写。**
5. 机器组稿 → 跑四闸（不过按违例返修，2 轮不过带病叫你）→ 出预读提词单（永军/曹的考题，供你报送前自备）。
6. **触点三（你出场）**：收货，写使用体验、回填台账「采用句数」。
7. 交付：成稿＋边角料箱＋预读提词单，全在 `runs/<id>/`。
8. **报送成稿导出**：内参版式 docx 用仓内 `scripts/neican_docx.py`（见下方遗留清单，尚待真人单接入验证）。

**铁律（你和机器共守）**：判据只取自图纸，禁止任何评分/档位/分数；不注入文风规则；每步实体提示词必引图纸原文；零编造全溯源、禁区剪枝不剪反证；两触点必停、四闸必跑。

### 4.4 工包五·真流程首单（拔尖创新人才培养·早期发现）

- 形态：**装配工代理与写作者代理由两个互相独立的全新子代理担任，领班居中传递文件**——真实预演"人机两触点"交互。
- 装配工（`[ASSEMBLER]`）：到触点一/二**真停**、落待决材料、报告领班；领班转写作者决策后 SendMessage 续跑。全程真联网、真调 yongjun/cao、四闸真跑返修 0 轮、插补检索 1 次（查实沃土/脱颖官方未公开识别口径，负向证据反坐实承重判断）。
- 写作者（`[AGENT-WRITER]`，人设=教科院研究员）：三次触点出场——①对态势速览自选聚焦角度「早期发现」并签方向书（借鉴型/部党组）；②逐行勾选观点清单，**勾选率 91%**（勾 8＋改 2＋叉 1）；③收货写使用体验。
- **写作者代理的使用体验（原话要点）**："可作报送底稿直接采用，不需返工；剩下是署名前该亲自过手的三处轻活（亲核负向证据、压'推动立法'口径、擦内部锚记号），不是推翻重写。"聚焦守住、观点是所勾那批、无夹带、存疑边界诚实兑现、禁区干净。
- **自估可直接采用句数**：约 34／42 句（约 80%）——**代理自估、非真人，须留真人单校准**（已如此标注入台账）。
- 两代理**无串档**：写作者只接触面向撰写者的产物（态势速览/观点清单/成稿），装配工只读最终方向书与勾选记录，各自身份档分文件独立。
