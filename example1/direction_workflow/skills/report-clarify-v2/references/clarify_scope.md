# 定向生成逻辑要点 v2（路线判定 / 侦察口径 / 方向书六栏预填）

> 供 `report-clarify-v2/SKILL.md` 各步引用的判定细则。本文件是 skill 内部资产。
> v2 与原版差异：产物从 clarify_decision.md 改为《方向书》；Q3 核心观点→倾向箭头；Q2 体例→用途类型（三类型学）；
> Q4 维度逻辑降级不问；Q5 文风子型撤；新增禁区（必答）与半成形直觉（选填）。

## 一、路线判定判据（SKILL 第①步）

**判"问题已明确"须同时满足三条**（缺一即走侦察路线）：
1. 有明确研究对象：具体国家/国家组 + 具体政策领域（"美国 AI 人才战略"明确；"终身教育""国外教育科技"不明确）。
2. 有可判的问题形态：能改写成一个判断句或"研判 X / 借鉴 X / 比较 X / 追赶 X"句式。
3. 落点无歧义：看得出用途类型（借鉴/趋势研判/差距追赶）中的哪一种，且读者层级可判。

**兜底规则**：三条中任何一条拿不准 → 按"模糊主题"处理，走侦察。误把明确当模糊只多花几分钟侦察；误把模糊当明确会定偏整个方向锥体——代价不对称，宁可多侦察一步。

**明确路线也可选看侦察**：满足三条的用户默认直填方向书，但若其倾向箭头拿不准（想看看各方在吵什么再站队），允许补跑一次侦察辅助点选。

## 二、侦察模式的口径（SKILL 第②步，委托 topic-material-search-v2 scout mode）

- 目标是**够点选定向**，不是够写作：十几条权威线索、分钟级，覆盖到"能摆出分歧轴"即停。
- 搜索式取"主题词 + 政策/战略/白皮书/纲要/OECD/UNESCO + 近 2 年"，优先命中：最新官方文件、国际组织报告、权威统计、标志性事件、以及**各方争论点**（分歧轴的原料）。
- 产出＝态势速览四栏（见 templates/态势速览模板.md），非料包文件；**不做**全量六类检索、DS 审校、跨类去重（那些是 topic-material-search-v2 全量模式）。
- 线索不足（<3 条 T1/T2）：如实写"公开线索不足，建议换角度或方向书签字后用全量模式深挖"，列出已有的。
- 无联网权限：态势速览全页标 `[SIMULATED]`，据模型常识构造合理态势供流程测试，并在交付时显著告知"侦察为模拟，真实检索待补"。

## 三、态势速览→方向书的翻译（SKILL 第③步）

态势速览四栏与方向书栏的对应：
- **分歧轴的两端** → 方向书"倾向箭头"的具体候选（撰写者选"站哪端"）。反锚定：两端中立对称，措辞无褒贬。
- **候选研究问题** → 方向书"议题"（勾一个感兴趣的带出，或据其自述）。
- **反直觉信号 / 数据缺口** → 勾撰写者问题意识，可能落入"半成形直觉"或收窄议题。
- 任一栏逃生口被填 ＝ 侦察打偏，记录并回头修侦察策略。

## 四、方向书六栏的预填默认项规则（SKILL 第④步）

自动判定**只做预填**，呈现时标注"推荐"，由用户改选或确认：

- **议题**：从 ③ 勾选的候选研究问题带出；用户直填模式则用其自述，收敛成一句话话题。
- **倾向箭头（可多选）**：
  - 跑了侦察 → 选项 = 各分歧轴的两端（"轴A左端 vs 右端"）+ 通用箭头 + 逃生口；**不预设默认端**（反锚定）。
  - 未跑侦察 → 用通用箭头：🔴警惕 / 🟢借鉴 / 🟡观望 / 🔵追赶 / ⚪存疑 + 逃生口。按用途类型给弱提示（借鉴型常配🟢借鉴、趋势研判型常配🟡观望、差距追赶型常配🔵追赶），但仅提示不预勾。
- **读者层级**：从议题落点高度预填——涉国家全局布局/国际竞争位次 → `national_leader`；涉部级制度设计/政策工具 → `moe_leadership`；涉具体工程/试点/操作 → `bureau`。判不出 → 预填 `moe_leadership`（内参最常见档），并说明理由。
- **用途类型（三类型学，永军 B4）**：按判据预填——
  - **借鉴型**：我方有一个明确问题，看国际怎么做（如课外辅导治理）。特征：问题在我方，答案去国外找。
  - **趋势研判型**：人家都在动、我方还没大动，要判断这股势往哪走、到哪个阶段（如 AI+教育）。特征：多国零散新信号，判断"往哪走"。
  - **差距追赶型**：我方也做了但落后，别人又出新方法，要盯差距（如某技术代差）。特征：我方已在场，比的是新旧代差。
  - 用户在 ③ 已选候选问题时，直接带出该候选标注的用途类型。判不出 → 预填趋势研判型（信息最少时的稳妥档），说明理由。
- **禁区（必答，可为"无"）**：默认不预填内容，直接问"什么不碰/不想说/篇幅红线"，给"暂无明确禁区"勾选项兜底。若议题涉明显敏感区（部门责任划分、某国别、某提法），可温和提示"是否要把 X 列入禁区"，但不替用户圈定。
- **半成形直觉（选填）**：默认留白。仅当用户在 ③ 或对话中已流露某种预感时，把它回述为一句供其确认，不逼、不硬凑。

## 五、方向书.md 的固定格式（SKILL 第⑤步）

用 `712测试/templates/方向书模板.md` 的六栏格式落盘，栏序：议题 / 倾向箭头 / 读者层级 / 用途类型 / 禁区 / 半成形直觉。

**机械签字校验**（模板末尾栏，逐条可查，任一硬栏缺失即报错退回）：
- 议题非空
- 倾向箭头 ≥1 项（含逃生口填写视为已选）
- 读者层级、用途类型各选定 1 项
- 禁区栏已表态（含勾选"暂无"）
- 半成形直觉栏空缺**不**判为不合格（选填项）

落盘位置：沙箱测试写 `712测试/testruns/<测试单目录>/方向书.md`；真实使用写 `runs/<run-id>/方向书.md`。
