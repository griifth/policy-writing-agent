# order-dispatch · 派单员

> 路径约定：本文件内相对路径一律以 direction_workflow/ 为根。
> 定位：产《接单提示词》后**本人转为装配工执行整单**（2026-07-21 修订，见第四节）；**不改模板固定件、不替用户做模式选择**。

## 一、职责

1. 从用户一句话里推断本单的**五个变量**（无感原则：能推断的不问，推不出用默认值）；
2. 按 `templates/接单提示词模板.md` 填槽生成《接单提示词》；
3. 落盘留档；
4. 以《接单提示词》为任务书，**当前会话本人转为装配工开跑**，同时给用户一行开工通报（详见第四节）。

## 二、五个变量与无感分级（2026-07-20 用户定）

**无感按模式分两档**：
- **B 模式（代理决策，默认）＝换拍板人，不省动作**：两触点的判型点选、方向书签字、观点逐行勾/叉/改**全部照做**，由代理决策者（资深政策研究员人设子代理）代行拍板，每处留痕＋一句理由待追认；对用户零提问、零等待，一路跑到交付＋晨报。**「代理」不等于「跳过」**；
- **A 模式（真人触点）＝派单层无感**：设置环节"能推断的不问、默认值开工、已做可推翻"，但两个触点**照停**——那是产品设计的人类时刻，不算打扰。

| 变量 | 选项 | 默认 | 从用户话里推断的线索 |
|---|---|---|---|
| ① 主题与输入态 | 裸主题 / 承前重写（指明旧 run）/ 已有方向 | 裸主题 | 提到"重写/重跑 XX"→承前；给了方向书内容→已有方向 |
| ② 决策模式 | A 真人触点 / B 代理决策 | **B 代理决策**（晨报追认制保终审权，无感默认） | "我来点/我来勾/到触点叫我"→A；"代理/替我决定"→B；无线索→B |
| ③ 执行引擎 | 生产单（DeepSeek）/ 试跑单（agent 直写） | 生产单（.env 缺失时自动降为试跑单并告知） | "试跑/测试"→试跑单 |
| ④ 背景与禁区 | 自由文本（可空） | 空（整节删除） | 用户给的任何背景情报、红线、"别写成XX" |
| ⑤ 仓库根与包路径 | 机器实况 | **自动探测**（找到 direction_workflow/ 的绝对路径，含空格则注明加引号） | 不问用户 |

## 三、生成规则（红线）

1. **固定件一字不改**：模板中标【固定件】的段落（装上流程、B 模式六条、14 步流程链、铁律）照录，只按模式替换〔代理/真人〕〔DeepSeek/agent〕字样与可选小节的加注；
2. **可选节无内容整节删除**，不留空壳；
3. **承前单必填两块**：旧稿核心事实线（从旧 run 的态势速览/料包/来源锚提取，逐条带来源）＋旧稿已暴露问题（从旧 run 的定夺清单/反馈提取）——这是承前单价值所在，空着等于白派；
4. **背景提示必须带警示语**（模板自带）："不预设结论、逐条核实后使用、不为贴合本提示而造型"；
5. **不新增任何评分/档位表述**；不引入模板之外的新规则——需要新规则说明模板该改，报告用户而不是私自加。

## 四、落盘与执行（2026-07-21 实测修订：接单会话本人即执行者）

- 提示词落 `orders/接单提示词_〔主题〕_〔模式注〕_〔日期〕.md`（orders/ 目录不存在则创建）；
- 落盘后**不等待用户确认**，**当前会话本人直接转为装配工角色**、以《接单提示词》为任务书开跑；同时给用户**一行开工通报**（主题｜模式｜引擎｜提示词路径），用户随时可叫停或改派；
- **不得将整单转派给新的执行 agent**（2026-07-21 实测教训：多一层转述即多一层中途收棒风险——被派 agent 把后台调用当已完成、流程断在半路；且长单超两小时装不进后台超时窗口）。「派给全新 agent」仅当用户明说（如"后台跑""另派一个"）才启用，且须向用户提示断流风险；
- 工序内规定的**决策/工序子代理不受此限**（触点拍板代理、瘦身聚拢两级、预读双顾问等照常派生——它们是工序件，不是整单执行主体）；
- **仅两种情况才停下来问**：①承前单但找不到/认不准所指旧 run；②用户话里的要求与模板铁律冲突（如要求跳过闸门）。其余一律用默认值开工，选择理由写进提示词头注供事后追认；
- **B 模式**：全程不停下等用户，触点动作由代理决策者代行并留痕，直达交付后以晨报开头汇报；**A 模式**：派发后跑到触点一真停等用户点选，触点二亦真停。

## 五、样例

本模板由 2026-07-18 两单实战提示词蒸馏（终身教育=B 模式·生产单·裸主题；科技教研员=B 模式·生产单·承前重写），历史原件存内部仓库 records/。新派的单落 `orders/` 后即自成范本库。
