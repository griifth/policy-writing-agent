## 2. 论文侧观察

1. **选题起点**：多个议题从国家战略与教育现实之间的结构性矛盾起步。例如教育评价文围绕“新技术/旧标准、单向度/多模态、高赋能/高负担、技术性/伦理性”；科学教育文从国家战略、现状进展、认识误区再到路径。
2. **材料组织**：常用“历史或政策脉络 → 现状/案例或比较 → 类型化或机制解释 → 本土路径与治理边界”。平台国际比较以发展阶段和 9 个平台为材料，再归纳 3 种模式、落到四类策略；不是直接把案例逐项罗列。
3. **判断生成**：判断常将技术/资源问题重构为组织、能力、治理和人的问题。例如平台从资源集成走向能力集成；数字化从点状应用走向全域赋能；评价强调动态模型和人机协同。
4. **边界与担责**：多篇文本主动保留技术决定论、伦理、隐私、安全、公平、教师负担及治理责任等反作用，未把技术使用量等同于教育变革。

## 4. 与 V1 的逐条差异

| V1 项 | V2 状态 | 依据/处理 |
|---|---|---|
| 读者三层级 | 证实并扩充 | 多源互证，保留为主干；注明并非所有文体的固定分类。 |
| 三层兼备/上挂下落 | 证实并改写 | 加入论文的战略—机制—场景贯通；“顶天立地”正确归为曹/永军合源。 |
| 观点鲜明、维度逻辑 | 证实并去评分化 | 改写为“可反驳判断”和“复述切分轴”。 |
| 纲领文件锚定 | 从低置信提升为中置信 | 论文补足了政策锚定行为，但会议无直接“必须引用”原话；只生成具体挂接问题。 |
| 三翻模拟 | 维持 | 会议实证强；加入“每句引原文位置”的硬约束。 |
| 文风规则 | 明确排除 | 会议当场决定不限制风格，且本轮靶心明令排除。 |
| 技术—教育—治理边界 | 新增条件性镜片 | 论文高频、会议弱；仅用于相关议题。 |
| 作者等于审稿人 | 证伪为可直接推断 | 论文不能充分复现审稿口味，保持构思顾问定位。 |

## 5. 运行边界与责任

- 不评分、不定档、不排名、不把任何镜片改成“有没有 X”的清单。
- 不输出语言风格或角色模仿；不把论文中的个别方案当作本人对新议题的固定立场。
- 对政策只使用 `references/纲要地图.md` 中已核验的正式文件；文件失效、更新或无法定位时，明确标注待核。
- 所有最终判断、取舍和报送责任仍由用户/业务负责人承担；本 skill 只提供问题、模拟和可选结构。

## 6. 自测记录

### 用例 1：虚构结构提案（结构提案侧）

输入：三章“国际做法”，结尾两条建议，未说明面向谁、比较轴和政策关系。

输出检查：应提出“比较是在找趋势、类型还是可移植机制”“两条建议由谁改变什么”“每条往上可对照哪项教育布局”等问题，并给出可选择的重切轴；**没有**出现评分、档位或“是否包含国际比较/政策引用”的检查语句。通过。

### 用例 2：仓内成稿首屏（预读提词＋三翻模拟）
