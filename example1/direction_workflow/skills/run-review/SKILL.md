# run-review · run 回顾页与 runs 总览仪表盘

> 定位：run 文件夹即基层数据库，页面是其静态投影，**落盘有变动即可重建，重建幂等**。

> 路径约定：本文件内相对路径一律以 direction_workflow/ 为根。

> 配套文件（生成前先读）：
> - 抽取规约（字段映射真源·候选文件名·容错与推断规则；§六为总览页轻量摘要字段）：`skills/run-review/references/抽取规约.md`
> - 单页模板（六区一链＋联动 JS，数据占位符 `/*__RUN_DATA__*/`）：`skills/run-review/references/page_template.html`
> - 总览模板（run 卡片列表，数据占位符 `/*__OVERVIEW_DATA__*/`）：`skills/run-review/references/overview_template.html`

## 输入定位

- 给定 run-id → `runs/<run-id>/`。
- 给定 run 内任一文件路径（如某成稿）→ 向上反查所属 `runs/<日期-主题>/` 目录。
- 未给定 → 询问用户要回顾哪一单（不得自行挑一单跑）。

## 生成流程（四步）

**第 1 步·清点**：列出 run 目录在场文件，对照抽取规约 §二的候选文件名表逐类按序探测；在场但未入页的文件（`generated/*`、态势速览、改动说明、docx 等）只记清单。

**第 2 步·抽取**：按 `references/抽取规约.md` 把在场文件解析为 RUN_DATA JSON。任何文件缺失/解析失败不算错误——字段留空、记入 `extractionNotes`；**叉/改的观点、边角料、反证、`[待核]` 标记必须抽出**（红线 3）；sections↔viewpoints 联动优先用论证结构单，缺此件按规约 §三 推断并记 extractionNotes。

**第 3 步·替换**：校验 JSON 合法后，整体替入 `references/page_template.html` 的 `/*__RUN_DATA__*/` 占位符（转义规则见规约 §四）。模板一字不改；页面无评分、无外链、无网络请求。

**第 4 步·落盘＋自检**：写 `<run>/outputs/回顾页.html`（UTF-8），然后过自检清单（见下）。

**第 5 步·顺手重建总览**：每次生成/刷新任一单页后，顺手按下节流程重建 `runs/回顾总览.html`——总览永不落后于单页。对已有页幂等覆盖。

## 总览页生成流程（「重建总览」／「回顾全部」收尾共用）

**第 1 步·扫描**：列出 `runs/` 下全部 run 目录（含只有方向书的容错单，一个不漏），按 run-id 倒序（新单在上）。

**第 2 步·轻量抽取**：按 `references/抽取规约.md` §六，对每个 run 只抽摘要字段（runId｜标题｜日期｜判型/用途类型｜勾选率｜执行引擎｜在场产物清单｜有无回顾页），**不做全量抽取**。缺件留空、记入 extractionNotes。

**第 3 步·替换**：校验 JSON 合法后，整体替入 `references/overview_template.html` 的 `/*__OVERVIEW_DATA__*/` 占位符（转义规则同规约 §四）。模板一字不改；页面无评分、无外链、无网络请求；状态徽记只许"在场/缺件"事实陈述，禁止进度条、百分比完成度、红黄绿颜色分级。

**第 4 步·落盘**：写 `runs/回顾总览.html`（UTF-8）。重建幂等：同一批 run 状态连续重建两次，页面内容一致。

新增文件仅限各 `<run>/outputs/回顾页.html` 与 `runs/回顾总览.html`，其余一律只读。

## 红线（违反即返工）

1. **零分数零档位**：页面任何位置不得出现评分、星级、百分比健康度、"优/良/合格"。勾选率可显示（它是过程指标，须带上原文的"代理预演·非质量背书"字样，如有）。
2. **零编造**：页面所有实质文字必须抽自 run 文件原文；生成器不得新写任何结论、概括、评价性语句。区块空缺显示"本单无此件"。
3. **可见可捞回**：叉掉的观点、边角料、反证、`[待核]` 标记必须呈现（可默认折叠，不可省略）。
4. **只读**：对 run 目录只读；回顾页是唯一新增文件。
5. **模板不含人名**：page_template.html 与 SKILL.md 中不得出现任何真实人名；历史 run 内容含旧称谓原样展示，靠页脚声明兜底。
6. **抽取诚实**：解析不确定、字段靠推断、文件缺失——一律记入 `extractionNotes` 并在页面"数据抽取备注"中可见。宁可标"推断"，不可默默填。

## 自检清单（落盘后逐条过）

- [ ] 单文件、零外链（无 CDN/无外部字体/无网络请求），双击本地打开正常，浏览器 console 无报错
- [ ] 六区齐全；②主线链三级联动可用（点节→观点→料双向高亮，再点取消）
- [ ] 观点区：全部观点在列，勾正常显示、叉置灰、改并排原句/改句，每条带勾选备注与置信度
- [ ] 料包区：口径纪律原文在顶；边角料箱逐条带"为什么没用/可在哪用"原文
- [ ] 闸门区：违例清单原文照录，空清单显示"本闸无违例"；预检单 `<pre>` 原样呈现
- [ ] 预读提词区：两组顾问考题＋三翻模拟＋需作者定夺清单逐条在列
- [ ] 红线六条逐条自查（尤其：全页无评分性词汇、无新写概括句、模板无人名）
- [ ] 缺件位置一律显示"本单无此件"，extractionNotes 如实列缺/列推断
