# 信息与格式校对

> 本件系外来 skill（GPT 生成，原件存 ~/Desktop/信息与格式校对Skill/）落位 direction_workflow 的副本，2026-07-22 经用户拍板转正。
> 在流水线中的调用方式见 `finishing/信息与标点收束规程.md`（第13步排版前的收束核查，只用本 skill 的核查模式）。

## 工作原则

- 将“事实正确”“转述准确”“推论稳健”“格式规范”分开判断，不用搜索结果数量代替证据质量。
- 对可能变化的信息、具体政策文件、统计数据和用户给出的链接进行联网核查；优先使用发布机关、统计机构、法律法规数据库等一手来源。
- 不把规划目标、预测值、媒体转述或研究估算写成已经发生的统计事实。
- 不把“鼓励”“探索”“支持”等方向性表述扩写成“必须”“已经设岗”“已有编制”等制度事实。
- 只在用户授权修改时改文件；默认保留原件，另存带“修订版”或用户指定名称的副本。
- 不确定但无法查实的内容标记为“待核”，不得凭印象补全。

## 选择交付模式

按用户意图采用一种或组合使用：

1. **核查模式**：只给结论、证据和修改建议，不改原文。
2. **修订模式**：完成信息、逻辑、标点和版式修改，交付修订文件。
3. **对比模式**：比较两篇或两个版本，说明哪篇更好、各自问题及推荐用稿。

用户未明确时，评价类请求采用核查模式；“修改、改好、生成修订版”等请求采用修订模式。

## 执行流程

### 1. 读取并保护原稿

- 识别文件类型、篇章结构、作者原有语气和格式。
- `.docx` 必须同时使用可用的 Word 文档处理技能，并遵循其解包、编辑、打包、验证和渲染流程。
- PDF 先判断是否包含可提取文本；扫描件需要 OCR 时说明识别风险。
- 建立修改范围：信息、逻辑、标点、版式，以及用户明确排除的项目。

### 2. 建立待核事实清单

抽取所有可验证陈述，至少覆盖：

- 数量、比例、年份、排名、预算和覆盖率；
- 政策名称、文号、发布机关、发布日期、效力状态；
- 引文、转述、项目名称和机构名称；
- “首次、目前、近期、全国仅有、尚无”等强时效或排他性判断；
- 因果关系、国际比较与建议所依赖的前提。

政策研究或长篇报告需读取 [references/checklist.md](references/checklist.md)，按其中的核查矩阵留痕。

### 3. 核查信息

- 从官方原文反向核对，不只验证标题或搜索摘要。
- 同时记录“统计期”和“发布日期”，避免以新发布日期冒充新统计期。
- 检查分母、单位、地域、人群、时间范围是否一致；静态相除不自动等于覆盖率。
- 区分现状值、累计值、年度值、目标值、预测值和估算值。
- 对跨国比较检查定义是否可比；不可比时降低结论强度并解释限制。
- 若证据只支持部分内容，保留可证部分，删除或降调超出证据的部分。
- 所有关键修正保存可点击来源；最终交付按用户需要提供简明来源说明。

### 4. 检查内部逻辑

- 核对标题、分论点、缺口数量、原因数量和建议数量是否前后一致。
- 检查建议是否逐项回应前文问题，短期、中期、长期是否存在依赖倒置。
- 区分政策原文、作者判断和建议，避免三者混写。
- 检查概念是否漂移，例如“队伍”被改写为“独立岗位”、“协调机制”被改写为“法定机构”。
- 数据不足时先建议摸底、试点或评估，不直接给出虚假的精确配额。

### 5. 校对中文标点与文字格式

- 将中文语境中的英文逗号、冒号、分号、问号、叹号、引号和括号改为中文符号。
- 中文正文使用“”；引号内再用‘’。文件名、书名、政策名按语义使用《》。
- 并列成分使用顿号，完整分句按关系使用逗号或分号；范围优先使用“—”，解释插入语可使用“——”。
- 不机械替换数字小数点、百分号、网址、邮箱、文件路径、英文缩写、代码和必要的英文术语。
- 斜杠表达并列时优先改写为“、”“与”“或”；加号表达复合关系时根据语义改为“＋”或文字连接。
- 从文档提取纯文本后运行 `scripts/scan_chinese_punctuation.py`，逐条判断候选项，不得直接全局替换。

### 6. 修改与验证文件

- 优先最小化修改，保留原有样式、段落结构、表格、页眉页脚、脚注和引用关系。
- Word 文件使用 XML 级编辑时，必须重新打包并运行结构验证；不得仅修改解压目录后直接交付。
- 渲染全部页面或至少首页、修改密集页和末页，检查缺字、乱码、孤行、溢出、异常分页和纸张尺寸。
- 重新提取修订稿文本，确认旧错误表述已消失、新表述存在、中文标点扫描无未解释问题。

## 交付要求

先给结论，再给文件或问题清单。修订模式至少说明：

- 已修正的关键事实和概念边界；
- 仍无法独立核实的内容；
- 标点与版式处理范围；
- 验证结果和修订文件的绝对路径链接。

除非用户要求逐项校勘表，不罗列所有机械性标点替换。重大事实修改必须给出来源或在文档中保留来源线索。
