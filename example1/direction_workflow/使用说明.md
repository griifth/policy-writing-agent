# 使用说明——从配置 API KEY 到跑完一篇报告

> 读者：第一次拿到本包的使用者。照本文从上往下走一遍，约 15 分钟环境就绪，然后一句话跑出一篇决策咨询报告初稿。
> 三份文档的分工：本文＝**从零到跑通的路线图**；[USAGE.md](USAGE.md)＝跑单过程中两触点怎么操作、交付物怎么用的**操作手册**；[移植说明.md](移植说明.md)＝路径约定与平台差异的**部署参考**。

---

## 第一步：拿到包（约 2 分钟）

```bash
# Windows 先配 git 三项（防中文路径与换行问题，只做一次）
git config --global core.longpaths true
git config --global core.autocrlf false
git config --global core.quotepath false

# clone 到浅目录（Windows 建议 C:\proj\，Mac 任意）
git clone https://github.com/griifth/policy-writing-agent.git dw
cd dw
```

## 第二步：装 Python 依赖（约 1 分钟）

```bash
pip install -r requirements.txt
```

装的是两样：python-docx（排版导出 docx 用）＋ openai SDK（DeepSeek 引擎用）。Python 需 3.10 以上；Windows 命令用 `python`，Mac 用 `python3`。

## 第三步：配置 API KEY（约 1 分钟）

```bash
# Mac/Linux
cp .env.example .env
# Windows PowerShell
Copy-Item .env.example .env
```

打开 `.env`，**只需要填一行**：

```
DEEPSEEK_API_KEY=你的密钥
```

其余变量全部有默认值，且默认值就是本项目生产实测配置（deepseek-v4-pro / 600 秒超时 / 12000 token / 推理力度 max），不用动。密钥在 https://platform.deepseek.com 申请；`.env` 已被 .gitignore 排除，不会被提交。

> **没有密钥也能跑**：跑"试跑单"时立论与组稿由 agent 直写，不需要 DeepSeek。派单时说一句"试跑"即可。

## 第四步：装 skill（约 3 分钟，二选一）

**方式 A·装进 agent 的 skill 目录（推荐，可按名触发）**——Mac 是 `~/.claude/skills/`，Windows 是 `%USERPROFILE%\.claude\skills\`：

```powershell
# Windows PowerShell 示例（Mac 用 cp -R，命令见 移植说明.md 第二节）
$DW = "C:\proj\dw"   # 改成你的实际路径
Copy-Item -Recurse "$DW\skills\policy-report-assembler","$DW\skills\topic-ideation","$DW\skills\strategy-preread","$DW\skills\order-dispatch","$DW\skills\run-review" "$env:USERPROFILE\.claude\skills\"
```

装完须把装配工与派单员安装件里的相对路径替换为绝对路径——现成替换命令见 [移植说明.md](移植说明.md) 第二节（Mac sed 版）与第五节附注 3（Windows PowerShell 版）。

**方式 B·不安装，按路径读取**——对任意 agent 会话说"读取 `<包路径>/skills/policy-report-assembler/SKILL.md` 并遵照执行"，零配置，适合快速尝试。

## 第五步：自检（30 秒）

```bash
python gates/precheck.py README.md        # 应输出七项语域读数表
python -c "import docx, openai; print('依赖 OK')"
python engine/run_entity.py --help        # 无密钥也应正常打印用法
```

三条都过，环境就绪。

## 第六步：跑一单（你只说一句话）

在装好 skill 的 agent 会话（Claude Code 或其他具备联网搜索工具的 agent 平台）里说：

```
派单：<你的主题>
```

主题可以很模糊（"终身教育方面的"）也可以很具体（"十五五教师AI素养培训布局"）。手里有现成资料就顺手拖给它，机器会编目为用户供料、高优先使用。

**两种模式，按你想投入的程度选**：

| 模式 | 触发方式 | 你要做什么 |
|---|---|---|
| **B·代理决策（默认）** | 直接"派单：主题"，不加说明 | **什么都不用做**。机器全程代跑，触点由代理决策者代拍并逐处留痕；跑完给你一份 3 分钟能读完的《晨报》，你逐条追认或推翻 |
| **A·真人触点** | 派单时加一句"到触点叫我"或"我来勾" | 出场两次、合计约 90 秒：**触点一**（约 1 分钟）看一页态势速览，点一个"问题判型"、签方向书四栏；**触点二**（约 30 秒）对观点清单逐行勾/叉/改——勾了的话会一字不差成为小标题 |

派单员会自动生成本单《接单提示词》存入 `orders/`，然后当前会话自己转为装配工开跑（不转派）。全程 14 步：侦察→判型定向→检索→立论→勾选→观点逻辑确认→组稿→四道闸＋主线保真→预读提词→清稿→瘦身聚拢→排版。生产单一般 1–2 小时；**期间别合盖睡眠**（本地进程会被冻结），插电开盖锁屏即可。

## 第七步：收货（跑完后）

产物落在 `runs/<日期-主题>/`，主件与备查件：

| 文件 | 用途 |
|---|---|
| `outputs/初稿_可交付.docx` | **主件**——内参版式，对照定夺清单过一遍即可署名走报送 |
| `outputs/需作者定夺清单.md` | **必看**——机器替你往前推了一步的所有位置，逐条拍板 |
| `outputs/聚拢版_初稿可阅读.md` | 主件的 md 原文，想改文字从这份改 |
| `gates/预读提词单.md` | 领导可能会问的问题预告，报送前自己先答一遍 |
| `outputs/附件_边角料箱.md` | 正文没用上的好料（每条注明为什么没用），写自己的稿时最值得翻 |
| `晨报.md`（B 模式） | 全部代理决策点清单，逐条追认或推翻 |

交付时装配工会**多问一嘴**"需要出一张本单回顾页吗"——应一声，它就生成一张可视化回顾页（成稿每句话 ⇄ 背后观点 ⇄ 证据来源三级联动，被毙掉的观点和弃用材料也全部可见）。也可随时说"回顾这单"补生成；Chrome 里打开 `runs/回顾总览.html` 点"连接 runs/ 目录"可实时查看全部单子。

## 常见问题

- **报"缺少 DEEPSEEK_API_KEY"**：生产单才需要密钥；要么按第三步配 `.env`，要么派单时说"试跑单"。
- **Windows 控制台中文报编码错**：用 Windows Terminal，或先执行 `set PYTHONUTF8=1`。
- **docx 打开字体不对**：机器缺仿宋_GB2312/楷体_GB2312 字体，Word 会自动替换、内容无损；安装这两款字体即恢复内参版式。
- **换了 agent 平台（如 OpenClaw）联网搜索还能用吗**：能。检索指令是平台无关的，用执行平台自带的搜索工具；平台没有联网工具时侦察/检索会降级并如实标注。
- **机器给的观点/判型不合意**：A 模式当场改（判型有"以上都不是"逃生口、观点勾选率低于一半自动回头重来）；B 模式在晨报里推翻对应决策点、让它重跑相应工序。
- **这个系统不做什么**：不打分、不评优劣、不保证事实无误（保证每个事实可溯源，报送前关键数字仍需人工抽验）、不代报送——最终判断与署名权在你。
