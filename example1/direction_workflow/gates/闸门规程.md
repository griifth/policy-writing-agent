# 闸门规程（机械闸 · 零裁量执行规程）

> 路径约定：本文件内相对路径一律以 direction_workflow/ 为根。
> 所属：direction_workflow · 工包三：机械闸。上游图纸：`blueprints/元模块契约.md` 契约④（审查元模块，四道闸；此为包内快照，真源在 records/装配式图纸_2026-07-12/，见 移植说明.md）。
> 本规程管三道「LLM 辅助闸」的机械执行：**溯源闸 · 承重闸 · 方向保真闸**；第四道「语域预检」由本目录 `precheck.py` 机械承担，本规程只写死其触发规则。
> 四道既有闸之外，另有一组**「主线保真检查」**（机械预检族·四闸之外的并列项，见第五节）：**四道闸的称谓与道数不变、原样必跑**，主线保真不占闸序、不改「四闸」称谓，只作四闸之外的机械并列项（W1.3 契约修订案 修订五／DEV-03）。
> 铁律：每道闸**只产出「违例清单」**——把违例逐条摆出来，不下任何裁断、不给结论、不写"是否通过"。清不清、修不修，是人的事。主线保真检查同此铁律。
> 措辞纪律：本规程通篇不出现任何裁断口径的字样，只描述如何把违例清单产出来（守契约④的禁令：不留裁断器复辟的口子）。

---

## 通用约定（三道闸共守）

**输入**（每道闸都吃这几样，来自本 run 台账）：
- 成稿（markdown）；
- 方向书（`templates/方向书模板.md` 实例，六栏：议题 · 倾向箭头 · 读者层级 · 用途类型 · 禁区 · 半成形直觉）；
- 已勾观点清单（`templates/观点清单模板.md` 实例，仅取勾选为「勾」的行）；
- 料包（检索元模块产出，带来源的证据条目）；
- 机械预检单（`precheck.py` 对本篇的 stdout 输出）。

**输出形制**：每道闸一张违例清单。清单为空即写「本闸无违例」一行，不许省略、不许改写成结论句。

**零裁量口径**：闸门只能引用「具体条目 + 具体缺口」这类可核事实来登记违例；不得写"不够鲜明""不够深入""略显单薄"这类裁量措辞（契约④禁令）。凡登记一条违例，必须能指出对应的原文位置。

---

## 一、溯源闸 —— 产出「无来源事实清单」

**要问的唯一一件事**：这条事实，能不能回到一个可查来源？

**机械执行步骤**：
1. 逐句扫成稿，摘出所有**事实性陈述**——含数字、年份、国别做法、机构名称、条款名称、引述他人观点的句子。（纯过渡句、纯主张句不在此列，它们归承重闸管。）
2. 对每一条事实，回料包与成稿脚注/夹注找它的来源锚：
   - 命中来源锚（料包某条 / 文内标注的出处 / 可点的文件名或链接）→ 略过；
   - 找不到来源锚 → 登记为一条「无来源事实」。
3. 输出「无来源事实清单」，每条含：原文事实句（摘前 60 字）＋ 它在文中的位置（小标题或段序）＋ 缺口一句（"未见来源锚"）。

**边界**：料包里有、但成稿未标注出处的，仍登记（来源可回溯但未落到稿面，属可修的挂靠缺口）；这是把缺口摆出来，不是断言编造。是否补锚、如何补，交人工与撰写者。

---

## 二、承重闸 —— 产出「装饰句清单」

**要问的唯一一件事**：这句段首判断，抽掉它下面的证据，它还立得住吗？立不住才是承重句；抽了照样能空转的，是装饰句。

**机械执行步骤**：
1. 逐段取**段首判断句**（每段第一句里带主张/判断的那句）。
2. 对每一句做一次「抽证据试塌」：把该句所辖段身的证据条目（带来源的事实、条款、数字）遮住，只留这句判断，看它是否还能独立成立。
   - 遮掉证据后这句照样成立、换个主题也能用 → 它没被证据顶住，登记为一条「装饰句」；
   - 遮掉证据后这句悬空、无从落地（即证据一撤它就塌）→ 它是承重句，略过。
3. 输出「装饰句清单」，每条含：段首判断句（摘前 40 字）＋ 位置（小标题或段序）＋ 观察一句（"抽其下证据不塌，未被顶住"）。

**边界**：只登记「抽证据不塌」这一机械事实，不评判句子写得好不好。下架与否交人工。

---

## 三、方向保真闸 —— 产出「锥体外条目清单」

**要问的唯一一件事**：这个小标题（及其所领的主张），能不能回到方向书某一栏、或已勾观点清单某一行？回不去的，就是锥体外夹带。

**机械执行步骤**：
1. 逐个取成稿**小标题**，连同其领起的主张句。
2. 对每一个，做两路回溯：
   - **回方向书**：能否落到「议题 / 倾向箭头 / 用途类型 / 读者层级」某一栏，且不触碰「禁区」栏所列的任一项；
   - **回已勾清单**：能否对上某一行勾选为「勾」的观点句（可润色，语义须一致）。
3. 判定与登记：
   - 两路皆回不去（既非方向书某栏、又非已勾清单某行）→ 登记为一条「锥体外条目」；
   - 触碰了方向书「禁区」栏任一项 → 登记为一条「越禁区条目」，并抄出所碰的禁区原文；
   - 能对上已勾清单某行、但语义被改写到与该行不一致 → 登记为一条「语义偏移条目」，并抄出原勾选句与成稿句对照。
4. 输出「锥体外条目清单」（含上述三种登记，各注类别标签）。每条含：小标题原文 ＋ 位置 ＋ 回溯结果一句。

**边界**：观点句可润色、不可换意（契约③）。本闸只登记「回不去 / 碰禁区 / 语义被改」这三类可核事实，不裁量观点本身对错。

## 四、语域返修触发规则（写死，不留裁量）

语域一项不是独立的 LLM 闸，而是接 `precheck.py` 的机械读数：

- **触发线**：`precheck.py` 预检单第 5 项「军事化语域」命中数 **≥ 3** 才触发语域返修。
- **未过触发线**：命中数为 0、1、2 时，**一律不得以语域为由要求返修**（T02 教训：未过线不得在语域上重罚）。
- **过触发线之后**：产出「军事化语域违例清单」——直接照抄 `precheck.py` 预检单第 5 项列出的每一处命中（原文短语 ＋ 语境），逐处摆出，交撰写者按 `gates/register_blacklist.md` 第二节的处置规则改写（降级为可核事实陈述；乙类过强度受限门；丙类仅对方原话可引）。
- 词表用包内快照 `gates/register_blacklist.md`；本规程与 `precheck.py` 都引用此快照。其真源是 `strategic_response_workflow/shared_schema/register_blacklist.md`（仓库根下），真源改动后须重新快照进包，勿只改快照副本（见 移植说明.md）。
- **生造词/内部词扫描独立走 `gates/lexicon_blacklist.md`**：`precheck.py` 对成稿另做「生造词/内部词命中」扫描（`load_lexicon_terms()` 独立读 `gates/lexicon_blacklist.md` 丁类生造复合词／戊类内部术语外漏／己类学术模型名），与本第 5 项军事化语域**并列、互不合并**。军事化第 5 项照旧读 `register_blacklist.md`（甲乙丙三类并集）、`load_military_terms()` 逻辑与触发线（命中 ≥3）**原样不动、不放松**（DEV-03 / W1.4 图纸 ③）。生造词/内部词命中的违例登记不并入本军事化清单，改走「五、主线保真检查」第 5 项。

**注意**：触发线是一个机械命中的条数门槛，不是对稿件的任何裁断。命中 ≥3 只意味着「军事化语域违例清单」非空、需照单改写；它不对整篇下结论。

## 五、主线保真检查（机械预检族 · 四道闸之外的并列项）

主线保真检查是**四道既有闸之外的机械并列项**，同属机械预检族：**四道既有闸（溯源／承重／方向保真／语域预检）原样必跑、称谓与道数不改**，本项不占闸序、不改「四闸」称谓，只作四闸之外的一组机械检查。与四道闸同口径——**只产出「违例清单」，零裁量、不打分、不下结论**；返修指令只能逐条引用本项列出的具体违例（同四闸口径）。（依据 W1.3 契约修订案 修订五·消解冲突 C2；宪法条款2「四闸必跑」不受触动。）

**输入**（本项额外读两样，来自本 run 台账）：《论证结构单》（`runs/<id>/outputs/论证结构单.md`）＋本篇结构单（`runs/<id>/结构单.md`）。缺其一而无法机械比对的项，按「七、遇图纸未覆盖时」停下不猜。

**五项检查**（逐项出「齐／违例」；违例只列具体缺项、注文中位置，不写"不够齐/略欠"这类裁量措辞）：

1. **每节挂段？**——逐个取成稿小标题，看它是否归属铁三角某一主线段（表现／归因／建议，回溯结构单主线段-节问题链）。回不到任何一段的小标题 → 登记一条「游离节」违例（小标题原文＋位置）。
2. **标题序＝结构单序？**——取成稿标题顺序，与《论证结构单》定位定序（主线序：表现→归因→建议）逐位比对。某标题位次与结构单不一致（跳跃／交叉穿插）→ 登记一条「标题序偏移」违例（成稿标题序 vs 结构单序对照）。
3. **建议↔归因映射齐全？**——逐条取建议段的建议，看其是否标注了所回应的归因；逐条取归因，看其是否有对应建议。无映射的建议 → 登记「悬空建议」；无策的归因 → 登记「无策归因」（各注原文＋位置）。
4. **有无空段？**——对照结构单铁三角覆盖轴，看表现／归因／建议三段有无整段空置。某段在结构单标为应有、成稿整段缺 → 登记一条「空段」违例（注缺哪一段）。
5. **内部词表零命中？**——成稿正文对内部词／生造词／学术模型名是否零命中。词源即 `gates/lexicon_blacklist.md`（丁类生造复合词＋戊类内部术语外漏＋己类学术模型名），与闸4「语域预检」的 lexicon 扫描**同源同表**；`precheck.py` 预检单第 7 项「生造词/内部词命中」非零即逐处照抄为违例（原文短语＋语境）。庚类「语境慎用」（下行风险）单列提示、**不计入本项违例**（见 `lexicon_blacklist.md`，W1.4 图纸 Q4）。

**机检落点与脚本欠账**（如实登记）：
- 第 5 项由 `precheck.py` 第 7 项 lexicon 扫描机械承担（照抄命中）——**全机检、无欠账**。
- 第 2 项：`precheck.py` 打印「成稿标题序」（并在给出结构单参数时打印结构单标题序）供逐位比对；但**结构单序与成稿序的等序判定属脚本欠账**——结构单「主线段-节问题链」新格式的节序机检不可靠，等序判定按**本规程与人工先行**（执行者按上口径逐位比对登记）。
- 第 1／3／4 项：脚本不做，由本规程机械登记（挂段回溯、映射清点、空段对照结构单覆盖轴）——**规程先行、脚本欠账**（生造词判据"未见于公开政策文本"亦无法纯机检，机检只做已知样例定值扫描，判据本身归清稿规程＋人工，见 W1.4 图纸 Q3）。
- 凡出现无法机械判定的边界（如"建议/归因"边界含糊、小标题缺失无从回溯），按「七、遇图纸未覆盖时」停下不猜。

## 六、五张清单的去向

三道 LLM 辅助闸 ＋ 语域读数 ＋ 主线保真检查，各自产出的清单汇入本 run 的「闸门报告」：

- 无来源事实清单（溯源闸）
- 装饰句清单（承重闸）
- 锥体外条目清单（方向保真闸）
- 军事化语域违例清单（语域读数，仅当命中 ≥3 时非空）
- 主线保真违例清单（主线保真检查五项·四闸之外机械并列项，含内部词/生造词命中；语境慎用不入清单）

闸门报告只是这几张违例清单的汇总 ＋ 契约④规定的预读提词单（生成式提词，由审查元模块另出，不在本机械规程职责内）。**闸门报告不下总结论、不写整篇裁断**；返修指令只能逐条引用上述清单里的具体违例（契约④禁令：返修指令只能引用具体闸门违例）。

---

## 七、遇图纸未覆盖时

本规程只登记违例、不立法。若某篇出现四道闸口径无法机械判定的情形（如"事实"与"主张"边界含糊、小标题缺失无从回溯），**停止猜测**，把情形写进 `direction_workflow/_问题反馈录.md`，不自行加判据、不静默绕过。
