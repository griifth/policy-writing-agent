# 反馈：接单提示词执行主体定位 ＋ 回顾页常驻仪表盘（2026-07-21）

> 来源：2026-07-21 单《人工智能通识教育落地梗阻（代理决策）》全程实测后的用户反馈两条。
> 状态：**只落地为文档，先不改动任何 skill/模板/脚本**；候选方案待用户裁决后另行实施。

## 反馈一：接单提示词应让接单 agent 本人成为搬运工，而不是派生一个搬运工

### 用户原意

接单提示词（任务简报层）的接收 agent **本人即成为装配工（搬运工）**，按既定运行路线（宪法八条＋14 步）跑完全程；不是让接单 agent 再去派发一个"执行 agent"来当搬运工。

### 现状差异（本单实测）

1. **现行设计是多一层派发**：`skills/order-dispatch/SKILL.md` 第四节写明"落盘后不等待用户确认，直接派发：起一个**全新执行 agent**，把《接单提示词》全文作为其任务书"——即派单员起一个新 agent 当搬运工。
2. **实测暴露的问题**：
   - 被派生的执行 agent 在把第二版立论的 DeepSeek 调用挂到后台后就结束回合——把"已提交"当"已完成"，流程停在触点二第二轮之前，产物已落盘但无人接续；
   - 父会话只能 resume 续跑并叮嘱"每步等结果落地再走下一步"；
   - 最终用户明确指示"**你是执行的 agent，不要再派发 agent 去当执行的 agent**"，本单第 7 步（观点逻辑确认）起全部由主会话亲跑才顺利到交付（经过与结果已记入本单台账与晨报）。
3. **差异本质**：多一层 agent＝多一层任务书转述与"中途收棒"风险。简报层的设计初衷是"给执行者一份完备任务书"——而执行者应当就是拿到任务书的那个 agent 本人。背景执行还有 30 分钟硬超时，长单（本单约 2 小时）天然装不下。

### 候选落地方向（待裁决，先不改动）

1. **改 order-dispatch 第四节默认动作**：《接单提示词》落盘后，默认由**当前会话直接转为执行角色**开跑；"派给全新 agent"降级为显式选项（用户明说才起）。
2. **或在接单提示词模板铁律节加一条**："接单 agent 本人即执行者，不得将整单转派子代理执行；工序内规定的决策子代理（触点拍板代理、瘦身聚拢两级）不受此限"——把"执行主体"与"工序内子代理"区分写死。
3. 配套：`templates/接单提示词模板.md` 头注"你是政策报告装配工"的身份语义同步明确；`USAGE.md` 派单段相应更新。

### 影响面（评估用，未动）

- `skills/order-dispatch/SKILL.md` 第四节（落盘与派发）；
- `templates/接单提示词模板.md`（铁律节、头注）；
- `USAGE.md` 派单/执行段。

## 反馈二：回顾页应以 run 文件夹为基层数据库，做常驻仪表盘，不要随用随建

### 用户原意

回顾页不是"每次要用才跑一次生成器"的快照，而是一个**常驻仪表盘**：run 文件夹即它的基层数据库，持续存在、能反映 run 目录的最新状态（新落盘的闸门轮次、清稿、台账回填等），并支持多单总览。

### 现状

- `skills/run-review` 是触发式生成器：用户说"回顾这单"才抽取一次、产 `outputs/回顾页.html` 静态快照；
- 快照之后 run 目录再有新产物，页面不会自动反映，须人工重跑；
- 各 run 各自一页，没有跨 run 的总览入口。

### 候选落地方向（待裁决，先不改动）

1. **数据层不变**：`runs/<id>/` 仍是唯一真源且只读；仪表盘不另建数据库、不复制产物、不写回 run 目录。
2. **形态选项**（按成本从低到高）：
   - **a. 静态仪表盘＋自动重建**：保留现有单文件 HTML 路线，加一个总览页（run 列表）＋"run 目录变动后自动重跑抽取"的触发点（如每步落盘后由装配工顺手重建，或一条手动重建命令），保证页面始终最新；
   - **b. 打开即抽取**：仪表盘壳固定，打开时用脚本现场从 run 文件夹重建数据（build-on-open），无需守护进程；
   - **c. 本地 watch 小服务**：监听 runs/ 变化自动刷新——体验最好但引入常驻进程与依赖，需单独评估。
3. **红线沿用**：零分数零档位、零编造、叉/改/反证/待核可见可捞回、只读 run 目录、模板无人名——常驻化不改变这些约束。

### 影响面（评估用，未动）

- `skills/run-review/`（SKILL 定位由"生成器"扩为"仪表盘"，references 两配套件）；
- 可能新增总览页/构建脚本存放位置（需与宪法§三运行形制核对：新增文件落点是否越出"回顾页是唯一新增文件"的现行约定）；
- `USAGE.md` 回顾段。
