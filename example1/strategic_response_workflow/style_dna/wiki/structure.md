# structure.md

## 1. 通用结构范式（递进式）
多数政策研究报告采用如下递进逻辑链，适合“战略竞争分析+中国应对策略建议型”报告：

**摘要/开头**
- 高度浓缩：点明议题重要性、研究缺口/核心问题、方法/视角、主要发现/核心判断、对策方向。

**问题提出/引言**
- 宏观背景锚定：政策背景、技术趋势、国际动态。
- 问题化：指出当前研究/实践的缺口、矛盾或认知误区。
- 研究问题声明：明确本文要回答的核心问题（通常2-4个）。

**理论基础与分析框架（可选）**
- 引入特定理论视角（如“外化”视角、嵌入理论、行动者网络理论等）作为分析透镜。
- 定义核心概念，构建分析维度。

**国际经验/政策演进/历史脉络**
- 阶段性划分：按时间或逻辑划分发展阶段（如“起步探索→扩展推进→调整转型”）。
- 国别/区域比较：选取代表性国家/组织，从政策、实践、成效等维度进行比较。
- 提炼模式：从分散经验中归纳出典型模式、关键议题或共性特征。

**现状/机制/挑战分析**
- 对中国实践进展的描述：按维度（如平台建设、教学应用、机制保障）展开，可结合案例。
- 发现问题/矛盾：揭示深层结构性矛盾（如“新技术与旧标准”），常以多维矛盾形式呈现。
- 机制解释：运用理论框架解释问题成因（如治理真空、资本逻辑侵蚀、路径依赖）。

**对策建议**
- 多维并行建议：通常4-5条，从理念重塑、制度建设、能力提升、技术路径、生态构建等维度展开。
- 每条建议内部遵循“问题指向→政策工具/行动→实施机制→预期目标”逻辑。

**结语/讨论（可选）**
- 升华核心观点，指出研究局限，展望未来研究方向或政策演变趋势。

## 2. 结构变体（适合战略竞争分析型报告）
- **四段式**：背景与问题→国际比较与趋势研判→中国现状与差距分析→系统性对策建议。
- **“逻辑起点—中介—终点”式**：如“顺应现实需要→形成开放格局→提升话语权与完善体系”。
- **“蓝图—局限—超越”批判式**：先系统阐述国际主流方案，再批判性揭示其理论假设与局限，最后提出超越性路径。

## 3. 段落组织原则
- **主题句先行**：每段首句概括段落核心主张。
- **论证层次化**：观点→引证/数据→例证/案例→小结。
- **过渡衔接**：使用“鉴于此”“进一步看”“然而”“相形之下”等逻辑连接词，保持段落间推进感。
