# recommendation.md

## 1. 问题驱动原则：每条建议必须“师出有名”
- **问题-建议强对应**：建议部分的每一条（或一组）措施，须在前文“挑战/问题/短板”分析中找到明确对应项。
- **不建议无源**：避免提出前文未讨论过的全新问题领域下的建议，除非作为延伸讨论并有明确说明。

## 2. “问题指向—政策工具—实施机制—预期目标”四要素结构
每条健全的政策建议应包含以下四要素：
- **问题指向**：用1句话点明要解决的特定问题或要抓住的机遇。
- **政策工具/行动**：具体的手段或措施。例如：“设立…专项资金”“制定…技术标准”“建立…协同中心”“实施…试点项目”。
- **实施机制**：谁来做、如何做、依托什么载体。明确政府层级、部门、学校、企业、社会等多元主体的角色与协同关系。
- **预期目标**：此措施期望达成的可观察效果。表述为“以…”“进而…”“助力/支撑…”。

示例结构：“针对…（问题），应…（政策工具），通过…（实施机制），以期/从而…（预期目标）。”

## 3. 建议的合理性与可行性自检
- **政治与政策可行性**：是否符合国家现有大政方针与政策趋势？是否在现有体制框架内可操作？
- **财政与资源可行性**：是否考虑了成本、资金来源、投入产出比？对中西部地区/弱势群体是否具备实施条件？
- **技术与能力可行性**：所需技术是否成熟？实施主体（教师、管理者）是否具备相应能力？是否需要配套培训？
- **可持续性**：是短期运动式还是长期制度化安排？是否形成长效机制？

## 4. 建议的体系化与协同性
- **维度覆盖**：建议应覆盖理念、制度、能力、技术、资源、生态等关键维度，形成系统解决方案。
- **避免冲突**：各条建议之间不能存在逻辑矛盾或政策冲突。
- **国际经验本土化**：若借鉴国际经验，必须添加“利用…的本土化调试/根据我国…实际”等条件限定。

## 5. 建议语体特征
- 使用“需要”“应”“可”“亟需”等情态动词，体现专业判断而非行政命令。
- 常用排比式小标题来组织结构化建议（如“第一，构建……；第二，实施……；第三，健全……”）。
