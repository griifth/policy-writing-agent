# Style DNA Wiki

本目录由 `processed/style_excerpt_corpus.md` 蒸馏生成，用于政策研究报告工作流的文风控制。

- `voice.md`：政策研究声音与写作姿态。
- `structure.md`：文章结构和论证递进方式。
- `sentence.md`：句式、段落和表达模板。
- `forbidden.md`：禁用表达与常见失败模式。
- `recommendation.md`：政策建议写作和合理性标准。
- `self_check.md`：自动化审查分层规则。

注意：这些文件是文风规则，不是事实知识库。写作事实仍应来自 NotebookLM 检索材料和工作流中间产物。
