# self_check.md

## L1 硬性规则（必须满足，否则报告无效）
- [ ] 无乱码、无PDF抽取污染痕迹。
- [ ] 无AI身份暴露语（“作为AI”等）。
- [ ] 无口号化、文学化、口语化表达。
- [ ] 所有数据、引述均有明确来源（或标注为“本研究调查显示”等）。
- [ ] 核心概念在首次出现时已界定或注释。
- [ ] 建议部分与挑战/问题部分在逻辑上构成对应关系。

## L2 风格一致性（高度优先）
- [ ] 全文语气统一为“冷峻审慎”基调，无突兀的情绪化段落。
- [ ] 保持“现象→分析→判断”的论证节奏，不跳跃。
- [ ] 段落长度适中，信息密度高但可读。
- [ ] 术语使用前后一致，无混用。
- [ ] 全文贯彻“战略竞争分析+中国应对”的报告定位，不偏离主题。

## L3 内容质量（核心价值）
- [ ] 国际比较部分是否有实质性的模式提炼或趋势研判，而非简单罗列国别做法？
- [ ] 对中国现状/问题的分析是否触及结构性矛盾，而非停留于表面现象描述？
- [ ] 提出的建议是否具有创新性、可操作性，且针对诊断出的问题？
- [ ] 论证是否严谨，结论是否可证伪、可讨论？
- [ ] 是否体现了批判性思维（如对国际主流叙事的审慎、对技术决定论的警惕）？

## L4 政策研究声音（专业性呈现）
- [ ] 是否体现了基于证据的专业判断力？
- [ ] 是否保持了建设性的、面向未来的问题解决姿态？
- [ ] 价值取向是否清晰（公平、质量、人本、国家立场）且通过分析体现，而非直接宣告？
- [ ] 引用与理论运用是“为分析服务”还是“为引用而引用”？

## L5 用户纠错记录（迭代优化）
格式：`[日期] 问题描述 → 修改方案 → 当前状态`

示例：
- `2025-01-01 建议部分“加强顶层设计”过于空泛 → 修改为“建立由教育部牵头的跨部门协同机制，明确年度任务清单” → 已修正`
- `2025-01-02 引言段AI腔“接下来将从三个方面分析” → 删除过程引导句，直接切入第一方面主题句 → 已修正`
