# 任务
从知识库检索【主题】领域目标国家"政策N"（最新政策）的核心举措素材。
只做检索与结构化提取，不做分类、不做历史关联分析。

# 检索内容（逐项查找，宁全勿漏）

## 一、政策总体信息
- 政策N正式名称（中英）/ 发布时间 / 发布机构（中英）/ 文件性质

## 二、执行摘要与目录
- 执行摘要核心结论（逐条列出）
- 目录结构：逐部分/逐章列出标题（中英）及核心定位

## 三、战略形势判断
- 核心判断 / 竞争形态演变 / 竞争对手提及情况

## 四、具体措施（按目录结构逐部分提取）
针对每一部分，提取：
- 核心论点（一句话）
- 具体措施（逐条原文摘录，含责任主体+量化指标）
- 制度创新（新机构/新机制/新工具/新提法）

## 五、特殊要素
- 反制措施（针对特定国家的手段）
- 历史关联线索（仅记录名称及位置，不展开）

# 检索关键词
[政策N正式名称] / [政策N简称] / executive summary / table of contents /
national strategy / action plan / framework / 法案 / 战略 / 规划 / 计划 + 【主题关键词】

# 检索要求
- 只收录真实命中的素材，不臆测、不补全。
- 数据精确，保留原始表述。
- 执行摘要、目录、具体措施逐部分列出，不遗漏。
- "历史关联线索"仅记录，不展开。

# 输出格式

【政策总体信息】
政策名称 / 发布时间 / 发布机构 / 文件性质

【执行摘要核心结论】
逐条列出

【目录结构】
部分编号. 标题（中英）— 核心定位

【具体措施】（按部分逐条列出）
部分编号. 部分标题
- 核心论点：
- 措施1：[原文摘录，含责任主体+量化指标+制度创新]
- 措施2：[原文摘录，含责任主体+量化指标+制度创新]
- ……

【特殊要素】
反制措施 / 历史关联线索（仅记录）
