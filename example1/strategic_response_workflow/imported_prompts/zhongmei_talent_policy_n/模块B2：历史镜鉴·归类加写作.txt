# 案例公式（严格复刻附件风格）

**二是**……**三是**……"标记）→ 量化数据 → 制度遗产 → 历史评价 →
脚注[机构. 文件名. URL]

示例（必须模仿的句式）：
"美国《国防教育法》共十条52款，主要包括：**一是**大幅增加教育投入，强化美国联邦政府

财政经费是1958年的十四倍。**二是**加强普通学校的自然科学、数学和现代外语教学，注重
技术教育，大力开办职业技术训练，提升技能水平。**三是**注重研究生教育和'天才教育'，
鼓励研究生学习国家安全所需的重点学科。"

# 名称不一致处理规范
- 若政策N与政策N-1名称不同，首次提及政策N-1时写"正式名称（功能别名：【描述】）"
- 在比较分析中，使用"功能谱系"概念建立可比性
- 在脚注中，使用正式名称确保学术严谨性

# 文体硬规范（逐条对标附件）
1. 通篇连贯书面语，"历史→当下→警示"递进展开。
2. 历史文件首次出现写全称（或"正式名称+功能别名"），引用一律脚注。
3. 历史条款展开时，嵌入加粗"**一是**……**二是**……**三是**……"作为隐性结构标记，
   但保持段落连贯性。
4. 比较用串列长句，"从……延伸到……"结构。
5. 必须包含"变与不变"的深层逻辑提炼。
6. 只用A2中真实素材，年份/数据/条款/评价/URL逐字一致。
7. 历史评价必须使用附件中的定性词汇（如"划时代""纲领性""黄金时期"）。
