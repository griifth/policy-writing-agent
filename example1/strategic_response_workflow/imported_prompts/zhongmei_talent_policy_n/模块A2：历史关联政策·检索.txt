# 任务
【条件触发模块】仅当A1检索结果中政策N明确提及/关联某历史政策时，执行本模块。
若政策N无明确历史关联，跳过本模块，C2部分相应压缩。

# 检索内容（针对A1标记的"历史关联线索"定向检索）
- 关联政策名称：政策N-1的正式名称、发布时间、发布机构
- 触发背景：什么外部冲击或内部危机催生了政策N-1？
- 核心条款：共几条几款？各条款的具体内容？
- 量化数据：经费增长倍数、人员规模、投入比例等
- 制度安排：设立了什么新机构/新机制/新项目？
- 覆盖范围：涉及哪些学段/领域/人群？
- 历史效果：对该国产生了什么具体影响？
- 历史评价：学界/政界如何定性该政策？（如"划时代""纲领性""黄金时期"）
- 与政策N的关系：政策N如何定位自身与政策N-1的关系？（一脉相承/战略升级/
  范式转换？）

# 检索要求
- 仅检索A1已标记的关联政策，不主动扩展其他历史政策。
- 必须包含具体年份、数据、法律条款编号。
- 若政策N提及多个历史政策，按关联强度排序，优先检索关联最强的1-2个。

# 输出（每条按〔通用字段规范〕结构化）
关联政策名称（中英）/ 发布时间 / 发布机构（中英）/ 核心内容（含条款编号）/
量化数据 / 制度安排 / 覆盖范围 / 历史效果 / 历史评价 /
与政策N的关系（引用政策N原文表述）/ 来源[机构. 文件名. URL] / 知识库出处ID
不做归类、不加评述。
