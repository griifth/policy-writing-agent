# subtype_b.md（子型 B · 机制 / 趋势综述 · 维度词典）

> 适用：`trend_review`，或 `--style-subtype b`。报告的活儿是"梳理/比较国际做法供决策者参阅"，**不出中国对策**。约占语料 ⅔——是本体例的多数派（终身教育趋势、教育国际战略动向、高校分类管理、本科评估认证、数字微认证、葡语九国、校园餐、学生奶、综合高中、数字教科书…）。

## B1. 章节范式
- **维度 / 洲际 / 功能横切**：按功能维度切（"一、〔维度A〕 二、〔维度B〕……"）、或按洲（欧/洋/北美/亚）切、或按功能大类横切多国（研究型/应用型…，而非按国切）。
- **每个单元判断句领起 + 多国实例**（头号骨架）；维度内可一国一段平铺，但须节首总判、节末收拢。
- **判断式整句标题**常见（标题即结论，正文即举证）。

## B2. 落点（**合法地不回中国**）
- 收尾 = **趋势收拢句**（"可见，世界大多数国家……，已成不可逆趋势"）/ **三大待解问题**（认可度·分级·安全）/ **价值升华句**。
- 中国落点**可有可无**：要么编者按一句"为我国……提供借鉴"轻收，要么段内嵌入一句"相比之下我国……仍有待加强"，**要么完全没有**——都合格。
- **不要硬塞建议章、不要强行制造对华段、不要升格+兜底双声部**（多为单声部机制声）。

## B3. 声音增量（覆盖 voice 通则）
- **单声部、机制中性声**：第三人称、零自称、判断后必缀实证；**通常无对华层**，故 voice 通则"第三档对华谦抑"在此**不触发**。
- **判断强度**：敢下归纳强判甚至负面判断（"该模式并不成功"），但仍 1∶N 缀证。

## B4. 子型 B 的真风险（审查重点）
- **伪比较 / 罗列无归因**（头号）：类型化/并列了却不解释国别差异成因与适用条件。
- **判断稀薄 / 资料堆叠**：只有国别事实、缺归纳判断领起（"先证后断"或有证无断）。
- **学术综述化**：滑向按人名/理论框架/引文体组织、停在"有待进一步探究"——触发体例门槛排除。
- 注：**无建议章 / 无对华落点 / 单声部不是缺陷**，不得据此扣分。

## B5. 子型 B · L3 自检
- [ ] 有实质**类型提炼或趋势研判**，而非简单国别罗列？
- [ ] 每个组织单元有判断句领起 + 多国实证（判断∶证据 1∶N）？
- [ ] 尝试了**真比较**（差异 + 原因 + 适用条件），能上对比表则上？
- [ ] 量化分层对位（并置百分比/分级）到位？
- [ ] 落点收束于趋势/待解问题/价值升华（**不因缺建议章或缺对华落点而扣分**）？
