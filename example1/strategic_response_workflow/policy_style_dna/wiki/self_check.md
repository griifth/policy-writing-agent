# self_check.md（顶层通则 + 子型路由）

> L1–L2 为全子型通则；L3 按子型切换，见 `subtype_a.md` / `subtype_b.md` 末尾的子型自检；L5 为纠错记录。**先确认子型，再套对应 L3。**

## L1 硬性规则（全子型，必须满足）
- [ ] 无 OCR 噪声（断裂英文、缺字、乱码、表格错位）残留入文。
- [ ] 无 AI 身份暴露语、无写作元话语（"本文将分析""综上所述笔者认为""本文先纵比后横比"）。
- [ ] 无情绪化定性词（"触目惊心""令人震惊"）；危机用数据、问题用中性词。
- [ ] 所有强判断与关键数字就地带出处线索（报告名／机构／文件／年份；脚注亦可）。
- [ ] 外文专名首次给中文全称＋缩写，其后统一用缩写。
- [ ] **每个组织单元以判断句领起、判断后必缀实证（判断∶证据 ≈ 1∶N）。**

## L2 风格一致性（全子型）
- [ ] "冷静研判、结论前置"基调统一，无突兀情绪化段落。
- [ ] 国际经验**有归因**：类型化/比较后解释了国别差异成因或适用条件，不是"伪比较/罗列无归因"。
- [ ] 并置段有判断句领起 + 节末收拢（背景/资料章可适度平铺）。
- [ ] 加粗领起（论点式或国名锚点式均可）、编号连续整齐、分类基数一致。
- [ ] 非纯学术综述（未按人名/理论框架/引文体组织、未停在"有待进一步探究"）。

## L3 内容质量（**按子型切换**）
- **子型A** → 见 `subtype_a.md`：建议是否镜像对位前文？四要素"实施机制"是否在位？是否本土化？敏感议题是否稳慎兜底？升格+兜底双声部？
- **子型B** → 见 `subtype_b.md`：是否有实质类型提炼/趋势研判（而非罗列）？是否尝试真比较（差异+原因）？量化分层对位是否到位？**不检查建议章/镜像/对华落点**（无即合格）。

## L4 政策研究声音（全子型）
- [ ] 证据驱动的专业研判力（判断∶证据 1∶N）。
- [ ] 价值取向通过事实体现，而非直接宣告。
- [ ] 引用与数据"为研判服务"，非"为引用而引用"。

## L5 用户纠错记录
格式：`[日期] 问题描述 → 修改方案 → 当前状态`
- `2026-06-25 wiki 把"决策对策型"特征当全体例通则，抹平占~⅔的综述型 → 拆顶层通则 + A/B 子型路由 → 已修正`
