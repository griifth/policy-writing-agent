# subtype_a.md（子型 A · 战略建议 / 预警 / 对策）

> 适用：`strategic_response`、`experience_response`，或 `--style-subtype a`。报告的活儿是"比国际经验 → 推导中国对策"。约占语料 ⅓，是镜像建议范式的真正原型（中美AI人才、警惕竞争法案、美英澳人才争夺、拔尖人才启示、课后服务双减、学制启示）。

## A1. 章节范式
- **标准三段**：①国际经验/对手举措（镜像铺垫）→ ②我国差距/我方风险点 → ③加粗领起的对策建议。
- **镜像三段式（高阶骨架）**：主要举措／态势 → 我方风险点 → 对策建议，**三栏逐条对位**（"五举措→五风险→五建议"，警惕竞争法案是范本）。
- **攻防镜像变体**：建议逐条对冲对手招数（"你抢移民／我建人才高地"），末条可不兜底而以升格收尾。

## A2. 声音增量（覆盖 voice 通则第 2、4 档）
- **升格 + 兜底双声部**：一边把议题抬到"国家战略/安全/竞争力"，一边用"公平/民生/守正"对冲——成对出现。
- **对华语气按风险烈度**：高烈度预警/争夺可用强命令式（"必须打牢""开足开齐""亟需"）；常规战略建议仍可谦抑（"应/可/宜"）。即 voice 通则里"慎用必须/立即"在本子型**放开**。

## A3. 建议写法（完整）
- **镜像推导**：每条建议对位前文某"经验/特征/风险"锚点，不另起炉灶；问题指向常已在前文交代、条内可省。
- **四要素**（不机械四段、常压缩为连续短句）：问题指向 → 政策工具（"出台《某标准》/设专项资金/建协同中心/办试点"）→ **实施机制（硬核：谁做、靠什么载体、点名中国部委与层级、"成立…拟订…纳入绩效"动词流）** → 预期目标（"以…/确保…"小尾巴）。
- **加粗领起两式**：判断导向"**第〔N〕，〔口号式导向〕。**"；枚举动宾"**一是〔四字动宾〕。**/**（一）〔动宾〕。**"。单条内再"一是/二是/三是"细分。
- **本土化**：话语转译、去国名虚指、条件限定（见 recommendation 通则第 2 节）。
- **稳慎兜底末条**：涉选拔/分流/超常/收费等敏感议题，末条恒为"稳慎有序推进／加强舆论引导"（攻防镜像变体可例外）。

## A4. 子型 A 专属禁区
- **悬空建议**：只有方向无机制（缺"谁做/靠什么/怎么衔接"）即不合格，硬核=做法命名＋实施机制。
- **照搬不本土化**：直接要求中国"也应设立"某国机构/法案，未做体制对接与敏感词软化。
- **敏感议题缺稳慎兜底**。

## A5. 子型 A · L3 自检
- [ ] 建议逐条镜像对位前文经验/风险？
- [ ] 每条四要素的"实施机制"在位（非悬空动词）？
- [ ] 完成本土转化（中国话语、部委层级、条件限定、敏感词软化）？
- [ ] 敏感议题有稳慎兜底末条（或攻防变体的升格收尾）？
- [ ] 升格 + 兜底双声部成对出现？
