## 一、机构定位
本机构是**教育研究机构**，产出面向教育决策的政策研究报告。
**一切对策建议最终必须落在教育域抓手上**，不得写成纯产业/外交/军事/科技政策。

## 二、建议落点域（建议必须落在这些教育抓手）
学科专业 / 人才培养 / 课程教材与评价 / 师资 / 拔尖创新人才 / 产教融合与职业教育 / 国际教育与留学治理 / 教育数字化 / 教育治理。

## 三、跨域议题落回教育接口（关键）
遇到国家安全 / 科技竞争 / 产业 / 外交 / 标准等跨域议题，**不直接提产业或外交对策，而落到它的教育接口**：
- 芯片 / 硬件封锁 → 集成电路学科建设、卓越工程师培养、产教融合
- 标准争夺 → 标准领域人才培养、相关课程、高校参与国际标准的激励
- 算力 → 高校科研算力供给、教育算力平台
- 人才虹吸 / 移民 → 拔尖人才早期培养、留学治理、来华留学、海外人才的教育引进通道
- 意识形态安全 → 思政课、国家课程、教材与外教监管
原则：**议题越宏观，越要落到"学科/课程/师资/留学治理"这类具体教育抓手**，而不是泛泛体制口号。

## 四、对策怎么从国情+前文想出来（五步桥接链，每条建议都要走完）
1. **立靶**：回前文找靶子——对手招数 / 我国短板 / 国际共识（三选一），一句话写清"我国 X 环节存在 Y 缺口"或"对手用 Z 威胁我 W"。**无靶不写建议。**
2. **对症**：每条建议可追溯到一个前文判断，一靶一策。
3. **国情容器**：给建议找一个中国现有制度载体（**盘活存量 > 改造 > 新建**）。教育常用容器：双一流/强基/学科动态调整、中考新高考、综合素质评价、教师资格体系/职称/编制、师范培养方案、国家自然科学基金专项、国家智慧教育平台、产教融合、一带一路学历互认、少年宫科技馆、课后服务。
4. **三个为什么（桥接承重墙）**：为什么做 / 为什么不照搬 / 为什么是这个版本——受**四类约束阀**塑形：
   - 统一性（学制课程中央统一 → 只能局部弹性、试点先行、补配套）
   - 减负双减（新增内容不得触发学业负担红线 → 融入既有学科而非单设课）
   - 教育公平敏感（拔尖/选拔类必加"稳慎推进 + 公平防控"）
   - 阶段位置（落后则跟进、已上马缺配套则补配套、**已过度则预警刹车**）
5. **落地七要素**：对象 / 工具 / 机制 / 牵头主体 / 前提条件 / 风险提示 / 优先级，**至少齐 ①②③④**；牵头主体尽量点名层级（教育部哪个司、地方教育部门等）。

## 五、本土防护栏（加分项，尽量加一条）
在国外经验之外，**新增一条由中国国情倒逼、国外无对应物的条款**（教育公平→稳慎推进；双减→控教师负担；立法滞后→先指导意见后立法）。这往往是最显功力处。

## 六、失败模式自查（写完对策回头查）
- 不是编者按一句"借鉴"了事——正文必须有独立"我国应/建议……"落点段；
- 不悬空、不口号（停在"应建立/加快布局"而无机制无牵头）；
- 不照搬（镜像翻译而不换容器、不走三个为什么）；
- 不回避硬约束（编制 / 中高考公平 / 立法滞后要给过渡方案或标为前提）。
