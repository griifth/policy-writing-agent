# 读者站位互校验范围（scope = audience_alignment）

> 独立的"读者站位"尺子：**只审站位，不审事实**——不核数据真伪（citation/先例核查职责）、不审文风细则（style_and_expression 职责）、不判总分（jiaokeyuan_final_review 职责）。只回答一个问题：**这篇稿的判断高度与对策粒度，配不配得上它要报给的那一级读者。**

## 前置判定（gated，先做）

读 run 目录根下的 `audience_profile_snapshot.md`：
- **不存在** → 本次运行未选读者层级。报告只写一行：`本次未选读者层级，站位维度跳过`，并给 `总体结论：达到`（站位维度不设默认门槛），结束。
- **存在** → 它就是本次唯一判据基准（内容同 `audience_profiles/<level>.md`，含该档关心的三问、宏/中/微权重、语气详略、站位反例）。以下每条判据都对照它执行。

## 审什么（三条判据，逐条对照 profile）

1. **层级匹配**：判断高度与对策粒度是否配得上所选读者。
   - 对照 profile 第二节的宏/中/微权重，粗估正文（尤其对策章）实际的宏/中/微分布，明显倒挂即不匹配。
   - 典型病例：给 national_leader 写却通篇处室操作、试点台账（**过低**）；给 bureau 写却只有"加强顶层设计、构筑高地"式宏观口号、无一条可列台账的动作（**悬空/过高**）。对照 profile 第四节反例句逐条比对。
2. **读者层级 ≠ 政策对象**（概念隔离，必查）：本 scope 审的是**报告写给谁看**（国家领导/部党组/司局）。体例 review 维度里的"对象匹配"审的是**政策作用于谁**（顶尖科学家/青年研究人员/留学生等）——两者不同轴。不得把"政策对象选得准"当作"读者站位对了"，也不得因政策对象错配在本 scope 扣分（那归建议合理性维度）。
3. **详略与语气对档**：对照 profile 第三节——判断密度、数字密度、篇幅倾向、速读适配是否符合该档要求（如给国家领导的稿数字过密过碎、给司局的稿无一个可执行数字，均为不对档）。

## 输出

- 逐条给：`判据（层级匹配/概念隔离/详略语气）→ 原文摘录 → 对照 profile 哪一节哪一条 → 判定（对档/过低/过高/悬空）→ 改法示例`。
- 病例改法须**具体到句**：过低句给"上升一级"改写，悬空句给"落到该档粒度"改写（参照 profile 第四节 ✔ 例句的写法）。
- 最后一行：`总体结论：达到 | 基本达到 | 未达到`（与评分门兼容）。判"未达到"仅限：对策章整体档位倒挂（≥半数建议粒度错档），或出现 profile 第四节反例句同型段落且无补救。个别句子错档 → "基本达到"并列改法。
- 报告写到 handoff 指定的 `output_path`。
