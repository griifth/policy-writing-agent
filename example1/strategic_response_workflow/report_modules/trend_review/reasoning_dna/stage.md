# 阶段刀（stage）

> 体例：trend_review（国际动向研判 + 中国对策）。承接推理链中"信号识别 → 趋势归纳 → **阶段研判 → 对我国对策**"的核心枢纽——本刀是动向体例区分"深稿 vs 条目堆叠"最关键的一刀。
> 元格式见 ../../../reasoning_dna/conventions.md（先读）。本刀只规定"必须想到哪几层、哪条判断必须留痕"，不规定文体。

## 必答问题

针对每一条已认定的趋势，**中国相对这条趋势处在哪一步**——是落后/空白、已上马但缺配套、还是已过度/有特异风险？并据此定对策方向：**决定中国该怎么做的，不是"国外做了什么"本身，而是"中国此刻站在哪个位置"。** 同一条国际趋势，落在不同的中国阶段位置上，对策可能完全相反（跟进 / 补配套 / 预警刹车），绝不能一律翻译成"国外有 X，建议我国也搞 X"。

每条趋势须把中国定位到下列某一档，并给依据：
- **落后 / 空白**：中国尚未起步或明显滞后于国际前沿 → 对策方向是**跟进 / 加快布局 / 填补空白**；
- **已上马、缺配套**：中国方向已对、已有动作，但制度 / 师资 / 标准 / 质量等配套没跟上 → 对策方向是**补配套、提质量、防粗放**，而非重复"建议开展 X"；
- **已过度 / 有特异风险**：中国在这条上不是落后而是一哄而上、结构性过剩，或中国国情下另有特异风险（如功利化、低龄选拔的舆论环境）→ 对策方向是**预警、刹车、纠偏、防结构性过剩**——这一档最容易被漏掉，深稿恰恰要敢于在此踩刹车；
- **领跑 / 并跑但有隐忧**：中国数据上领先但存在虚名（如总量第一但源头创新空白）→ 对策方向是**补短板、防虚顶、稳健发展**。

## 什么算答到了（含反例）

**算答到了：**
- 每条趋势后面都跟着一句**中国阶段定位 + 一条对策方向**，且方向是从定位推出来的：
  - 落后 → "我国虽有零星实践，但明确意识和清晰路径尚未形成，有必要参照加快布局"（金样本 AI 拔尖人才"低龄入手"）；
  - 缺配套 → "我国新增 AI 独立专业已达 180 所，但脱不开粗放浮躁，有必要对结构性过剩预警"（同一趋势上，对"独立专业"中国已过度，要踩刹车，而非继续鼓励上）；
  - 领跑有隐忧 → "中国从粗放数据看处于第一梯队，但理论创新不足、关键技术存在空白，避免后劲乏力、徒顶虚名"。
- 同一条国际趋势上，**敢于给出与"跟进"相反的方向**（补配套 / 刹车 / 纠偏），证明对策是被中国阶段位置决定的，而不是被国外做法决定的。
- 中国阶段定位**有依据**：援引中国现状、政策文件、新增数量 / 缺口数据、制度与舆论环境，而非凭空判"我国也应加强"。

**反例（糊弄 / 未答）：**
- **镜像翻译**（本刀首要防住的）：把每条国际趋势直接翻成"国外有 X → 建议我国也搞 X"，完全不问中国此刻站在哪——这正是条目堆叠综述的典型病灶，对策与阶段脱钩。
- **一律跟进**：无论中国落后还是已过度，结论永远是"加强、加快、加大投入"，从不出现"刹车 / 纠偏 / 防过剩"这一档，等于没做阶段研判。
- **只夸国外不提中国**：趋势主体写得满满当当，落到中国时只有一句"值得我国借鉴"，没有把中国定位到任何一档，对策悬空。
- **阶段判断无依据**：断言"我国应跟进"却拿不出中国现状 / 数据 / 制度依据，把分析者的主观倾向当阶段定位。
- **回避刹车档**：明知中国某条已一哄而上、结构性过剩或有特异风险，仍只字不提，一路鼓励上马——漏掉最该预警的那一档。

## 降级扫描要求

**必做扫描：** 把每条趋势列成清单，逐条做"中国阶段定位 + 对策方向"扫描，每条标注：
- **中国位置**：落后/空白 ｜ 已上马缺配套 ｜ 已过度/有特异风险 ｜ 领跑/并跑有隐忧；
- **定位依据**：a 有中国现状/政策文件/数量/缺口数据支撑　b 普遍认知　c 仅分析者断言；
- **对策方向**：跟进/布局 ｜ 补配套/提质量 ｜ 预警/刹车/纠偏 ｜ 补短板/防虚顶；
- **方向—位置一致性**：对策方向是否由阶段位置推出（一致 / 镜像翻译未顾位置）。

**取舍记录格式（逐条留痕）：**
```
趋势：<一句话>
中国位置：落后空白 / 缺配套 / 已过度有特异风险 / 领跑有隐忧
定位依据：a<数据/文件> / b 普遍认知 / c 仅断言
对策方向：跟进 / 补配套 / 预警刹车 / 补短板防虚顶
一致性：方向由位置推出 ｜ 镜像翻译（未顾中国位置）
处理：保留 ｜ 改写为"按中国所处<X>档，对策应为<Y>" ｜ 标"阶段定位仅 c 级断言，待核实再据以出策" ｜ 删（与位置脱钩的镜像建议）
```

**红线（与 conventions 一致）：**
- 必须**做扫描并给结论**。结论可以是"N 条趋势中 M 条原为镜像翻译、已按中国阶段位置改写对策方向（含 K 条从'跟进'改为'补配套/刹车'）"，也可以是"全部对策方向均由中国阶段位置推出、定位均有据，无需降级"。
- **镜像翻译**（"国外有 X → 我国也搞 X"，未做中国定位）不得直接写入正文，须补阶段定位后改写或删除。
- 凡中国处于"已过度 / 有特异风险"档的趋势，对策**不得**继续写成"加快推进"，须给出预警 / 刹车 / 纠偏方向——漏判此档即视为未做阶段研判。
- 阶段定位仅 c 级（分析者断言）支撑的，须标"待核实"，不得当既成事实作为对策依据。
- **不要求强行制造一条否定**——若每条对策都由有据的中国阶段位置推出，如实写"无需降级，依据是 X"。
- 可审查的产物是"扫描 + 每条中国位置/依据/对策方向/一致性 + 处理结论 + 理由"，不是"写一段对策建议"。
