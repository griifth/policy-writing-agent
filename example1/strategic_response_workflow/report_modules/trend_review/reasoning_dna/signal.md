# 信号刀（signal）

> 体例：trend_review（国际动向研判 + 中国对策）。承接推理链中"**信号识别 → 趋势归纳** → 阶段研判 → 对我国对策"的第一、二环。
> 元格式见 ../../../reasoning_dna/conventions.md（先读）。本刀只规定"必须想到哪几层、哪条判断必须留痕"，不规定文体。

## 必答问题

我手上这一条条外部动作 / 文件 / 案例，**是真已成形的趋势信号，还是个别国家的孤立事件、一份尚未落地的计划、或一时的噪音**？把"我看到一堆现象"收敛成"我判定这是一条趋势"——并交代凭什么这么判：是**多国/多机构共现**、有**数据或第三方研究支撑**、还是有**跨年份的持续性**，而不是把单点、单国、单份战略文件直接升格成"全球趋势"。

具体须触及（领域无关）：
- **共现广度**：这条趋势是多国 / 多类主体（政府、高校、专业团体、国际组织、企业）各自独立走到一起，还是仅一两个国家的个案被说成"国际趋势"？
- **证据支撑**：支撑它的是运行数据 / 参与率 / 第三方研究 / 可比统计，还是仅一份战略文件、一句宣告、一条媒体转述？
- **持续性**：它跨了几个年份、有没有迭代演进（如框架出到第 4 版、计划分三阶段推进），还是一次性的孤立宣布？
- **信号 vs 噪音**：哪些是确有方向的真信号，哪些只是个别国家的特殊产物 / 一时风潮 / 政治周期内的临时动作，不宜归入趋势。

## 什么算答到了（含反例）

**算答到了：**
- 每条写进正文的"趋势"，背后能指出**至少一项归类依据**：多国共现（"OECD 一半以上成员国都发布了专门数字教育战略，如澳、比、加……"）、或数据支撑（"全球 2.2 万 AI 拔尖人才中美占 46%、中国 11%"）、或跨年持续（"国际工程联盟框架已出到第 4 版"）。
- 对**"看着像趋势其实是个案"**保持警觉：一个国家的特色做法（如荷兰"与水共处"水教育、日本海洋立国教育）被如实标为"本国特色 / 个案"，不冒充全球趋势。
- 把零散信号**收敛成有名有姓的趋势条**（"以标准建设引领改革""培养重心向低龄下沉"），而不是逐国逐条平铺、读完只见现象不见趋势。

**反例（糊弄 / 未答）：**
- **单点升格**：拿一两个国家的一份战略文件 / 一句目标，直接断言"已成全球趋势"，不问还有谁在做、有没有落地。（对照浅综述 `主要国家教育国际战略趋势和动向.md`：逐国罗列战略文件名与"提出/计划/旨在"，从不判"这算不算一条经过验证的趋势"。）
- **条目堆叠冒充趋势归纳**：A 国这样、B 国那样、C 国又那样，每段一个国家平铺，始终没有一句"这些共同指向同一条趋势，依据是 X"。
- **把噪音当信号**：把一时风潮、政治周期内的临时动作（如某届政府的一次性行政令）当成稳定趋势写入，不区分方向性信号与偶发事件。
- **个案与趋势两张皮**：既说"这是全球趋势"，举的却全是同一个国家的例子，共现广度为零却不自知。

## 降级扫描要求

**必做扫描：** 把正文将要写入的每条"趋势"列成清单，逐条做"信号成色"扫描，每条标注：
- **共现广度**：多国/多主体共现 ｜ 区域性（几国）｜ 单国个案；
- **证据状态**：①运行数据/参与率/第三方研究　②已立法/已建制　③仅战略文件/目标宣告　④媒体转述/单次事件；
- **持续性**：跨多年且有迭代 ｜ 单一年份 ｜ 一次性宣布；
- **判定**：真趋势 ｜ 区域性苗头（暂未成全球趋势）｜ 个案/噪音（不归入趋势）。

**取舍记录格式（逐条留痕）：**
```
候选趋势：<一句话>
共现：多国共现<列举> / 单国个案<国名>
证据状态：①②③④ ——<数据/立法/文件/媒体>
持续性：跨年迭代<例> / 单年 / 一次性
判定：真趋势 / 区域苗头 / 个案噪音
处理：写入为"已成形趋势" ｜ 降级为"苗头/动向，尚待观察" ｜ 标为"某国特色个案，不冒充趋势" ｜ 剔除（噪音）
```

**红线（与 conventions 一致）：**
- 必须**做扫描并给结论**。结论可以是"识别出 N 条趋势、其中 M 条仅单国③级支撑、已降级为'苗头/某国动向'"，也可以是"全部趋势均有多国共现 + ①②级证据，无需降级"。
- 仅③④级（单份文件 / 媒体转述）、且无多国共现支撑的，**不得**写成"已成形的全球趋势"，须降为"苗头/动向"或标为个案。
- 单国特色做法须如实标"本国特色个案"，不得冒充国际共识。
- **不要求强行制造一条否定**——若每条趋势都有多国共现 + 数据/研究支撑，如实写"无需降级，依据是 X"。
- 可审查的产物是"扫描 + 每条共现/证据/持续性 + 处理结论 + 理由"，不是"写一段趋势综述"。
