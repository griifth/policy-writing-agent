# 成因刀（driver）

> 体例：trend_review（国际动向研判 + 中国对策）。承接推理链中"信号识别 → **趋势归纳** → 阶段研判 → 对我国对策"，回答"这条趋势为什么在此刻发生、还会不会持续"。
> 元格式见 ../../../reasoning_dna/conventions.md（先读）。本刀只规定"必须想到哪几层、哪条判断必须留痕"，不规定文体。
> 与 experience_response 的 cause 刀同名同源但角度不同：cause 问"各国为何走了不同的路"（横向差异归因），driver 问"这条趋势被什么力量推着走、动力会不会续"（纵向动力与持续性）——服务于后一步的阶段研判。

## 必答问题

对每一条已认定的趋势，**它是被什么力量驱动起来的（技术 / 制度 / 人口 / 经济 / 地缘竞争 / 社会思潮 / 危机），这股驱动力是会持续加力、还是会衰减甚至反转**？即：不停在"在发生什么"，而要问到"为什么现在发生、靠什么续命"——因为驱动是否持续，直接决定下一步"中国该不该跟、跟多久"。

具体须触及（领域无关，至少答到前两项）：
- **驱动力归类**：这条趋势被什么推着走？是技术突破（如算力/大模型成熟）、制度倒逼（认证/立法）、人口结构（少子化/老龄化）、经济与产业需求（人才缺口/产业升级）、还是国家间竞争 / 危机催化（如美苏争霸催生拔尖人才培养、石油危机后的国力焦虑）？
- **持续性**：这股动力是会继续加强（底层条件长期存在），还是已是强弩之末、依赖一次性事件（一届政府、一次疫情）、可能随政治周期 / 思潮回摆而衰减或反转？
- **动力 vs 现象**：把"趋势的成因"和"趋势的表现"分开——别把"很多国家都在做"当成"它为什么发生"的回答（共现是信号刀的事，不是成因）。

## 什么算答到了（含反例）

**算答到了：**
- 每条趋势挂着**一句以上、指向可核对力量的"因为"**：如"AI 教育向低龄下沉，因拔尖人才需要群众基础、且各国把 AI 视为关乎国家安全的战略资源"，"在线/混合教学骤兴，由世纪疫情这一外生冲击直接催化"——而非"因为大家重视""因为技术先进"这类同义反复。
- 对动力的**持续性**有判断：哪些有长期底层支撑（技术演进、产业刚需），会续；哪些靠一次性事件（疫情催生的远程教学）拉动，冲击退去后可能回落——并据此为阶段刀埋下"这趋势稳不稳"的判断。
- 识别出**可能反转/回摆**的趋势及其成因（如某些做法随政权更迭被叫停又重启），不默认所有趋势都单调向前。

**反例（糊弄 / 未答）：**
- **纯枚举无因**：通篇"各国在做 X"，从不问"为什么此刻、被什么逼出来"，读完只知现象不知动力。（对照浅综述 `主要国家教育国际战略趋势和动向.md`：满篇战略文件名与指标，从不交代"这个国家为什么此时推这条战略"。）
- **贴标签当成因**：用"因为重视 / 因为发达 / 因为先进"解释——这是把结论改写一遍，不是驱动力。
- **把发明史当驱动力**：交代某做法"谁在哪年提出"（如 `欧美国家主要体育课程模式.md` 给每个模式标注提出者与年份），却不说它**为解决什么处境、被什么力量推广开**——人名年份不是驱动力。
- **静态外推**：默认趋势会一直线性持续，不察觉其依赖一次性事件或正处于可能回摆的位置，给后续"中国要不要跟"埋下错误前提。

## 降级扫描要求

**必做扫描：** 把每条趋势列成清单，逐条做"驱动力 + 持续性"扫描，每条标注：
- **驱动类型**：技术 / 制度 / 人口 / 经济产业 / 地缘竞争 / 危机催化 / 社会思潮（可多选）；
- **归因强度**（本刀附属量表，量归因深度，非证据成熟度 E 级；证据分级另见 `../../../shared_schema/evidence_maturity.md`）：深层（指向具体的技术/制度/人口/经济/竞争条件）｜浅层（贴标签、同义反复）｜缺失（只有现象无因）；
- **持续性判断**：持续加力（长期底层支撑）｜ 平台期 ｜ 依赖一次性事件、可能衰减 ｜ 有回摆/反转先例。

**取舍记录格式（逐条留痕）：**
```
趋势：<一句话>
驱动力：<被什么推动> —— 类型：技术/制度/人口/经济/竞争/危机/思潮
归因强度：深层 / 浅层 / 缺失
持续性：续 / 平台期 / 依赖一次性事件可能衰减 / 有反转先例<例>
处理：保留并据此判稳定 ｜ 标"成因待补"（缺失/浅层不得当已解释下结论）｜ 标"动力依赖<X>，持续性存疑，慎作长期外推"
```

**红线（与 conventions 一致）：**
- 必须**做扫描并给结论**。结论可以是"N 条趋势中 M 条仅到缺失/浅层、已标成因待补，正文不得据其断言长期持续"，也可以是"全部达深层、且持续性均有底层支撑，无需降级"。
- 缺失/浅层（无因 / 贴标签）的趋势**不得**在正文当作"已解释、会持续"来给后续对策当依据，须标"成因待补"。
- 动力依赖一次性事件（疫情、单届政府）或有回摆先例的趋势，**不得**做单调线性外推，须标注持续性存疑——这是阶段刀正确定位的前提。
- **不要求强行制造一条否定**——若每条趋势都挂了可核对的驱动力且持续性有支撑，如实写"无需降级，依据是 X"。
- 可审查的产物是"扫描 + 每条驱动类型/归因强度/持续性 + 处理结论 + 理由"，不是"写一段成因分析"。
