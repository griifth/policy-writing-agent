# 不确定性刀（uncertainty）

> 体例：trend_review（国际动向研判 + 中国对策）。贯穿"信号识别 → 趋势归纳 → 阶段研判 → 对我国对策"全链，在落笔成稿（plan_article）前为每条研判结论标住把握度。
> 元格式见 ../../../reasoning_dna/conventions.md（先读）。本刀只规定"必须想到哪几层、哪条判断必须留痕"，不规定文体。

## 必答问题

我对这条趋势及其阶段研判**把握有多大？在什么条件下它会变向、停滞甚至反转**？即：把"研判"和"定论"分开——一条还在演进、依赖特定前提、有回摆先例的趋势，不能用"已是定局""不可逆转"的口吻写死，更不能让一条把握不足的研判直接撑起一条强硬对策。深稿的底气不在于把话说满，而在于说清楚"这一条我有几分把握、变数在哪"。

具体须触及（领域无关）：
- **把握分级**：这条研判是高把握（多国共现 + 数据 + 跨年持续，方向清晰）、中把握（方向较明但证据/共现尚不足），还是低把握（信号稀疏、主要靠推断）？
- **变向/反转条件**：什么情况下它会改道——驱动力衰减（一次性事件退潮）、政治周期回摆、技术路线被替代、出现结构性过剩或反噬？至少为关键趋势点出一个"如果……则趋势可能变"的条件。
- **研判把握 → 对策强度的匹配**：高把握趋势可支撑较确定的对策；低把握趋势上的对策应留有余地（"持续观察""小切口试点""预留调整空间"），不据未定之势下重注。

## 什么算答到了（含反例）

**算答到了：**
- 对关键趋势区分了**确定性措辞与开放性措辞**：方向明确、证据足的写"已成大势 / 难以逆转"（如金样本判"'独立'本身确是世界范围内难以逆转的趋势"）；尚在演进的写"正在形成 / 有待观察 / 存在变数"。
- 至少为一条研判点出**变向条件或反向风险**：如金样本对 AI 独立专业"一哄而上的态势之下，有必要对未来结构性过剩的前景有所预警"——既认其为趋势，又指明其反噬风险；又如对依赖疫情催化的远程教学，提示冲击退去后可能回落。
- **对策强度与把握匹配**：把握不足处不写"必须立即全面铺开"，而给"先试点 / 持续跟踪 / 预留调整"的弹性建议。

**反例（糊弄 / 未答）：**
- **把研判写成定论**（本刀首要防住的）：对每条趋势都用"必然 / 不可逆 / 已成定局"的口吻写死，从不交代把握度，把仍在演进、证据稀薄的判断当铁案。
- **把目标当兑现**：把各国战略文件里的指标承诺（"2025 年翻一番""提高到 20%"）当成已实现的事实来研判趋势，不留"尚是承诺、能否兑现存疑"的余地。（对照浅综述 `主要国家教育国际战略趋势和动向.md`：满篇"提出/计划/旨在/将……"被平铺成既定走向，无一处问"这能不能成"。）
- **零变数外推**：默认趋势单调线性延续，从不设想驱动衰减、政治回摆、路线替代、结构性过剩等反转情形。
- **把握与对策错配**：在低把握研判上压一条不可回头的强硬对策（"应全面推行 X"），既不留试点余地也不设观察窗口。

## 降级扫描要求

**必做扫描：** 把每条研判结论列成清单，逐条做"把握度 + 变数"扫描，每条标注：
- **把握级别**：高（多国共现+数据+持续）｜ 中（方向较明、证据待充实）｜ 低（信号稀疏、主要靠推断）；
- **关键变数**：会令其变向/反转的条件（驱动衰减 / 政治回摆 / 路线替代 / 结构性过剩 / 尚是承诺未兑现 / 暂无明显变数）；
- **对策强度匹配**：对策是否与把握度相称（相称 / 在低把握上下了重注需放宽）。

**取舍记录格式（逐条留痕）：**
```
研判：<一句话>
把握：高 / 中 / 低 ——依据<共现/数据/持续 或 仅推断>
关键变数：<变向条件，或"暂无明显变数">
对策匹配：相称 ｜ 低把握却压强硬对策，需改为试点/观察
处理：保留确定性措辞 ｜ 改写为"正在形成/有待观察"等开放措辞 ｜ 对策放宽为"先试点/持续跟踪/预留调整" ｜ 标"指标尚为承诺，趋势成立与否待兑现数据"
```

**红线（与 conventions 一致）：**
- 必须**做扫描并给结论**。结论可以是"N 条研判中 M 条把握不足、已改用开放措辞并放宽对应对策、K 条指标为承诺已标待兑现"，也可以是"全部研判均为高把握（多国共现+数据+持续），措辞与对策强度相称，无需降级"。
- 低/中把握的研判**不得**用"必然/不可逆/已成定局"写死，须改开放措辞；据其所出的对策须留试点/观察余地。
- 战略文件中的目标承诺**不得**当作已兑现事实支撑趋势研判，须标"尚为承诺，待兑现数据"。
- **不要求强行制造一条否定**——若每条研判都把握充分、措辞与对策均相称，如实写"无需降级，依据是 X"。
- 可审查的产物是"扫描 + 每条把握级别/关键变数/对策匹配 + 处理结论 + 理由"，不是"写一段展望"。
