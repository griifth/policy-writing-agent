# trend_review 样本清单与角色标注

> 体例：国际动向研判 + 中国对策。推理链固定：信号识别 → 趋势归纳 → 阶段研判 → 对我国的影响与对策建议。
> 取样为**混搭**：趋势主体取自 trend_body 金样本，对策落点移植自 strategic/experience 金样本（trend_body 那几篇对策普遍塌尾，不照抄其收尾）。
> 反例用于让 dev/reviewer 认知“条目堆叠、无对策”的不及格形态。
> gold_samples 原件位于 `../../../gold_samples/`（已 gitignore）；本目录 `gold_samples/` 为只读参考拷贝，文件名前缀标注其在本体例中的角色。

## 主范文

| 文件 | 角色 | 说明 |
|---|---|---|
| `sample.md` | 体例标杆（趋势主体 + 对策落点合成范文） | 趋势主体（一、二节）取自《AI拔尖人才六大前沿趋势》真实文本；对策收尾（三、四节）移植《中美AI人才竞争及应对策略》真实政策建议。两段同属 AI 拔尖人才领域，自然衔接。runner 以本文件作为审查/对比基准，故必须同时示范成熟趋势主体与不悬空的对策收尾。 |

## dev 第一步结构勘察结论（取样定稿）

- **趋势主体取样**：选定 `AI拔尖人才六大前沿趋势`（首选，逐趋势带中国位置）+ `国际工程教育改革动向和趋势` + `世界教育数字化发展态势分析`（两篇提供多趋势并归骨架），共 3 篇。
- **对策落点取样**：主取 `中美AI人才竞争及应对策略`（六条加粗领起句 + 抓手 + 回扣压力/短板），辅以 `拔尖创新人才早期培养国际经验及启示`（逐条回扣纪律）。
- **关键判断**：三篇趋势主体的对策收尾均塌尾或缺失，故主范文 `sample.md` 的对策段不取自趋势主体，而移植自战略/经验金样本，以确保本体例“强制对策落点”这一红线在标杆范文里就已坐实。
