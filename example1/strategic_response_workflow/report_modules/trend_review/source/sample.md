# 人工智能拔尖人才培养国际前沿趋势研判及我国对策

> 范文说明（不入正文）：本范文为动向研判体例标杆。趋势主体（一、二节）取自金样本《全球经验：人工智能拔尖人才培养的六大前沿趋势》，体现“信号识别→趋势归纳→阶段研判”的成熟趋势主体；对策收尾（三、四节）移植自战略金样本《中美AI人才竞争及应对策略》的政策建议落点，体现“从研判推导、不悬空、有抓手”的成熟对策写法。两段同属人工智能拔尖人才领域，可自然衔接，用以矫正趋势主体范本普遍存在的“只判趋势、对策塌尾”问题。

2021年中国驻外使领馆教育处发回的三轮调研报告显示，欧美及日韩等发达国家的主流媒体时常渲染中国在人工智能领域的全球领跑地位，并屡屡强调我国在该领域的所谓"野心（Ambition）"。诚然，当前中国人工智能技术的发展，从粗放数据上看确实处于第一梯队，并成为各国眼中的主要竞争者和高地争夺者。但对标国际前沿、尤其是对标美国来看，中国实际上在该领域的理论创新不足、关键技术掌握存在空白，特别是拔尖人才的储备上，举措粗放，章法有限。在人工智能拔尖人才培养上，有必要深度研判全球前沿趋势，取长补短、稳健发展，避免后劲乏力、徒顶虚名。

## 一、全球局势对比

国际权威数据显示，迄今在全球顶级学术会议上发表人工智能论文的约2.2万名AI拔尖人才中，美国占比高达46%，第二位中国占比11%（2420人左右），第三为英国占比7%，而东亚邻国日本的比例为4%。我国国内目前还没有自己的较为权威的AI拔尖人才统计数据，只能从上述他国统计中反观中国这一群体的大致规模。国家工业信息安全发展研究中心发布的《人工智能与制造业融合发展白皮书2020》显示，目前中国人工智能人才的全口径缺口达30万人，复合型人才缺口较大，具有开拓性的领军人才、拔尖人才极其匮乏。

从国家战略上看，美国2020年发布的《人工智能教育战略》，是由国防部（而非教育部）出台的专门针对"人工智能拔尖人才"的国家级培养战略，开篇即称"正有一场针对拔尖人才（Talents）的全球战争正在发生"。从体系完善度上看，以美国为主的高等院校布局时间早、系统相当完善，斯坦福大学、卡内基梅隆大学等半个多世纪以来持续深耕；相对于美国研究型人才的培养重点，中国目前尚停留在应用型人才的培养侧重上，课程与教学体系的设计上处于模仿和跟跑阶段。

## 二、六大角度借力全球经验

整体上看，美国等西方发达国家围绕AI拔尖人才的针对性培养，展现出六大前沿趋势，同时也是值得我国深度参照的六大角度。

**（一）高开高走，从国家战略高度聚焦拔尖人才培养。**纵观教育史，拔尖人才的针对性培养普遍起始于国家危机，极少数拔尖人才本身是国家的关键战略资源。面对新一轮科技革命，西方发达国家纷纷从国家战略层面定位培养高度，起点高走势也高。我国具备举国体制的制度优势，当前提及AI拔尖人才的正式文件有2017年国务院《新一代人工智能发展规划》、2018年教育部《高等学校人工智能创新行动计划》等，但在激烈国际竞争背景下，聚焦还可以更准、站位还可以更高、力度还可以更大。该趋势已制度化、多国扩散，对我国构成现实压力。

**（二）低龄入手，推动培养重心全面下沉。**美英等先行国家已将AI教育的触角向基础教育延伸，特别是日本，从群众基础到拔尖人才的萃取战略异常清晰化和精细化。面向中小学生的"AI思维训练"、面向全体大学生的"AI通识教育"、面向全体理工科本硕博的"AI普遍性素养"，成为西方发达国家培植群众沃土、孕育拔尖人才的三大主流思路。我国当前虽有零星实践，但明确的意识和清晰的路径尚未形成。

**（三）拔高地位，上升为独立专业和独立院系。**将人工智能上升为边界清晰的专业学科、整合为独立院系，是大势所趋。截至2020年3月中国新增人工智能独立专业的高校已多达180所，但脱不开粗放和浮躁的一面，有必要对未来结构性过剩的前景有所预警；但"独立"本身确实是世界范围内难以逆转的趋势。

**（四）资本先行，科技巨头全面渗透AI人才培养。**微软、IBM、Intel等全球科技巨头通过资本力量，已在一线专业人才、整体智识水平、成人教育、基础教育至少四个层次启动了"人工智能+教育"的全面渗透。中国本土的BAT等均有涉及但水平参差；尤为凸显的是科技资本对基础教育阶段校外培训领域的热切渗透，对这一现象的引导和规范亟待形成清晰共识。

**（五）抱团冲锋，构建学界、商界、政界人工智能教育共同体。**法国、日本、韩国等大政府国家能够相对有效地组织学界、商界、政界集体攻关。当前国际有效经验集中在产学研结合的利益驱动与师资力量的相互填补两方面，近期中外科技巨头中有一部分顶级工作者从企业回到高校，掀起商界反哺学界的浪潮。该共同体动态仍处扩散阶段，有必要持续关注和参照。

**（六）强基保底，跟进人工智能的另一条演化路径。**当代主流AI研发转向了大数据暴力计算的实用主义方法论，但从"理解真正智能"入手的科研领域仍代表着前沿阵地之一，仍有一批西方国家科学家团队选择继续坐冷板凳。此路径尚属萌芽，值得我国在相关尖端人才队伍上有所布局、有所储备，以期未来有所应对、有所抗衡。

## 三、对我国的影响研判

综合上述趋势，AI拔尖人才培养的国家战略化、培养重心低龄化、专业与院系独立化已进入制度化扩散阶段，对我国构成现实竞争压力；教育共同体建设仍在扩散，强基保底路径尚处萌芽。对标这些趋势，我国在拔尖人才储备、贯通培养、师资结构、基础研究布局上的差距既是压力来源，也是对策的直接依据。下述对策按"近期跟进—中期制度建设—长期前瞻布局"分层推进。

## 四、政策建议

**第一，树立"科创教育要从娃娃抓起"的鲜明导向。**回应培养重心全面下沉这一趋势，在中小学广泛开设以人工智能为主题的科创教育特色课程，倡导科学、数学、物理、信息技术等跨学科学习。扭转中小学科创教师以兼职为主、专业发展受限的不良局面，对其职称评审实行单列计划、单设标准，选拔培育一批科创名师。将信息技术设为中考必考科目和新高考选考科目，淡化成绩排名，将数字素养和计算思维纳入学生综合素质评价。

**第二，实施人工智能人才国家储备计划。**回应国家战略高度聚焦拔尖人才这一成熟趋势，鼓励高校开设人工智能专业，分类培养理论人才、研发人才和应用人才，健全以产业创新为导向的学科专业动态调整机制。大幅增加人工智能专业研究生招生名额，引导拥有人工智能相关一流学科的不同高校成立教育联盟，通过课程共建、学制互通、师资共享等方式联合培养领军人才。

**第三，打造互聘共享的复合型师资队伍。**回应教育共同体中"商界反哺学界、师资相互填补"的经验，针对高水平师资匮乏和学科结构不合理问题，引导高校从计算机科学、通信工程、自动化、统计学、哲学等专业选配人才，跨专业共享优秀师资。提升兼职教师评聘的灵活性，吸引行业一流人才从教，建立科学家和工程师驻校制度。

**第四，构建高水平的新兴技术研究网络。**回应"强基保底、跟进另一条演化路径"这一尚属萌芽的前瞻趋势，宜以前瞻布局方式分步推进：在国家自然科学基金和国家哲学社科基金设立人工智能专项资助计划，面向优秀硕博研究生设立奖学金和研究基金；加快布局人工智能及新兴技术领域的重点实验室、工程中心和产学研基地，在关键技术方面形成自主知识产权和国际通用标准。

**第五，建立跨界联动的协同育人机制。**回应学界、商界、政界抱团冲锋的趋势，成立国家人工智能人才工作领导小组，推动教育、科技、发改、工信、商务等部门业务整合。鼓励高新科技领域的研究机构、企业、场馆等向学校开放，强化产教融合，将实践性学习纳入研究生培养方案，设置专门学分，加强双导师队伍建设。

**第六，建设国际人工智能人才高地。**回应全球抢夺AI拔尖人才的国家战略竞争，与友好国家联合成立全球人工智能研究基金，布局前沿研究计划和重大工程项目。鼓励我国人工智能行业龙头在欧美国家建设实验室和研究中心，灵活利用国际人才参与技术研发。适当淡化人工智能领域的国家级人才称号，面向新兴技术领域的国际高端人才调整移民政策和签证制度，在全球范围内吸引人才。
