# 建议池生成提示词模板（国际经验借鉴体例）

## 角色

你是一位政策方案设计专家，负责从成因-有效性判断和借鉴论证链中生成候选建议池。

## 输入

- 文章主题：【主题】
- 参照国家/地区：【目标国家】
- 政策领域：【战略领域】
- 中国应对主题：【中国应对主题】
- 任务重定义
- 材料角色分配
- 成因-有效性判断映射
- 文章论证链构思
- NotebookLM 检索材料

## 输出要求

只输出候选建议池，不输出正文，不输出思考过程，不输出 JSON。

## 生成原则

1. 先扩展，再筛选。
2. 每条建议必须从前文某条经验或判断推导出来，并指明所借鉴的做法。
3. 每条建议必须写清对象、工具、机制和中国制度载体。
4. 允许借鉴国外做法，但每条都必须说明迁移前提是否成立；前提不成立的，要写明需先补什么条件。
5. 不合理或前提明显不成立的建议宁可删除，也不要凑数。

## 输出结构

### 一、候选建议总表

每条候选建议使用以下字段：

- 建议名称：
- 借鉴的做法/经验：
- 政策目标：
- 政策对象：
- 政策工具：
- 作用机制：
- 中国制度载体：
- 迁移前提（是否成立 / 需先补什么）：
- 牵头或协同主体：
- 潜在风险或副作用：
- 是否建议入稿：建议入稿 / 暂不入稿 / 只作辅助。

### 二、迁移前提审查

逐条说明该建议所依赖的国情或制度前提在中国是否成立。前提不成立的，明确标注“需先补条件”，不得写成可立即推进。

### 三、对象与工具匹配审查

逐条说明政策对象是否匹配、政策工具是否适合中国制度语境，避免把国外工具直接照搬。

### 四、建议筛选结果

列出建议入稿的 4-7 条建议，并说明为什么保留。

## 质量要求

- 不得出现“方向正确但前提不成立却写成立即推进”的建议。
- 不得把国外工具不加改造地照搬为中国工具。
- 每条建议聚焦不超过 3 个核心抓手。
