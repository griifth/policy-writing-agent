# 意图刀（intent）

> 体例：strategic_response。承接推理链中"措施 → **战略意图** → 对华压力 → 短板 → 应对"的第二环。
> 元格式见 ../../../reasoning_dna/conventions.md（先读）。本刀只规定"必须想到哪几层、哪条判断必须留痕"，不规定文体。

## 必答问题

对方抛出的每一项具体举措，**它真正要达成的战略目的是什么、最终指向谁**？即：剥开"做了什么"（动作层）问到"为什么这样做、想换来什么、把谁设为对手"（意图层）——并能说出这项举措在对方整盘棋里占的位置，而不是把它当成一条孤立的中性政策来转述。

## 什么算答到了（含反例）

**算答到了：**
- 对每一类（或每一组）举措，给出"动作 → 意图"的一句话翻译：这一步是为换取什么优势 / 防住什么、削弱谁。
- 指认举措串成的**整体战略指向**：把分散的动作（如人才、移民、标准、知识产权、意识形态）收敛到一两条主轴上（如"织密针对某国的技术防线""把教育从内部改革延伸到全球争夺"），并说明这些动作彼此如何配合。
- 用**对方自己的话/数据**坐实意图，而不是替对方猜（如其文本中反复点名的对手、明示的目的句、量化目标、所援引的历史先例与其逻辑）。
- 点明**谁是目标、谁获益**：这项举措的承受方是谁、对方想从中拿走什么。

**反例（糊弄 / 未答）：**
- 只复述举措清单（"某国提出 A、B、C"），通篇没有一句"它为什么这么做、想换来什么"。
- 在对方文本**已明示针对性**（点名对手、明写目的）时，仍把举措当**中性趋势**平铺（"国际上普遍在加强 X"）回避之，意图层缺位。
  - 注意反向亦错：对方文本**未点名、无明示针对性**时，把举措脑补成"对手设定 / 蓄意攻击"属**过定性**（见语域降级），中性陈述才是正解。
- 意图层只剩一句万能空话（"为了提升国家竞争力""出于国家安全考虑"），不落到这组具体动作所图的**具体**优势/对手。
- 替对方拔高或脑补意图，却没有对方文本/数据/先例支撑（把推测写成事实）。

## 降级扫描要求

**必做扫描：** 逐项（或逐组）举措做"意图证据"扫描，每条标注其意图判断的**证据来源与强度**：
- A 对方明示（其报告/法案原文直述目的、点名对手、给出量化目标）；
- B 强结构推断（多项动作只有在某一战略意图下才自洽，可据动作组合反推，须说明推断链）；
- C 历史/先例类比（援引可比先例及其已知逻辑，须说明类比成立的条件）；
- D 推测（无上述支撑，仅为分析者假设）。

**语域降级（与 conventions 语域红线一致）：** 意图判断的措辞分寸由证据级定。**"敌意/蓄意/对手设定"这类定性，只有 A 级（对方原话直述）才可照写**；B/C 级须落到中性陈述（"该组动作在 X 战略下方自洽""与某先例逻辑相似"），不得升格为"蓄意针对"。无论证据多强，都不得用"遏制 / 围堵 / 收割"等情绪化定性替代事实陈述。

**取舍记录格式（逐条留痕）：**
```
举措：<动作>
意图判断：<它真正要达成什么 / 指向谁>
证据级别：A / B / C / D ——<对方原话片段 / 动作组合 / 所援引先例 / 标注为推测>
语域：合格（陈述句）｜ 超标（含无 A 级支撑的定性词<…>）→ 改写为<中性陈述>
处理：写入正文为"<战略意图>" ｜ 降级为"疑似/可能意图，证据为推断" ｜ 不写入（D 且无法补强）
```

**红线（与 conventions 一致）：**
- 必须**做扫描并给结论**。结论可以是"全部意图判断均有 A/B 级支撑，无需降级"，也可以是"第 X 条仅 D 级，降级为推测/不写入"。
- D 级（纯推测）意图**不得**当作既定事实写进正文，须降级标注或剔除；C 级类比须写明"类比成立的条件"。
- **不要求强行制造一条否定**——若所有意图判断都坐实在对方原话/量化目标上，如实写"无需降级，依据是 X"即可。
- 可审查的产物是"扫描 + 每条证据级别 + 处理结论 + 理由"，不是"写一段意图分析"。
