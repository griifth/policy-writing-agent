# 威胁刀（threat）

> 体例：strategic_response。承接推理链中"措施 → 战略意图 → **对华压力 → 短板** → 应对"的第三、四环。
> 元格式见 ../../../reasoning_dna/conventions.md（先读）。本刀只规定"必须想到哪几层、哪条判断必须留痕"，不规定文体。
> 证据分级见 `../../../shared_schema/evidence_maturity.md`（唯一真源）；本刀测量对象：**对手举措的落地成熟度**（E3 已落地运行 > E2 已立法待实施 > E1 仅意图 > E0 媒体转述）。

## 必答问题

对方这套举措落到本方头上，**具体形成什么压力 / 风险，它咬住了本方哪一处真实短板，严重到什么程度、传导路径是什么**？即：把"对方的动作"翻译成"对**我**的、可定位、可分级的具体威胁"，并指认它恰好戳中我的哪个薄弱环节——而不是停在"影响很大""值得警惕"这类未定位、无差别的笼统判断。

## 什么算答到了（含反例）

**算答到了：**
- 把对方举措一一**对接到本方的具体短板**：不是泛泛说"有风险"，而是"X 举措 → 戳中我在 Y 环节的短板 → 形成 Z 风险"。短板必须是**本方自身**的真实弱项（如某链条割裂、某环节缺位、某能力稀缺），不是空喊。
- 给每条风险**定位 + 分级**：它压在哪个领域 / 群体 / 环节，是迫在眉睫还是中长期，是局部还是全局、是否可能"在根本问题上出颠覆性错误"。
- 说清**传导路径**：从对方动作到本方受损，中间经过哪几步（如签证收紧 → 留学渠道收窄 → 前沿理念吸纳受阻）。
- 区分**真威胁与虚惊**：哪些是确有其事的硬压力，哪些是声势大于实质；必要时点出"烈度较低但潜在影响大"这类非对称判断。

**反例（糊弄 / 未答）：**
- 只说"影响巨大 / 形势严峻 / 值得高度警惕"，却不说**压在哪、咬住我哪个短板、多严重**——无定位、无分级、无短板对接。
- 把对方的威胁**罗列成对方的成就**（"对方建立了完整体系"），却始终不回答"对我意味着什么"。
- 风险与短板**两张皮**：列了一串风险，又列了一串自身问题，但没有把"对方某动作 ↔ 我某短板"一一咬合起来。
- 无差别恐慌或无差别淡化：要么样样都是"重大风险"不分轻重，要么一句"问题不大"掩盖真实硬压力——两者都未做分级判断。

## 降级扫描要求

**必做扫描：** 逐条候选威胁做"是否成立 + 严重度"扫描，每条标注：
- **指向性**：是确实针对本方 / 戳中本方短板（定向威胁），还是普遍现象被当成对我威胁（伪定向）；
- **证据状态**（对方举措按 evidence_maturity 打 E 级）：E3 已落地/已生效（运行中；效果另被第三方评估证实的标 E4）　E2 已立法待实施　E1 仅政策意图/建议　E0 媒体转述；本方短板是 a 有事实/数据支撑 b 普遍认知 c 仅分析者断言（a/b/c 为本刀附属量表，量短板实证度，非证据成熟度 E 级）；
- **严重度**：全局颠覆性 / 重大 / 局部可控 / 声势大于实质。

**语域降级（与 conventions 语域红线一致）：** 威胁要"定位 + 分级"，但**措辞分寸独立于严重度**。军事化定性词的**词表与处置规则见 `../../../shared_schema/register_blacklist.md`**：除非对方原文明示（I-A 级直接引语），一律降级为**可核的事实陈述**（写"先进制程光刻机出口受'推定拒绝'管制，影响 16nm 以下量产"，删"釜底抽薪式绞杀"）。严重度判"重大"靠的是定位+分级+证据，不靠把词写狠；定性词替代不了证据。

**取舍记录格式（逐条留痕）：**
```
对方动作：<X>　→　咬住本方短板：<Y 环节>　→　风险：<Z>
指向性：定向 / 伪定向
证据状态：举措 E0–E4 ｜ 短板 a/b/c
严重度：全局颠覆 / 重大 / 局部 / 声势大于实质
语域：合格（陈述句）｜ 超标（含无 I-A 级支撑的定性词<…>）→ 改写为<中性陈述>
处理：写入正文为"<已成立的风险>" ｜ 降级为"潜在/中长期风险，依对方举措尚处 E1" ｜ 剔除（伪定向或仅 c 级断言）
```

**红线（与 conventions 一致）：**
- 必须**做扫描并给结论**。结论可以是"识别出 N 处定向威胁、其中 M 处需降级为潜在/中长期"，也可以是"全部风险均有 E3/E2 级举措 + a 级短板支撑，无需降级"。
- E1/E0 级举措（仅意图/媒体转述）支撑的威胁**不得**写成"已发生的损失"；伪定向（普遍现象冒充对我威胁）须剔除或降级。
- 自身短板若只有 c 级（分析者断言）支撑，须标注"待核实"，不得当作既成事实做后续应对的依据。
- **不要求强行制造一条否定**——若每条威胁都咬住有据短板、有已落地举措支撑，如实写"无需降级，依据是 X"。
- 可审查的产物是"扫描 + 每条指向性/证据/严重度 + 处理结论 + 理由"，不是"写一段风险分析"。
