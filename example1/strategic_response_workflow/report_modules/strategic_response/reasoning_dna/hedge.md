# 对冲刀（hedge）

> 体例：strategic_response。承接推理链中"措施 → 战略意图 → 对华压力 → 短板 → **应对**"的收口环。
> 元格式见 ../../../reasoning_dna/conventions.md（先读）。本刀只规定"必须想到哪几层、哪条判断必须留痕"，不规定文体。

## 必答问题

针对已识别的压力 / 短板，本方该出的**应对，是否真正对冲掉了那条具体威胁、是否扬己之长而非照搬对方的工具、是否分清了"该防守加固的"与"该反守为攻去抢的"**？即：每条建议都要能回答"它接的是哪条威胁、为什么这么接、凭什么这条路本方走得通"——而不是堆一份与威胁脱钩、人有我也有的万能政策清单。

## 什么算答到了（含反例）

**算答到了：**
- **建议↔威胁一一挂钩**：每条应对都明确"对冲的是前面识别的哪条压力 / 哪个短板"，没有悬空的、与威胁无对应的建议。
- **不照搬对方工具**：识别对方做法中哪些是其国情产物、本方照搬会水土不服或落入其设定的赛道；给出的是"基于本方条件的等效或更优解"，而非把对方的签证 / 移民 / 法案条文换个主语抄一遍。
- **分清防守与进攻**：哪些威胁要"守"（筑牢防线、补齐短板、防流失），哪些机会要"攻"（化风险为机遇、反向布局、去全球抢资源/抢标准/抢人才）；并说明取舍依据，而非一律防御或一律扩张。
- **本方可行性**：每条建议给出"凭什么本方这条路走得通"的支点（已有基础、可调动的体制/规模/联盟优势、可补的前提），不是只列愿望。

**反例（糊弄 / 未答）：**
- 应对与前文的压力 / 短板**脱钩**：风险讲了一大篇，建议另起炉灶，对不上号，等于换个题目重写。
- **镜像照搬**对方工具：对方设 X 签证我也设 X 签证、对方立 X 法我也立 X 法，不问本方国情是否成立、是否正中对方下怀。
- 一份**人有我也有的万能清单**（"加强投入、完善机制、深化合作、扩大开放"），抽掉本题也成立，没有针对这条具体威胁的咬合。
- 只防不攻或只攻不防，且不给取舍理由；或建议悬空，没有任何"本方为何走得通"的支点。

## 降级扫描要求

**必做扫描：** 逐条应对建议做"对冲有效性 + 可行性"扫描，每条标注：
- **挂钩**：对冲的是哪条已识别威胁 / 短板（写出对应编号或一句话），还是无对应（悬空）；
- **来源性质**：自主解 / 借鉴对方做法（若借鉴，须标"照搬性"——可直接用 / 需改造 / 本方国情不成立不能用）；
- **攻防定位**：防守加固 / 反守为攻 / 二者兼；
- **可行前提**：本方走得通的支点是否成立（已有基础 a / 需先补前提 b / 仅愿望 c）。

**语域降级（与 conventions 语域红线一致）：** 对策**默认以"本方建设 / 补短 / 培养"为主语**，写成建设句。对攻腔准入走双钥门（判据真源：`../../../shared_schema/strength_gate.md`）：对攻定性**只有该威胁 ≥E3（运行数据级，见 evidence_maturity.md）且本方确有此攻势条件、并给出可行支点时**才可用；否则一律改写为本方等效的建设解（写"建设国产算力普惠平台、培养工艺工程师"，删"以体系对抗体系、釜底抽薪反制"）。对攻定性词的词表与处置规则见 `../../../shared_schema/register_blacklist.md`。"分清防守与进攻"指的是**判断**该守该攻，不是把建议措辞一律升格为进攻腔。

**取舍记录格式（逐条留痕）：**
```
建议：<动作>
对冲：威胁/短板 <编号或一句话>　｜　悬空（无对应）
来源：自主 / 借鉴——照搬性：可直接用 / 需改造为<…> / 国情不成立不能用
攻防：守 / 攻 / 兼（判"攻"须注明：所接威胁 ≥E3 运行数据级 + 本方攻势支点<…>）
语域：合格（建设句）｜ 超标（无据的对攻定性<…>）→ 改写为<本方建设解>
可行前提：a 已有基础<…> / b 需先补<…> / c 仅愿望
处理：保留 ｜ 改写为"本方等效解<…>" ｜ 标"需先具备前提<…>再推进" ｜ 删（悬空或国情不成立的镜像照搬）
```

**红线（与 conventions 一致）：**
- 必须**做扫描并给结论**。结论可以是"N 条建议中 M 条为镜像照搬已改造 / 删除、其余均挂钩有据"，也可以是"全部建议均挂钩具体威胁、均为自主或已改造解，无需降级"。
- **悬空建议**（无威胁对应）与**国情不成立的镜像照搬**不得直接写入正文，须改写或删除。
- 仅 c 级（愿望、无可行支点）的建议须标"需先具备前提再推进"，不得写成可立即推进。
- **不要求强行制造一条否定**——若每条建议都挂钩具体威胁、都给了本方可行支点，如实写"无需降级，依据是 X"。
- 可审查的产物是"扫描 + 每条挂钩/来源/攻防/可行前提 + 处理结论 + 理由"，不是"写一份应对清单"。
