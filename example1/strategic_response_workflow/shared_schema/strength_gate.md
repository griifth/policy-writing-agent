# 强度双钥门（strength_gate · "必须/立即"与对攻腔的唯一判据真源）

> 层归属：本门是文风层与推理层的连接件，文件归推理层（shared_schema）持有；`policy_style_dna/wiki/subtype_a.md`、`policy_style_dna/review_scope.md`、`report_modules/strategic_response/reasoning_dna/hedge.md`、`reasoning_dna/conventions.md` 均只留摘要＋指针。判据变更只改本文件。

## 一、总公式

> **语气档位 = min(子型语域上限, 证据准入)。两钥同开才放行，任一钥不开即降档。**

单一证据闸门会丢掉体例维度（子型 B 证据再硬也不用对攻腔——这是体例属性，不是证据属性），故设双钥。

## 二、钥匙一 · 子型语域上限（体例定"最高能说多狠"）

- **子型 A**（strategic_response / experience_response，战略建议/预警/对策）：高烈度预警、争夺类议题**可用强命令式**（"必须打牢""务必""亟需""开足开齐"）；常规建议仍谦抑（"应/可/宜"）。
- **子型 B**（trend_review，机制/趋势综述）：**封顶建设句/陈述句**——任何证据级都不升格为命令式或对攻腔。实证：金样本（趋势研判篇）全篇 E3/E4 级证据仍是冷静单声部。

## 三、钥匙二 · 证据准入（证据定"这句话有没有资格说这么狠"）

- **指向中国的强命令式**（必须 / 务必 / 立即）与 **"反制 / 对抗 / 抢"对攻腔**：须**所接威胁 ≥E3（运行数据级，见 `evidence_maturity.md`）**，且本方有**可行攻势支点**（已有基础 / 可调动的体制、规模、联盟优势）；
- **情绪化敌意定性词**（敌意 / 蓄意 / 对手设定，词表见 `register_blacklist.md`）：须 **I-A（对方原话明示）**；
- 不过证据钥的降级路径：强命令式 → "应 / 宜"；对攻腔 → 本方等效的建设解；敌意定性 → 可核的事实陈述。

## 四、三判例

| # | 场景 | 裁决 |
|---|---|---|
| 1 | 子型 A ＋ 所接威胁 E3/E4（对方举措已有运行数据/效果评估） | "必须打牢"可用（双钥同开，强命令式放行） |
| 2 | 子型 A ＋ 所接威胁仅 E1（对方仅意图宣示） | 降级为"应 / 宜"（证据钥未开，不得写"必须立即"） |
| 3 | 子型 B ＋ 任何证据级 | 建设句/陈述句（子型钥封顶，如"有必要对结构性过剩预警"） |
