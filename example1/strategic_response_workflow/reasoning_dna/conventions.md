# reasoning_dna 元格式 · conventions（一把"刀"的统一形态）

> 所有 reasoning_dna 刀文件（各体例 `report_modules/<体例>/reasoning_dna/*.md`）都必须遵守本元格式。
> 改本文件 → 全体刀的形态约束随之变（共享基底，避免各体例反模版纪律漂移）。
> 共享词汇真源见 `../shared_schema/`（evidence_maturity 证据分级 / register_blacklist 军事化词表 / strength_gate 强度双钥门），各刀只准引用、禁止内联重定义。

## 一把"刀"是什么
不是文风（那是 policy_style_dna），不是流程模板（那是模块 prompt）。
一把刀 = **一刀逼问**：逼模型在某个角度想透，并留下**可检查的取舍记录**。约束的是"必须想到哪几层、哪条判断必须留痕"，不规定文体。

## 强制三段式（每把刀文件必须有这三节）
### 必答问题
该刀的**领域无关元问题**（不绑定具体选题，如不得出现"AI人才""校园餐"等词）。
### 什么算答到了（含反例）
正例判据 + **反例**：明确写出"什么样的回答是糊弄 / 未答"。
### 降级扫描要求
必须执行的扫描动作 + 取舍记录格式（见红线）。

## 反模版红线（不可让步）
每刀产物必须是"**完成降级扫描 + 留下可审查的取舍记录**"，不是"写一段分析"。
- 要求**做扫描并给结论**；结论可以是"存在 N 处需降级"，也可以是"无需降级，因为证据满足 X"。
- 可检查的产物是"**扫描 + 结论 + 理由**"，**不要求强行造一条否定**（防止为凑格式制造问题）。
- 原理：注水只能增不能减；模版能造小节，造不出"我扫描后判 X 不降级、依据是 Y"这种可核对的取舍痕迹。

## 语域红线（register，不可让步）
刀逼的是**判断深度**（想透哪几层 + 留下可核对的取舍痕迹），**不是语气强度**。把话说得更狠、更军事化，**不算把判断想得更深**——它常常只是用定性词替换了证据。

- **语域上限锚 = 金样本。** 合格分寸由 `policy_style_dna/wiki/voice.md`（现行文风真源：第三人称零自称、冷静克制、证据驱动、判断后必缀实证）+ 各体例 `source/sample.md` 共同界定。**该样本的写法是语域上限，不是下限**：警觉可入标题与总起，正文判对方用陈述句、写自身用建设句。
- **定性词是降级对象，不是质量信号。** 军事化/对攻类**情绪化定性**（词表唯一真源见 `../shared_schema/register_blacklist.md`，此处不再列举），除非对方文本**明示**（I-A 级，对方原话直述敌意），否则一律降级为**可核的事实陈述**（保留"约四分之三作者在境外工作"，删"绞杀"）。证据级再高，也不豁免语域闸。
- **中性 ≠ 未答。** 当对方文本无点名 / 无明示针对性时，**中性、克制的陈述是正解**，不是"意图层缺位"。把每段都改写成"对手设定 / 蓄意攻击"反而是**过定性**，须降级。
- **应对默认建设句。** 对策以"本方建设 / 补短 / 培养"为主语优先；"反制 / 对抗 / 抢"对攻腔仅在该威胁 **≥E3（运行数据级）**、且本方确有此攻势条件时才用，并须给可行支点（双钥门判据真源见 `../shared_schema/strength_gate.md`）——否则降级为本方等效的建设解。

## 审查判据
查两件事并立：① "**有没有发生过降级扫描并给出结论**"（判断深度）；② "**语域是否在金样本上限之内**"（措辞分寸）。**不查**"有没有对应小节"，**不要求**"必须有一条否定"。

- **判断深度**：金样本（已答）vs 浅综述（未答/未做扫描）区分得开。
- **语域分寸**：金样本（含其警觉口吻的标题/总起）应判"语域合格"；满纸定性词而无对方明示文本支撑的稿子应判"语域超标、需降级"。**克制但证据扎实**的稿子不得因"不够狠"被判低；**狠但定性词无据**的稿子不得因"判断到位"豁免语域。
- 探针：拿 1 篇金样本 vs 1 篇浅综述套这把刀 → 金样本"已答 + 语域合格"、浅稿"未答"；再拿 1 篇"过定性"稿 → 应判"已答但语域超标、逐条降级"。
