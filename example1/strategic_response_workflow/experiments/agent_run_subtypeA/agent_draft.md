# 美国AI人才战略布局及我国应对策略

2021年，美国人工智能国家安全委员会（NSCAI）发布最终报告，把人力资源短缺判定为美国将人工智能应用于国家安全的"最大障碍"，并据此提出一项"全政府"综合战略，要赢得AI时代的技术竞争。几乎同期，《2021年美国创新与竞争法案》将这一判断转入立法，授权大规模投资AI等关键技术，并把"赢得全球人才竞争"写入条文。值得注意的是，这套布局并未停留在报告层面：从国家科学基金会（NSF）数以万计的STEM奖学金，到联邦非国防AI研发资金按复利增长、到2026财年每年翻倍至320亿美元的预算安排，再到白宫层级的跨部门统筹机构，AI人才竞争已进入法案、预算与机构改革的实施环节。更需关注的是，美国在这套布局中反复点名中国，将AI人才同时作为补己之短与对华施压的杠杆，客观上对我国顶尖人才留存、算力底盘和国际合作空间形成系统压力。

## 一、美国围绕AI人才形成的系统性战略布局

NSCAI报告与《美国创新与竞争法案》并非孤立的教育或移民文件，而是把AI人才从专业议题提升为国家安全与科技竞争议题，通过国内培养、全球吸纳与定向管制三条链条形成政策组合，从人才源头一直贯通到算力底层与国际规则。

**在夯实国内人才基础方面，美国把育才环节前移到教育源头并向上打通高端通道。** 美国判断，本土出生的AI博士生数量自1990年以来未见增长，在科学前沿首次面临失去顶尖人才竞争优势的风险。为此，报告呼吁出台第二部《国防教育法案》以弥补教育系统缺陷，并要求NSF在五年内设立2.5万个STEM本科奖学金、5000个博士奖学金和500个博士后职位；同时设立"联邦AI服务奖学金计划"，以最长四年全额学费招募培训AI专业人员，并组建"美国数字服务学院""国家后备数字军团"和"STEM军团"，充实联邦政府与军队的技术人才库。这一安排的功能，是从基础教育到高端研究、再到公共部门岗位，建立一条可持续的人才生产与吸纳通道。

**在面向全球争夺顶尖人才方面，美国以移民政策为杠杆，并明确将其指向加剧对手的人才流失。** 报告提议通过《国家安全移民法》，向所有从美国认证大学毕业的STEM博士直接授予绿卡且不计入名额上限，将基于就业的绿卡数量在每年14万张的基础上翻倍，并创设不受上限限制、由NSF每三年界定一次技术领域的"新兴与颠覆性技术签证"，同时放宽O-1"杰出人才"签证标准。报告并不讳言这一政策的对华意图：它直言要利用移民政策加剧中国的"人才流失"，迫使中方陷入"两难境地"——要么承受人力资本流失与AI发展受阻，要么限制本国国民赴美学习工作。

**在守住自身优势的同时，美国对人才与技术的跨境流动设置定向约束。** 美国扩大外国投资委员会（CFIUS）对敏感技术的审查，强制要求中国等竞争对手披露在AI等领域的投资；立法禁止联邦科学机构人员参与中国等国的"外国政府人才招聘计划"，并对具有中国军方背景的研究人员实施严格签证审查。这些措施与吸纳政策一正一反，意在单向打开对己有利的人才流入闸门，同时收紧可能外溢的知识流动。

**在支撑人才发挥作用的底层条件方面，美国同步布局算力、产业与国际规则。** 报告提出建立"国家AI研究资源"（NAIRR），首期拨款3000万美元提供算力与政府数据集，以弥合研究人员之间的"算力鸿沟"，并建立整合学术界、企业和地方政府的"区域技术中心"推动成果商业化；在硬件底层，联合荷兰、日本对极紫外（EUV）和氟化氩（ArF）浸没式光刻机实施"推定拒绝"的出口管制，限制中国生产16纳米及以下节点的高端芯片；在规则层面，组建"新兴技术联盟"（ETC）、由NSF主导设立"多边AI研究院"（MAIRI），并针对《中国标准2035》计划要求加强美国在国际技术标准制定机构中的领导权。至此，育才、引才、管制、联盟标准四个环节相互衔接，共同服务于美国在AI领域保持竞争优势的总目标。

## 二、AI人才已成为美国国家竞争体系的重要支点

AI人才之所以被美国提升到国家战略高度，并不只因为一时的技术突破，而是因为它被直接联结到国家安全与科技主导权。这一思路并非首次出现：1958年，为应对苏联"人造卫星"冲击，美国曾通过《国防教育法案》大幅强化理工科教育与人才培养；NSCAI报告正是呼吁以第二部《国防教育法案》重塑当前教育与人才体系。这一类比成立的条件，在于美方自身已把当前竞争明确定义为可与冷战科技竞赛相比的战略竞争——其逻辑是，美国善于在感受到外部技术追赶时，将关键能力培养上升为国家工程集中投入。

与历史阶段相比，当前布局呈现三个新变化，而每个变化都对应着对我国的一种具体压力。

其一，从国内能力建设扩展到全球资源争夺，并以此戳中我国顶尖人才留存的真实短板。中国是全球最大的单一AI人才来源国，研究人员约占全球顶级深度学习人才的29%，但留住顶尖人才始终是突出难题——中央人才工作协调小组曾承认中国流失的顶尖人才数量居世界首位，2009年至2018年间约2800名中国NeurIPS参会者中，约四分之三目前在境外工作。美国以直接发放绿卡、新兴技术签证主动吸纳，又以禁止参与海外人才计划、收紧涉华签证阻断我方传统引才渠道，一进一收之间，形成顶尖人才"流出加剧、回引受阻"的双向压力。这一压力指向明确、且有数据支撑，属于需要中长期应对的重大风险。

其二，从单一专业政策扩展到算力、芯片与产业链协同，并咬住我国高端硬件的薄弱环节。中国在高端半导体供应上严重依赖国际企业，而美国正是将半导体制造设备视为限制中国AI能力的关键环节，通过联合荷兰、日本对高端光刻机实施"推定拒绝"的出口管制，影响我国16纳米及以下先进制程的规模化生产。其传导路径清晰：设备出口受限，则先进算力芯片的自主供给受阻，进而约束大模型等高算力依赖型AI能力的上限。这一压力局部而尖锐，集中压在高端制程这一环节。

其三，从单部门政策扩展到白宫统筹的多领域协同，并以联盟与标准挤压我国的国际合作空间。美国强调由白宫超越单一部门层级统筹经济、安全与科技战略，组建技术竞争力委员会等跨部门机制；对外则通过ETC、MAIRI等联盟平台协调出口管制与投资审查，并针对《中国标准2035》争夺国际标准制定主导权。与此同时，也应看到，美方评估认为中国虽在AI专利申请量上已超过美国、成为全球最多产的申请国，但部分申请由非市场因素驱动，存在质量约束。这一评估虽出自竞争对手视角，但客观上提示我国，在国际规则与创新质量的竞争中，单纯的数量优势难以转化为话语权。

综合来看，美国正在织密一套覆盖人才、算力、产业与规则的竞争网络，其核心设计是用吸纳与管制的组合，给中国同时制造"留人难"与"补链难"的压力。应对这一布局，关键不在于把美方的签证、法案条文换个主语照搬，而在于立足我国规模优势与制度统筹能力，先稳住人才与算力底盘，再推进制度建设和规则布局。

## 三、我国应对策略

**第一，强化顶尖AI人才留存生态，把"育得出、留得住、用得好"作为优先任务。** 针对我国顶尖人才流失居前、传统海外引才渠道收窄的双向压力，应由科技部、人力资源社会保障部会同教育部牵头，把优化科研环境与职业发展生态作为近期重点动作。具体而言，要分层施策、避免把不同层次人才混为"高端人才"一概而论：对顶尖科学家，重在以稳定支持的重大项目、宽容失败的评价机制和与国际接轨的科研条件留人；对青年研究人员，重在畅通职称晋升与独立主持课题的通道；对工程师与应用型人才，重在依托国家队企业和产业一线提供成长空间；对留学生与归国人员，重在简化服务、稳定预期。在引进端，应区分不同合作区域的真实功能，面向全球顶尖科研力量精准引才，而非笼统提出"到某地争夺顶尖人才"。其目标，是把我国庞大的STEM人才基础真正沉淀为稳定的战略科技力量。

**第二，集中力量突破高端半导体制造装备瓶颈，并建立供应链弹性机制。** 针对高端光刻机等设备出口受"推定拒绝"管制、先进制程量产受约束的尖锐压力，应由国家发展改革委、工业和信息化部会同科技部统筹，依托国家科技重大专项和新型举国体制，对高端半导体制造装备开展针对性集中攻关。同时，参照供应链弹性的思路，建立关键材料、设备与零部件的国产替代梯次方案和储备机制，降低单一来源依赖。需要清醒认识的是，高端装备攻坚是一项需要长期投入、并先补齐基础工艺前提的硬任务，宜以稳定预期的长周期投入推进，避免短期化。其目标，是逐步缓解先进算力芯片对外部供应的过度依赖。

**第三，建设国家级普惠算力平台与开源知识网络，赋能广泛的创新主体。** 针对我国AI研发易集中于少数科技巨头封闭生态、广大高校与中小企业算力不足的能力缺口，应由工业和信息化部、国家网信办会同科技部统筹，在国家层面出资建设普及化的公共算力平台、开放数据集和开源知识网络，并配套标准化测试床。可依托现有超算和国家实验室体系增设普惠服务功能，向学术界与中小企业开放可扩展的计算资源。其目标，是把算力从少数主体的封闭资源，转化为支撑全社会AI创新的公共基础设施。

**第四，推动AI知识产权从数量优势向质量优势转型。** 针对外部评估指出的我国专利"重数量、轻质量"问题，应由国家知识产权局牵头，优化专利审查标准与资助导向，把高质量发明、核心专利和实际转化纳入评价重点，逐步淡化单纯以申请量为指标的激励。可探索围绕AI核心算法、关键芯片和重大应用建立高价值专利培育机制。其目标，是把专利规模优势转化为真正的创新质量与规则话语权。

**第五，建立AI人才与产业发展的跨部门统筹机制，避免政策口径分散空转。** 美国把AI战略提升到白宫统筹层级，反映出此类跨领域竞争高度依赖顶层协调。我国不宜照搬其具体机构设置，但应针对人才、算力、产业、安全等政策长期分散于不同部门口径的问题，由教育部、科技部、国家发展改革委、工业和信息化部、人力资源社会保障部、国家网信办等建立部际协调机制，在规划、投入、评价、标准与项目安排上形成一致导向，推动项目共建、人才共育、成果共享。其目标，是让分散的政策资源围绕同一战略方向形成合力。

**第六，拓展非排他性的多边AI合作与国际标准参与，提升我国在国际规则中的主动权。** 面对美国以联盟和标准进行围合的态势，应对之道不是另起对抗性联盟，而是更主动地融入与塑造开放合作网络。应由科技部、国家标准化主管部门会同外交、商务等部门，加大对我国学者和企业参与国际标准制定组织的支持，并区分不同合作区域的真实功能：面向科研前沿地区开展顶尖联合研究，面向发展中国家开展AI能力建设、联合培养与标准合作，面向广阔市场开展应用场景与产业合作，而非把所有区域都简单理解为顶尖人才来源地。在坚持安全底线和自主能力建设的基础上，扩大开放合作，提升我国在国际创新网络和规则制定中的话语权。

需要强调的是，上述应对应在守住安全底线与自主能力的前提下稳慎有序推进。涉及人才引进、数据开放和国际合作等敏感事项，宜对配套条件好、基础具备的地区和领域先行先试，加强政策协调与舆论引导，在扩大开放与防范风险之间保持平衡，避免一哄而上或一刀切。唯有把被动承压转化为体系化的能力建设，我国才能在这场长期的AI人才与科技竞争中守住底盘、赢得主动。
