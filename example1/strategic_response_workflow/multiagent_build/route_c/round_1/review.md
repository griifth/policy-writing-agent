→ 金样本有多处"因为"且指向可核对条件、有国别差异归因、有可变性识别 → **已答**。

## 五、给 dev 的修改指令（非阻断，建议性增强）

1. **[efficacy.md L37–38] 降级红线对"④第三方评估"措辞略含混**：L11 把④定义为"有第三方评估/效果证据"（最高级），但 L37 降级红线写"①（仅政策意图）或 ④仅媒体转述 → 应降级"。此处"④仅媒体转述"与 L11 的"④第三方评估"是两个不同的④，易误读为"第三方评估也要降级"。建议把降级红线里的"④仅媒体转述"改标为独立等级（如"⑤媒体转述/单一新闻源"）或改写为"仅媒体转述（无论其声称等级）"，避免与 L11 的④撞号。

2. **[cause.md L10] "至少答到前三项"与三项并列项数对齐确认**：L11–13 恰好列了三项（驱动力/路径差异来源/可变性），"至少答到前三项"等于"全答"，措辞冗余且易让模型以为还有第四项。建议改为"下列三项须全部触及"或补出第四项备选，消除歧义。

3. **[两刀通用] 结论格式红线可加"扫描覆盖率"硬约束**：当前结论格式（cause L41 / efficacy L41）要求"共 N 条…其中 M 条降级"，但未强制 N 必须等于正文将引用的全部外部做法条数。建议补一句"N 须覆盖正文将引用的全部外部做法，不得抽样"，防止只挑好答的几条做扫描、绕过难点。

以上3条均为可操作的锐化，不影响本轮 pass 判定。
