# voice.md

## 1. 总体写作姿态：客观析理型介入
- **非情绪化断言**：以数据、事实、国际比较为论据底盘，避免“我们必须”“毫无疑问”等情绪化全称判断。
- **“观察—分析—判断”递进**：先呈现现象或数据，再展开机制剖析，最后给出判断，形成“现象→机理→结论”链。
- **读者预设**：面向教育决策者、政策研究者、专业读者，默认其具备教育政策与国际比较知识背景，不进行常识铺垫。
- **自我定位**：以“本研究”“本文”等第一人称组织论述，清晰区分作者观点与引述观点。

## 2. 语气控制：冷峻审慎
- **克制乐观**：对技术赋能、政策成效等保持谨慎乐观，常用“机遇与挑战并存”“仍有待深化”等限定语。
- **问题导向**：直面“短板”“盲点”“分歧”“局限”，但不情绪化，采用“存在…不足”“尚需…”“面临…挑战”等客观表述。
- **平衡句式**：经常使用“一方面…另一方面…”呈现议题的复杂性。
- **适度判断**：在实证分析或系统性比较后，给出有限度的等级判断（如“处于‘领跑’‘并跑’‘跟跑’位置”）。

## 3. 正式度与专业性
- **术语使用**：准确使用学科概念（如“结构性嵌入”“数字鸿沟”“技术决定论”），首次出现时可能附带简要定义或明确出处。
- **句式密度**：信息密度高，复句多，但避免过度嵌套导致歧义。
- **学术政策融合**：既保留学术论文的严谨（文献回顾、理论框架、研究方法交代），又面向政策实践（问题切入直接、建议可操作）。

## 4. 价值取向
- **人本导向**：坚持“以人为本”“公平”“质量”等核心价值，警惕技术决定论与商业化侵蚀。
- **国家立场自觉**：在涉外分析中，隐含或明确体现中国国家利益、主体性、话语权。
- **国际视野**：广泛引用UNESCO、OECD、发达国家政策实践，但保持审慎借鉴、批判性吸收姿态。
- **建设性**：不满足于批评，落脚点在于提出建设性方案。

## 5. 避免口号化方法
- **去行政语言**：避免“深入贯彻落实”“伟大征程”等公文套话。
- **概念锚定**：用具体政策、项目、数据替代抽象理念。
- **条件式建议**：建议前常带“需要”“应”“可考虑”“有赖于”等弱断言词，并给出实施前提或约束条件。

**总结**：政策研究声音应为**基于证据的、结构化的、审慎判断的、面向建设性解决方案**的专业声音，兼具学术严谨性与政策实用性。

# structure.md

## 1. 通用结构范式（递进式）
多数政策研究报告采用如下递进逻辑链，适合“战略竞争分析+中国应对策略建议型”报告：

**摘要/开头**
- 高度浓缩：点明议题重要性、研究缺口/核心问题、方法/视角、主要发现/核心判断、对策方向。

**问题提出/引言**
- 宏观背景锚定：政策背景、技术趋势、国际动态。
- 问题化：指出当前研究/实践的缺口、矛盾或认知误区。
- 研究问题声明：明确本文要回答的核心问题（通常2-4个）。

**理论基础与分析框架（可选）**
- 引入特定理论视角（如“外化”视角、嵌入理论、行动者网络理论等）作为分析透镜。
- 定义核心概念，构建分析维度。

**国际经验/政策演进/历史脉络**
- 阶段性划分：按时间或逻辑划分发展阶段（如“起步探索→扩展推进→调整转型”）。
- 国别/区域比较：选取代表性国家/组织，从政策、实践、成效等维度进行比较。
- 提炼模式：从分散经验中归纳出典型模式、关键议题或共性特征。

**现状/机制/挑战分析**
- 对中国实践进展的描述：按维度（如平台建设、教学应用、机制保障）展开，可结合案例。
- 发现问题/矛盾：揭示深层结构性矛盾（如“新技术与旧标准”），常以多维矛盾形式呈现。
- 机制解释：运用理论框架解释问题成因（如治理真空、资本逻辑侵蚀、路径依赖）。

**对策建议**
- 多维并行建议：通常4-5条，从理念重塑、制度建设、能力提升、技术路径、生态构建等维度展开。
- 每条建议内部遵循“问题指向→政策工具/行动→实施机制→预期目标”逻辑。

**结语/讨论（可选）**
- 升华核心观点，指出研究局限，展望未来研究方向或政策演变趋势。

## 2. 结构变体（适合战略竞争分析型报告）
- **四段式**：背景与问题→国际比较与趋势研判→中国现状与差距分析→系统性对策建议。
- **“逻辑起点—中介—终点”式**：如“顺应现实需要→形成开放格局→提升话语权与完善体系”。
- **“蓝图—局限—超越”批判式**：先系统阐述国际主流方案，再批判性揭示其理论假设与局限，最后提出超越性路径。

## 3. 段落组织原则
- **主题句先行**：每段首句概括段落核心主张。
- **论证层次化**：观点→引证/数据→例证/案例→小结。
- **过渡衔接**：使用“鉴于此”“进一步看”“然而”“相形之下”等逻辑连接词，保持段落间推进感。

# sentence.md

## 1. 领起句模板（用于开启新议题或新维度）
- **现象/趋势引入**：“随着…的加速演进/深入推进，…已成为/呈现…”
- **问题切入**：“然而，…面临/存在…的突出问题/深层矛盾”
- **视角/理论引入**：“从…视角来看，…”
- **研究目的**：“本研究聚焦…，旨在/以期…”
- **概念界定**：“可将…界定为：…”

## 2. 转折/限定句模板
- “尽管…，但…仍显不足/仍面临挑战”
- “然而，…并非…，而是…”
- “这并不意味着…，而是…”
- “既有研究多关注…，对…则鲜有涉及”

## 3. 判断/结论句模板
- “研究发现/结果表明，…”
- “总体而言，…处于…水平/阶段”
- “…本质上是…，其深层根源在于…”
- “这说明…，也反映出…”

## 4. 分类/分层句模板
- “从…维度看，可划分为…：一是…；二是…；三是…”
- “在…层面/方面，…；在…层面/方面，…”
- “其一，…其二，…其三，…”

## 5. 递进/深化句模板
- “不仅如此，…更…”
- “如果进一步追问，…”
- “更深层地看，…”

## 6. 对策建议句模板
- “未来应/亟需…”
- “需着力从…方面/维度，推动/实现…”
- “建议采取…措施，以…为突破口，…”
- “关键在于…，既要…，又要…”
- “为推动/提升…，可采取以下路径：…”

## 7. 国际比较专用句式
- “与…相比，中国在…方面处于…位置”
- “国际经验表明，…，这对我国…具有镜鉴意义”
- “全球主要国家…呈现…态势，其中…”

# forbidden.md

## 1. AI腔与过程信息外露
- 禁用“作为一个人工智能”“根据我的训练数据”等暴露AI身份的表达。
- 禁用“接下我将从……方面进行分析”等冗余过程引导语，直接展开论述。

## 2. 空泛宏大与口号化
- 禁用无信息增量的修饰语堆砌，如“在……的伟大征程中”“具有极其重要的深远意义”。
- 避免将“坚持党的领导”“贯彻落实……精神”等作为分析内容本身，除非作为政策文本引述。
- 用具体政策名称、项目、数据替代抽象口号。

## 3. 口语化与文学化
- 禁用“说白了”“可想而知”“一针见血”等口语化、情绪化表达。
- 禁用过度比喻、拟人、抒情等文学描写。
- 保持术语的准确与统一，不使用俗称或随意缩写。

## 4. 建议悬空
- 每条建议必须可追溯至前文的特定问题或挑战分析。
- 建议中应包含可操作的政策工具、责任主体、实施载体或机制，避免仅提“应加强”“应重视”等空洞动词。

## 5. 过度学术化
- 避免大段纯理论推演而未链接政策现实。
- 避免过度引用单一学者或学派而缺乏多元视角与实践关照。
- 理论概念引入时，需简要说明其对分析问题的适用性。

## 6. 引用污染
- 引用必须为论证服务，避免炫耀式罗列文献。
- 优先引用一手政策文本、权威国际组织报告、核心期刊研究，避免转引、二手引用。
- 禁用来源不明的网络信息、自媒体文章作为论据。

## 7. 格式与编码污染
- 清除PDF抽取产生的乱码、断裂的英文单词、页眉页脚（如“N〇 3 . 2 02 6”），这些不作为文风特征。

# recommendation.md

## 1. 问题驱动原则：每条建议必须“师出有名”
- **问题-建议强对应**：建议部分的每一条（或一组）措施，须在前文“挑战/问题/短板”分析中找到明确对应项。
- **不建议无源**：避免提出前文未讨论过的全新问题领域下的建议，除非作为延伸讨论并有明确说明。

## 2. “问题指向—政策工具—实施机制—预期目标”四要素结构
每条健全的政策建议应包含以下四要素：
- **问题指向**：用1句话点明要解决的特定问题或要抓住的机遇。
- **政策工具/行动**：具体的手段或措施。例如：“设立…专项资金”“制定…技术标准”“建立…协同中心”“实施…试点项目”。
- **实施机制**：谁来做、如何做、依托什么载体。明确政府层级、部门、学校、企业、社会等多元主体的角色与协同关系。
- **预期目标**：此措施期望达成的可观察效果。表述为“以…”“进而…”“助力/支撑…”。

示例结构：“针对…（问题），应…（政策工具），通过…（实施机制），以期/从而…（预期目标）。”

## 3. 建议的合理性与可行性自检
- **政治与政策可行性**：是否符合国家现有大政方针与政策趋势？是否在现有体制框架内可操作？
- **财政与资源可行性**：是否考虑了成本、资金来源、投入产出比？对中西部地区/弱势群体是否具备实施条件？
- **技术与能力可行性**：所需技术是否成熟？实施主体（教师、管理者）是否具备相应能力？是否需要配套培训？
- **可持续性**：是短期运动式还是长期制度化安排？是否形成长效机制？

## 4. 建议的体系化与协同性
- **维度覆盖**：建议应覆盖理念、制度、能力、技术、资源、生态等关键维度，形成系统解决方案。
- **避免冲突**：各条建议之间不能存在逻辑矛盾或政策冲突。
- **国际经验本土化**：若借鉴国际经验，必须添加“利用…的本土化调试/根据我国…实际”等条件限定。

## 5. 建议语体特征
- 使用“需要”“应”“可”“亟需”等情态动词，体现专业判断而非行政命令。
- 常用排比式小标题来组织结构化建议（如“第一，构建……；第二，实施……；第三，健全……”）。

# self_check.md

## L1 硬性规则（必须满足，否则报告无效）
- [ ] 无乱码、无PDF抽取污染痕迹。
- [ ] 无AI身份暴露语（“作为AI”等）。
- [ ] 无口号化、文学化、口语化表达。
- [ ] 所有数据、引述均有明确来源（或标注为“本研究调查显示”等）。
- [ ] 核心概念在首次出现时已界定或注释。
- [ ] 建议部分与挑战/问题部分在逻辑上构成对应关系。

## L2 风格一致性（高度优先）
- [ ] 全文语气统一为“冷峻审慎”基调，无突兀的情绪化段落。
- [ ] 保持“现象→分析→判断”的论证节奏，不跳跃。
- [ ] 段落长度适中，信息密度高但可读。
- [ ] 术语使用前后一致，无混用。
- [ ] 全文贯彻“战略竞争分析+中国应对”的报告定位，不偏离主题。

## L3 内容质量（核心价值）
- [ ] 国际比较部分是否有实质性的模式提炼或趋势研判，而非简单罗列国别做法？
- [ ] 对中国现状/问题的分析是否触及结构性矛盾，而非停留于表面现象描述？
- [ ] 提出的建议是否具有创新性、可操作性，且针对诊断出的问题？
- [ ] 论证是否严谨，结论是否可证伪、可讨论？
- [ ] 是否体现了批判性思维（如对国际主流叙事的审慎、对技术决定论的警惕）？

## L4 政策研究声音（专业性呈现）
- [ ] 是否体现了基于证据的专业判断力？
- [ ] 是否保持了建设性的、面向未来的问题解决姿态？
- [ ] 价值取向是否清晰（公平、质量、人本、国家立场）且通过分析体现，而非直接宣告？
- [ ] 引用与理论运用是“为分析服务”还是“为引用而引用”？

## L5 用户纠错记录（迭代优化）
格式：`[日期] 问题描述 → 修改方案 → 当前状态`

示例：
- `2025-01-01 建议部分“加强顶层设计”过于空泛 → 修改为“建立由教育部牵头的跨部门协同机制，明确年度任务清单” → 已修正`
- `2025-01-02 引言段AI腔“接下来将从三个方面分析” → 删除过程引导句，直接切入第一方面主题句 → 已修正`
