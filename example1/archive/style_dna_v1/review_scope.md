# 文风与表述审查范围（scope = style_and_expression）

只审【文风】和【表述】，**不核查事实对错、不读检索原始材料**（事实由别的环节负责）。

重点盯以下问题（都只看正文即可判断）：

- **AI 腔 / 八股**：套话、空泛排比、“首先其次最后”式机械结构、为对仗而对仗。
- **口号化 / 文学化**：四字格堆砌、煽情、标语腔、军事化或比喻化动词（如“釜底抽薪”“绞杀”）。
- **过程信息 / 系统标签外露**：“材料显示”“根据检索”“模块”“标签”等暴露生成过程的痕迹。
- **出处标注**：关键数字或强判断，表述上是否就地带出处线索（报告名 / 机构 / 年份）——只看有没有带，不核真假。
- **句式与篇幅**：超长段落（8 行以上）、超长复合句、冗余重复、连接生硬。
- **术语中文化**：夹生英文术语、音译腔、专业术语未转成自然中文表达。
- **凝练度**：“加强、完善、推动、不断”等空转词；一句话能说清却被拉长。

判据：查“有没有上述问题的**具体实例**”，逐条**引原文** + 给改写示范，不要泛泛而谈。最后给一行 `总体结论：达到 | 基本达到 | 未达到`。
