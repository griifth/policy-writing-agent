# policy_style_dna / wiki

国际比较·决策咨询体文风控制规则（蒸馏自 38 篇人类成稿国际比较报告）。**只控文风，不作事实来源。**

- `voice.md`：决策咨询声音、判断分层、价值取向、避免口号化。
- `structure.md`：三大递进范式、开篇五式、国际经验组织法（先类型化再填国名）、镜像收尾。
- `sentence.md`：占位符化可复用句式模板（领起/总判/分类/实证/判断/趋势/风险/建议）。
- `forbidden.md`：禁用/慎用（一国平铺无收拢、悬空建议、空泛大词、情绪化、过程外露、学术腔、本土化缺失、OCR 噪声）。
- `recommendation.md`：建议写作（镜像推导、四要素、加粗领起、本土化、稳慎兜底）。
- `self_check.md`：L1–L5 自动化自检体系。

## 接入原则
写作模块读 `voice/structure/sentence/recommendation`；审查与修改模块读 `forbidden/recommendation/self_check`。
最终正文不得输出文风分析过程、分类依据、比较维度或建议映射表，除非用户明确要求保留。
