## 二、测试结果

| 测试单 | 路线 | 输入 | 结果 | 点选耗时 |
|---|---|---|---|---|
| **A 终身教育** | 模糊主题 | 仅主题"终身教育" | 侦察→[态势速览](testruns/测试单A_终身教育/态势速览.md)（真实检索，5 事实/4 轴/5 候选问题）→模拟点选→[方向书](testruns/测试单A_终身教育/方向书.md)签字通过 | 点选 <1 分钟 |
| **B 教师AI素养** | 明确问题 | "十五五教师AI素养培训布局——主要国家做法与启示" | 判"明确"三条全中→跳过侦察→直填[方向书](testruns/测试单B_教师AI素养/方向书.md)签字通过 | 约 40 秒 |

**两条路线都走通、都在 1 分钟内点完、机械签字校验都通过。** 详见各单 `过程记录.md` 与 `撰写者自评.md`。

关键验证：
- **"先侦察后点选"成立**：A 单里，凭空问"你对终身教育的倾向是什么"几乎答不出；但"分歧轴A 你站左端还是右端"一秒可答——印证设计 §三·五"反应比生成便宜"。
- **反锚定守住**：A 单 4 根分歧轴两端中立对称，撰写者选轴A右端为自主选择，非措辞诱导。
- **选填项真可跳过**：B 单半成形直觉留白，机械校验未误判为不合格。
- **两触点省人力**：全程只需点选，未逼撰写者写任何成形观点。

## 三、发现的问题

1. **禁区栏是"点选为主"里唯一的异类**（两单共性）。它是必答但需**主动生成**（不像其他栏可点选/确认），撰写者要停下想"我不想碰什么"，约占单栏耗时 20–30 秒，是唯一真卡点。已给"暂无明确禁区"兜底缓解，但本质仍是开放输入。
2. **直填路线的倾向箭头信息量偏低**（B 单暴露）。无侦察时只能勾通用箭头（借鉴/观望…），锚在撰写者主观理解上而非真实分歧轴上；相比 A 单"轴A你站哪端"（有据），B 单箭头更"薄"。→ 说明侦察的边际价值集中在**给不出方向的模糊场景**，明确场景跳过合理，但"明确但对方向没底"的用户是灰区。
3. **倾向箭头两套并存**（通用箭头 + 分歧轴端）在 A 单呈现时略犹豫选哪套。实为互补（轴端具体、通用箭头补态度），但选项呈现需明确"两套都可勾"。

## 四、遗留待决问题清单

1. **禁区栏形态**：是否把"必答开放输入"改为"从候选禁区清单点选 + 可补充"，以贴合"点选为主"？候选禁区清单从哪来（议题敏感区规则库？侦察副产物？）。
2. **灰区路线**：对"问题明确但倾向箭头没底"的用户，是否默认追加一次**轻侦察（只生成分歧轴，不出全速览）**？还是保持"想看再补跑"的手动触发？
3. **倾向箭头呈现**：通用箭头与分歧轴端两套如何在 AskUserQuestion 里合并呈现不混淆。
4. **逃生口的闭环**：逃生口被填＝侦察打偏，SKILL 已要求"记录并改侦察策略"，但**记录到哪、怎么反哺侦察**尚无落地机制（本沙箱两单均未触发逃生口，此路径未被实测）。
5. **方向书→后半段的接口**：本沙箱到签字为止。方向书如何喂给"机器立论/触点二观点清单"、方向保真闸如何逐栏回溯——属第二批（设计 §六·五 件③④），本沙箱只留接口说明未实现。
6. **全量模式方向书入参未实测**：v2 topic-material-search 的"箭头加权/禁区剪枝/侦察种子"仅写入 SKILL，本沙箱前半段不触发全量检索，待第二批联调验证（尤其"加权不剪反证栏"需真跑一遍确认未退化为命题裁剪）。
7. **模拟点选 vs 真人**：两单的撰写者点选均为 agent 模拟。真实撰写者的点选耗时、禁区栏卡壳程度、逃生口触发率，需设计 §六 MVP 里"本周真题真撰写者"跑一单实测。
