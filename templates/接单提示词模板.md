# 接单提示词模板（启动单·八号模板）

> 用途：每接一单，由派单 skill（order-dispatch）或人工按本模板生成该单的《接单提示词》，交给执行 agent——它是装配工 SKILL 之上的**任务简报层**：本单的作战条件（仓库根/引擎/决策模式/承前素材/禁区）都在这里定死。实践证明缺此简报时部分 agent 无法正确执行工作流（样例：2026-07-18 两单代理决策提示词）。
> 填写规则：〔槽〕为变量，逐槽填写；标【固定件】的整段**一字不改**照录；标（可选节）的整节无内容时**删除整节**，不留空壳。

## 第三步：决策模式【二选一·B 模式六条为固定件】

**〔A 模式·真人触点〕**：两触点**真停**——触点一产态势速览＋候选判型后停下，落待决材料等用户点选签字；触点二产观点清单后停下，等用户逐行勾/叉/改。用户决策回传后续跑，不得代拍、不得模拟。

**〔B 模式·代理决策制度（本单核心·铁律六条）〕**：用户已授权**全程代理决策**，但「代理」不等于「跳过」——两触点仍须走完全部判型/勾选动作并完整留痕，只是拍板人从真人换成子代理。

1. **派资深政策研究员人设子代理代行两触点决策**，站在「要把这篇写成能过资深审稿人眼的决策咨询内参」的立场判断，不图省事、不迎合预期。
2. **每个代拍板处打标** `[AGENT-WRITER·代理决策·待主人追认]` ＋ 写一句**决策理由**，供用户逐条追认或推翻。
3. **触点一（判型＋方向书）**：判定树走查路径**每一问的走向**＋前置闸结论＋落型依据，**完整记入《方向书》**（代理模式留痕不得省略）。读者层级默认司局级。
4. **触点二（认观点）**：观点清单按主线段分组，子代理**逐行勾/叉/改**并各写一句理由；改过的句子将一字不差成为小标题，按「能否放进署名报告」的标准审。**勾选率如实记录并标注「代理预演·非质量背书」**；勾选率 <50% → 回触点一修方向书重来，不许硬写。
5. **观点逻辑确认（第 7 步）**：代理预演即**自动 pass**，《论证结构单》照常落盘，不构成新增触点。
6. **晨报制**：全程跑完置顶产《晨报》——落什么型/走哪条判定树路径〔承前单加：与旧稿型的异同〕、勾选率（标代理预演）、执行引擎实况、每个 `[待主人追认]` 决策点清单、带病标注（如有）、需用户醒来定夺事项。3 分钟读完可追认或返工。
