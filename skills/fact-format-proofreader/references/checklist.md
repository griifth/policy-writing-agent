# 信息与格式校对核查表

## 一、事实核查矩阵

对关键陈述记录以下字段：

| 字段 | 要求 |
|---|---|
| 原文陈述 | 保留可定位的完整句子 |
| 类型 | 数据、政策、引文、时效判断、比较、因果或建议前提 |
| 核查结论 | 准确、部分准确、不准确、过度概括、无法核实 |
| 证据 | 官方页面、法规原文、统计公报、原始报告或论文 |
| 口径 | 统计期、发布日期、单位、分母、人群、地域和定义 |
| 修改方案 | 保留、更新、降调、补限制条件、删除或标为待核 |

## 二、来源优先级

1. 法律法规原文、发布机关官网、国家统计机构和国际组织原始数据库。
2. 项目主管机构、正式报告、公开预算文件和原始研究论文。
3. 权威媒体对原始材料的报道，仅作交叉验证或线索。
4. 聚合页、自媒体和无来源转载，不作为关键数字的唯一证据。

搜索摘要只能定位材料，不能替代打开原文核查。引用二手来源时应查找其声称引用的一手材料。

## 三、常见信息错误

- 把规划预测写成实际结果。
- 把累计人次写成独立人数。
- 用不同年份或不同人群的分子、分母计算“覆盖率”。
- 把项目总额写成年度拨款，或把本币与美元混用。
- 把本科、博士奖学金等项目类型误写成博士后职位。
- 把“鼓励组建队伍”推断为已设独立岗位或新增编制。
- 使用“目前、近期、首次、唯一、全国仅”等词却没有明确检索截止日。
- 文件名称正确但文号、年份、条款或效力状态错误。

## 四、中文标点判断

| 场景 | 推荐形式 | 注意 |
|---|---|---|
| 中文直接引语 | “……” | 引号内再用‘……’ |
| 政策、书籍、报告名称 | 《……》 | 会议名和项目名不一定用书名号 |
| 并列词语 | A、B、C | 有层级或较长分句时改用分号 |
| 数值范围 | 3—5年 | 负号、连接号和破折号不可混用 |
| 解释或转折插入 | ——内容—— | 不用连续两个英文减号代替 |
| 小数和百分比 | 23.0%、1.5倍 | 小数点和百分号不做全角替换 |
| 并列路径 | 高校、科研院所 | 避免用 `/` 代替中文连接词 |
| 复合模式 | “学术＋产业” | 也可根据语义写成“学术与产业” |

## 五、文档交付检查

- 原文件未覆盖，修订稿名称可辨认。
- 段落、表格、图片、脚注、页眉页脚数量无意外变化。
- 关键旧表述已不存在，正确表述可检索到。
- 无残留英文引号、中文语境英文标点或未解释的斜杠。
- Word 或 PDF 可正常打开，页面无乱码、截断和异常空白。
- 文件结构验证通过，最终链接指向真实存在的绝对路径。
