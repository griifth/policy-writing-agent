# 定方向 · 方向书（Report Clarify v2）

> 路径约定：本文件内相对路径一律以 direction_workflow/ 为根。

把"模糊主题 / 明确问题"变成一份**《方向书》**——撰写者九十秒两触点里的第一触点。
新范式一句话：**人给方向，机器立论；此步只收方向，不逼观点。**

> 极性（设计记录 §一·4）：撰写者手里有的是"大体方向"，不是成形命题。逼他给核心观点＝逼他现场编。
> 故 v2 把旧 Q3"核心观点"换成**倾向箭头**（点方向），并靠"先侦察后点选"让方向可对着东西挑，而非在真空里想。

仓库根 `<ROOT>` ＝ 本包 direction_workflow/ 的上一级目录（路径可能含空格，命令必须加引号）。
本沙箱：`<ROOT>/712测试`（历史沙箱目录，仅原机存在；整包移植后此沙箱说明不适用，真实使用时落盘 `runs/<run-id>/`）。

## 与原版 report-clarify 的差异（改造对照，详见 README.md）

| 维度 | 原 report-clarify | 本 v2 |
|---|---|---|
| 产物 | `clarify_decision.md` + 启动命令 | **《方向书》六栏**（到方向书签字为止，不拼命令、不接引擎） |
| Q1 读者层级 | 有 | **留**（方向书分量） |
| Q2 体例 | 战略应对/经验借鉴/趋势研判/国际比较 | **并入"问题判型"**：借鉴型/趋势研判型/差距追赶型三类型学（v2 起由所点判型自动派生为读者用途标签，不单独作答） |
| Q3 核心观点 | 逼用户给一句判断 | **改为"倾向箭头"**：警惕/借鉴/观望/追赶…只给方向，不逼命题 |
| Q4 维度逻辑 | 前置必答 | **降级**：本步不问，留给机器后续在观点清单里提案 |
| Q5 文风子型 | 有 | **删**（会议决议风格不限制） |
| 禁区 | 无 | **新增必答**（锥体边界，缺它机器立论必夹私货） |
| 半成形直觉 | 无 | **新增选填**（有就收，绝不逼） |
| 检索关系 | 预检索→凝练候选问题（为定题） | **侦察模式→态势速览**（为定向）：调 topic-material-search-v2 scout mode |
| 交互形态 | 一次性五问问卷 | **先侦察后点选**：对着速览点方向书 |

## 总原则（会议共识，不可违背）

- **自动判定只做预填默认项，用户拍板**。问题判型、读者层级、倾向箭头都可能被 AI 判错——所以一切判定只作为 AskUserQuestion 的推荐默认项呈现，由用户点选确认。"判不准"的风险由此绕开。
- **只收方向，不逼观点**。倾向箭头是"你站哪端"，不是"你的命题是什么"。半成形直觉栏留白合法。
- **反锚定**：侦察产出的态势速览分歧轴两端必须中立对称呈现，不得用倾向性措辞把撰写者往某一端引。
- **拿不准一律走侦察**：无法确定用户问题是否已明确时，缺省走侦察路线，宁多问一步。
- **证据不足如实标注**：侦察搜不到就写"线索不足"，不硬凑、不编造来源；无联网权限时态势速览全页标 `[SIMULATED]`。

## 流程

### ① 路线判定

读用户输入，按 `skills/report-clarify-v2/references/clarify_scope.md` 一节的判据分流：

- **问题已明确**（有明确对象/领域/落点，能直接回答"研判什么、写给谁、哪种用途"）→ **可跳过侦察，直接进 ④ 填方向书**（侦察结果作为可选参考，用户想看再补跑）。
- **仅有兴趣领域/模糊主题**（如"终身教育""想写 AI 教育方向"）→ 走 ② 侦察。
- **拿不准 → 一律走 ②**（缺省侦察兜底）。

### ② 侦察（调 topic-material-search-v2 的侦察模式，scout mode）

不出全料包，只出**态势速览一页纸**：

- 触发 `topic-material-search-v2` 的 **scout mode**（降配：十几条权威线索、分钟级、不走完整复审循环），传入 `topic`。
- 产出按 `templates/态势速览模板.md` 格式的**态势速览**：①最近谁动了什么（3–5 条硬事实带源）②分歧轴（各方在哪几点上吵，每轴两端中立，两端即候选箭头）③反直觉信号与数据缺口 ④候选研究问题 3–5 个。每栏末尾带逃生口。
- 溯源纪律同 topic-material-search-v2 的 sourcing-standard；无联网权限时用 `[SIMULATED]` 完成流程，并明确告知用户"侦察为模拟，真实检索待补"。
- 把态势速览呈现给用户，进 ③。

### ③ 对着速览点选（把速览翻译成方向书草稿）

- 用户对着态势速览：从**分歧轴选"站哪端"**（→ 倾向箭头）、从**候选研究问题勾感兴趣的**（→ 议题）、看**反直觉信号/数据缺口**勾问题意识。
- 任一栏的逃生口被填（"以上都不是，我关心的是＿＿"）＝侦察打偏：记录该事件，据其重跑或收窄侦察，再回 ②。
- 由此带出方向书草稿的"议题、倾向箭头"两栏，进 ④ 补齐其余四栏。

### ④ 填方向书（AskUserQuestion 逐栏点选；已明确路线从这里直接进入）

按 `templates/方向书模板.md` 六栏逐栏点选，每栏给推荐默认项（依据见 clarify_scope），用户可改：

| 栏 | 内容 | 呈现方式 |
|---|---|---|
| 议题 | 一句话话题 | 从 ③ 勾选的候选问题带出；或用户自述 |
| 倾向箭头 | 方向性选项（**可多选**） | 警惕/借鉴/观望/追赶/存疑 + **速览分歧轴两端动态带出的具体箭头** + 逃生口"以上都不是" |
| 读者层级 | `national_leader` / `moe_leadership` / `bureau` | 按落点高度预填（clarify_scope 四节） |
| 用途类型（自动派生） | **借鉴型 / 趋势研判型 / 差距追赶型** | v2 起不单独作答：由触点一所点问题判型自动派生为读者用途标签（可留白） |
| 禁区 | 什么不碰/不想说/篇幅红线（必答，可为"无"） | 填空 + "暂无明确禁区"勾选项 |
| 半成形直觉 | 还没成句的判断（**选填**） | 留白即可，绝不逼 |

- **倾向箭头是本步与原版最大分野**：不问"你的核心观点"，只问"你站哪端"。选项优先用速览分歧轴的两端（"轴A左端 vs 右端"），撰写者点端即可；无侦察时用通用箭头（警惕/借鉴/观望/追赶/存疑）。
- **问题判型**替代原 Q2 体例：判型一刀定全篇骨架，用途类型降为判型派生的读者标签；判断先于一切写作。
- **不问维度逻辑**（原 Q4）：本步不逼用户拆维度，留给后续机器在观点清单里提案、人勾选。
- **不问文风子型**（原 Q5）：会议决议风格不限制，撤。

### ⑤ 方向书签字（落盘，本沙箱终点）

1. **落盘方向书**：写入 `runs/<run-id>/方向书.md`（历史沙箱测试时曾写 `<ROOT>/712测试/testruns/`，移植后不适用），六栏齐全，用 templates/方向书模板.md 格式。
2. **机械签字校验**（模板末尾"签字校验"栏，逐条机械可查）：议题非空、倾向箭头≥1、读者层级已选定、问题判型已点选、禁区已表态；半成形直觉空缺不判不合格。任一硬栏缺失 → 报错、退回对应栏重点选。
3. **把方向书摘要呈现给用户复核**，用户确认即签字。**方向书全程有效**，后续立论/写作/成稿的"方向保真闸"对其逐栏回溯核查（本沙箱不涉及，仅留接口说明）。

## 边界

- 本 v2 到**方向书签字**为止：不拼启动命令、不跑流水线、不碰立论/写作/质检（那些是方向书架构后半段，本沙箱不测）。
- 侦察的全量升级归 `topic-material-search-v2`（方向书签字后主力检索才全量上，并吃方向书入参：箭头加权/禁区剪枝/侦察种子）。
- 沙箱铁律：不改原 `report-clarify/`、`topic-material-search/`，不碰 `workflow/`、`strategic_response_workflow/`；所有改动只在 `712测试/` 内。
