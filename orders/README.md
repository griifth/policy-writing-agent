# orders/ — 接单提示词存档

派单员 skill（`skills/order-dispatch/`）为每一单生成的《接单提示词》落在此处，命名：`接单提示词_〔主题〕_〔模式注〕_〔日期〕.md`。

- 接单提示词是装配工 SKILL 之上的**任务简报层**：本单的仓库根、执行引擎（生产/试跑）、决策模式（真人触点/代理决策）、承前素材、禁区与铁律都在其中定死。实践证明缺此简报时部分 agent 无法正确执行工作流。
- 模板见 `templates/接单提示词模板.md`（八号模板）；固定件一字不改，可选节无内容整节删除。
- 本目录只存提示词，不存产物——产物按宪法形制落 `runs/<id>/`。
